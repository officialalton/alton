## 0. 준비 — 관리자 화면에서 계정 관계 확인

계정의 역할과 자녀 연결은 **관리자 > 사용자** 탭에서 바로 읽을 수 있다.
DB 접속이 필요하지 않다.

| 서브탭 | 보이는 것 |
| --- | --- |
| 학부모 | 이름 · 이메일 · **자녀 이름** · 가입일 |
| 학생 | 이름 · 이메일 · 상태 · **보호자 이름** · 수강 과목 |
| 선생님 | 이름 · 이메일 · 상태 · 담당 과목 |

각 탭 우측 상단 검색으로 이름·이메일을 찾을 수 있다.

여기서 아래 조합이 되는지 확인한다.

1. 같은 학생을 사이에 둔 **학생 1 · 담당 선생님 1 · 보호자 1**
   (학생 탭에서 그 학생의 보호자 이름과 과목이 채워져 있으면 연결된 것이다)
2. 그 학생의 과목에 **예정된 수업**이 하나 있을 것 — 선생님 계정의 `수업` 탭에서 확인
3. 자녀 분리 확인용으로, 위 보호자와 **연결되지 않은** 다른 학생 1명

부족한 것이 있으면 그 항목만 알려주시면 준비 방법을 안내하겠다.

## 1. 회차 준비 → 수업 연결 (선생님)

1. 선생님 로그인 → `커리큘럼` → `학생별` → 학생 선택 → 과목 선택
2. 회차 목록에서 준비 상태 칩(`자료 N개 준비됨` / `목표 미작성` / `수업 N개에 연결됨`)이 보이는지
3. 아무 회차의 `회차 준비` → 목표 입력(포커스를 벗어나면 저장) → 교재·문제 `담기`
4. `수업에 연결하기`에서 예정 수업 선택 → `이 수업에 연결`
5. 연결 후에도 준비 내용이 계속 수정되는지 (연결 ≠ 고정)
6. 수업 목록에서 `수업 시작` → 그 시점 준비 내용이 고정되는지

## 2. 교재에 학생·선생님 각각 필기 → 서로 조회

1. 선생님 화면에서 `교재` 탭 → `✏️ 필기 모드` → 본문 위에 필기
2. 학생 로그인 → 같은 수업 `교재` 탭 → 선생님 필기가 보이는지
3. 학생도 `✏️ 필기 모드` → 필기
4. 선생님 화면 새로고침 → 학생 필기가 보이는지

두 계정을 동시에 열어두면 필기가 실시간으로 나타나는 것도 확인된다
(같은 브라우저의 다른 창이 아니라 **다른 브라우저나 시크릿 창**을 쓴다 —
같은 브라우저는 로그인이 하나뿐이다).

## 3. 토글은 본인 화면에만 적용

1. 선생님 화면에서 `학생 필기` 버튼을 눌러 끈다 → 학생 필기가 사라지는지
2. 그 상태에서 **학생 화면을 새로고침** → 학생 화면은 그대로인지
3. 반대로 학생이 `선생님 필기`를 꺼도 선생님 화면은 그대로인지

## 4. 보호자는 조회·토글만

1. 보호자 로그인 → 자녀 수업 열기
2. 학생 필기·선생님 필기가 모두 보이는지, 토글이 동작하는지
3. `✏️ 필기 모드` 버튼이 **없는지**, `보호자는 읽기 전용입니다`가 보이는지
4. 연결되지 않은 다른 학생의 수업 주소를 직접 입력 → 아무것도 보이지 않는지

## 5. 문제 풀이 제출 → 다시 풀기 → 이전 풀이 조회

1. 학생 화면 `문제` 탭 → 문제의 `풀이판 열기`
2. 보기를 하나 고르고 풀이판에 필기 → `풀이 제출`
   (답을 고르기 전에는 제출 버튼이 눌리지 않는다)
3. 제출 후 정답·해설이 열리는지, 제출한 답에 `제출한 답` 표시가 붙는지
4. `다시 풀기` → 새 풀이판이 열리는지
5. `이전 풀이`에서 `1번째`를 눌러 앞선 풀이와 답안이 그대로인지
6. 선생님 화면에서 같은 풀이판을 열어 `피드백으로 기록됩니다` 레이어에 필기
7. 학생 화면에서 `선생님 피드백` 토글로 켜고 끌 수 있는지
8. 제출한 뒤에도 선생님이 피드백을 계속 남길 수 있는지

## 6. 새로고침 후 필기 복원

1. 교재와 풀이판에 각각 필기 → `✓ 저장됨` 확인
2. 새로고침 → 필기가 그대로인지
3. 다른 기기(또는 다른 브라우저)에서 같은 계정으로 열어도 그대로인지

## 7. 별도 실기기 UAT (이 경로에 포함하지 않음)

- iPad + Apple Pencil 필기감 — 지연, 팜 리젝션, 지우개
- 실제 모바일 단말에서의 읽기 편의 — 긴 지문 스크롤, 풀이판 크기, 확대(＋/－) 조작
