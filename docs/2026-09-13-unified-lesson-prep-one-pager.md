# 수업 준비 통합 — 착수 전 1장 정리 (2026-09-13)

CLAUDE.md "새 기능 착수 전 1장 정리"에 따른 문서. 결정된 것만 적는다.

## 0. 지금 무엇이 있고 무엇이 없나

조사 결과, 준비 기능 자체는 이미 상당 부분 있다. 없는 것은 **계층 일반화와 이름**이다.

| 것 | 현재 |
| --- | --- |
| `UnitPrepPanel` | **학생 회차(overlay unit) 전용**. 목표·키워드·교재 구성·문제·수업 연결. 예약이 없어도 열린다(이미 6절 요건을 학생 계층에서는 만족) |
| `/teacher/session-prep/[sessionId]` | 예약된 수업에서 들어오는 별도 준비 화면(LessonPrepScreen) |
| `/session/[id]` | 실제 수업 세션뷰. 교재·문제·과제·단어장·연습장·필기 |
| 관리자 과목 템플릿 회차 | 준비 진입 **없음** |
| 선생님 기본 템플릿 회차 | 준비 진입 **없음** |
| 진입 문구 | `회차 준비`·`수업 열기`·`수업 시작`으로 흩어져 있음 |

## 1. 사용자 흐름

세 계층 모두 같은 화면에 들어온다. 무엇을 고치는 중인지는 머리말로 구분한다.

```
관리자 과목 템플릿 회차 ──┐
선생님 기본 템플릿 회차 ──┼─→ [수업 준비]  ← 같은 UI, 대상만 다름
선생님 학생별 회차     ──┤     머리말: 관리자 기준본 / 내 기본 구성 / ○○ 학생
예정 수업 카드         ──┘
```

- **정상**: 회차를 고른다 → 자동 구성된 교재·문제가 이미 담겨 있다 → 필요하면 고친다 → 나간다. 저장은 즉시.
- **예약 없음**: 그대로 열린다. 화면을 열기 위해 임시 예약이나 수업 기록을 만들지 않는다.
- **수업 문맥 있음**: 같은 화면에 그 수업이 표시되고, 회차 변경·재수업·보강 연결을 여기서 한다.
- **실패**: 저장 실패는 사유를 화면에 남기고 상태를 되돌린다. 권한 없음은 "이 회차를 수정할 수 없습니다".

## 2. 데이터와 권한

새 상태를 만들지 않는다. 이미 있는 세 층을 그대로 쓴다.

| 계층 | 원본 | 키워드 | 교재 |
| --- | --- | --- | --- |
| 관리자 기준본 | `subject_template_units` | `subject_template_unit_keywords` | `subject_template_unit_materials` |
| 선생님 기본 | `teacher_curriculum_template_units` | `teacher_curriculum_template_unit_keywords` | `teacher_curriculum_template_unit_materials` |
| 학생 운영본 | `curriculum_overlay_units` | `curriculum_overlay_unit_keywords` | `curriculum_overlay_unit_materials` |

`20261317000000`에서 세 층이 이어졌으므로 상속 경로는 이미 있다. 이번 작업은 **화면**이다.

권한:
- 관리자 기준본 = `requireAdmin()`
- 선생님 기본 = 본인 템플릿만 (기존 RLS)
- 학생 운영본 = 담당 선생님 또는 관리자 (`requireAssignedTeacherOrAdmin`)
- 학부모·학생에게는 구성 편집과 교사 전용 초안을 **노출하지 않는다**

관리자·선생님 기본 계층에서는 **예약·수업 시작·학생 답안·수업 기록을 다루지 않는다.** 그 기능들은 학생 계층에서만 렌더한다.

## 3. UAT 데이터

공유 비프로덕션 정리 전까지는 기존 teacher1 계정과 `SAT Reading Test 1`로 확인한다.
정리 후에는 새 실행 ID로 계정·과목·교재·문제·예약을 새로 만들어 전체를 다시 본다.

## 4. UI 기준

- **모든 진입 버튼은 `수업 준비`**. `회차 준비`·`세션 준비 하기`를 대체한다.
  `수업 열기`(=세션뷰로 이동)와 `수업 시작`(=실제 시작·고정)은 **다른 동작이므로 이름을 유지**한다.
- 머리말: `관리자 기준본 / 내 기본 구성 / ○○ 학생` + 과목 · N회차 · 회차 제목.
- 자동 구성된 교재·문제를 **바로 보여준다**. "기본 구성 가져오기"를 눌러야 보이는 필수 단계를 두지 않는다.
- 상태: 로딩(스켈레톤), 빈 상태("아직 담긴 교재가 없습니다"), 오류(사유 노출), 권한 없음.
- 기존 URL(`/teacher/session-prep/[sessionId]`)은 회차·수업 문맥을 유지해 통합 화면으로 연결한다.

## 5. 검증과 성능

- 통합 테스트: 세 계층의 권한 경계, 예약 없이 진입해도 예약·세션이 생기지 않음, 수동 조정이 자동 갱신에 덮이지 않음, 수업 시작 시점 고정.
- 화면 테스트: 계층별 머리말, 학생 계층에만 보이는 기능, 실패 시 사유 노출.
- Preview UAT: 세 계층 각각 진입 → 구성 확인 → 수업 시작 → 복습.
- 성능: 준비 화면 진입 쿼리 수를 계층별로 확인. 문제 목록은 저장된 것을 읽고 **진입마다 다시 뽑지 않는다.**

## 6. 단계

1. `UnitPrepPanel`을 계층 일반화(`layer: catalog | teacher | student`) + 머리말
2. 관리자 과목 템플릿·선생님 기본 템플릿 회차에 `수업 준비` 진입 추가
3. 진입 문구 통일, `/teacher/session-prep/[sessionId]`를 통합 화면으로 연결
4. 세션뷰 안으로 준비 패널 통합, 별도 준비 화면 제거
5. 수업 시작 고정 경로 확인(이미 있는 것과 대조)

각 단계 끝에 테스트를 돌리고, 2단계까지 끝나면 Preview에 올려 중간 확인을 받는다.
