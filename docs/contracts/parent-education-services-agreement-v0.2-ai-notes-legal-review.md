# 학생별 교육서비스 이용계약서 v0.2 — AI 회의록 통합 법률 검토 메모

> 내부 검토용 / 고객용 계약 문서에 포함하지 않음 / 법률 자문 아님
>
> `parent-education-services-agreement-v0.2-draft.md`와 `lib/contracts/family-contract-template.ts`를 실제 사용하기 전에 미국·캘리포니아 변호사가 확인할 쟁점이다.

## 1. 문서·제품 정합성

### 이번 개정으로 해소한 충돌

- 계약 본문의 선택형 AI 처리와 “거부해도 수업 계속 제공” 문구를 삭제했다.
- 부속서 A의 AI 사용·거부 체크박스와 별도 서명란을 삭제했다.
- 미성년자만을 전제로 한 당사자 문구를 보호자/성년 학생 분기 구조로 바꿨다.
- “중도 해지” 중심 표현을 이용중단·선택적 추가 구매·비활성 상태 중심으로 바꾸고 수업권 환불정책은 유지했다.
- 실제 DocuSign 생성 템플릿을 계약 원문의 전체 조항 체계에 맞추고 서명 앵커를 하나만 유지했다.
- 가족 기본계약에서 체험수업 조항과 체험 운영 문구를 제거하고, 체험 완료 후 정규수업 이용관계에만 적용되며 과거 체험에 소급되지 않는다고 정리했다.
- 체험 Smart Notes는 별도 계약서가 아닌 예약 화면용 `trial-class-ai-review-notice-consent-v0.1-draft.md`로 분리했다.

### 정식 사용 전 남은 충돌·제품 작업

1. 개인정보처리방침과 계약 의사결정 문서의 선택형 AI·거부 후 수업 계속 문구는 이번 문서 개정으로 해소했다. 실제 화면과 데이터 기록 구현은 별도 제품 작업이므로 아직 완료된 것으로 보지 않는다.
2. `CURRENT.md`에는 과거 opt-out 구현 이력이 역사 기록으로 남아 있으므로, 최신 정책 항목에서 체험 예약 단계 동의와 정규 계약 동의를 명확히 구분해야 한다.
3. 현재 계약 발송 호출부는 보호자 수신자만 전제로 한다. 템플릿은 성년 학생을 표현할 수 있게 했지만, 성년 학생의 계약 생성·수신 이메일·결제자·계정 활성화 흐름은 별도로 연결·검증해야 한다.
4. 체험 예약 화면의 학생별 최초 1회 동의와 감사기록 필드는 아직 구현되지 않았다. 구현 전 체험 Smart Notes를 운영하지 않는다.
5. 보관·삭제 자동화와 원본 1년/확정 리뷰 3년의 서로 다른 만료일 처리는 R12 인수 기준이 완료되기 전까지 문서상 약속과 실제 운영 사이에 차이가 있다.

## 2. 미국·캘리포니아 변호사 확인 쟁점

1. **필수 처리 구조**: Smart Notes를 정규수업의 필수 요소로 하고 비동의 시 계약·활성화를 진행하지 않으며 명시적 처리 중단 요청 후 향후 수업을 제공하지 않는 구조가 COPPA, 캘리포니아 소비자·개인정보법과 불공정 관행 규정에 부합하는지 확인한다. 개인정보 권리 행사와 필수 서비스 처리 중단을 구분해야 한다.
2. **COPPA와 보호자 확인**: 만 13세 미만 학생의 발언·식별정보 처리에 적용되는 직접 고지와 검증 가능한 보호자 동의 요건을 확인한다. 체험 단계의 보호자 계정·학생 연결·능동 확인·버전·시각·IP 기록과 정규 단계의 DocuSign 서명·이메일·최초 결제 기록이 각각 충분한지 분리해 검토한다. FTC는 아동의 음성이 포함된 오디오 파일을 개인정보로 보고 적용 사업자에게 사전 고지와 검증 가능한 보호자 동의를 요구한다. 원본 음성을 저장하지 않더라도 Google AI가 발화를 일시 처리해 텍스트 형태의 결과와 요약 회의록을 만드는 과정이 어떤 범위에 해당하는지 별도 분석이 필요하다. 참고: [FTC COPPA FAQ](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions), [FTC COPPA 안내](https://www.ftc.gov/legal-library/browse/statutes/childrens-online-privacy-protection-act).
3. **계약 전 체험수업**: 체험에서도 Smart Notes를 필수로 사용하므로, 보호자 계정 로그인·학생 연결·학생별 최초 1회 능동 확인·문구/정책 버전·시각·IP 기록이 만 13세 미만 학생에 대한 직접 고지와 검증 가능한 보호자 동의로 충분한지 확인한다. 체험 확인은 별도 계약이나 DocuSign 서명이 아니며 정규 가족계약을 대신하지 않는다. 이 확인 방식의 적법성은 정식 출시 차단 항목이다.
4. **캘리포니아 통신 동의**: 영상·원본 음성을 저장하지 않아도 실시간 발언을 Google AI가 처리해 텍스트 결과와 요약 회의록을 만드는 행위가 캘리포니아의 기밀 통신 관련 동의 요건에 해당하는지 확인한다. 체험은 예약 단계의 보호자 확인, 정규수업은 가족계약 한 번의 서명을 사용하므로 각 방식이 충분한지, 학생·선생님에 대한 별도 고지가 필요한지 변호사가 확인해야 한다.
5. **Google 회의 내 고지와 참가자**: Google은 관리자가 설정한 경우 참가자에게 “Take notes for me” 같은 회의 기능에 별도 확인을 요구할 수 있고 기능 작동 사실을 표시한다. ALTON은 미팅 입장 단계에 별도 동의 절차를 두지 않는 정책이므로, 실제 Workspace 설정에서 별도 확인 화면이 나타나지 않는지 검증하고 이 구성이 법률 및 Google 조건상 허용되는지 확인한다. 필수 확인을 우회해서는 안 되며, 별도 확인이 법률상 또는 기술상 필수라면 정식 운영 전에 제품정책과 계약 구조를 재검토한다. 참고: [Google Meet ‘Take notes for me’ 도움말](https://support.google.com/meet/answer/14754931?hl=en).
6. **스크린샷**: Google 도움말상 Smart Notes는 발표 화면의 스크린샷을 포함할 수 있고 시작자에게 기본 선택될 수 있다. 현 계약은 화면 이미지 처리를 포함하지 않으므로 기능을 확실히 끄고 검증하거나 계약·개인정보처리방침의 처리 항목을 확대해야 한다.
7. **향후 영상 녹화 도입**: 현재 계약은 별도 영상 녹화와 원본 음성 녹화를 허용하지 않는다. 향후 영상 녹화를 도입하려면 보관·접근·사용 목적·미성년자 보호·권리 행사·보안·사고 대응을 포함한 별도 기능 스펙을 먼저 확정하고, 새 계약 버전과 개인정보처리방침을 개정한 뒤 적용 법률상 필요한 재동의를 받아야 한다. 기존 계약 서명만으로 영상 녹화까지 확대하지 않는다.
8. **처리업체·국외 처리**: Google의 실제 계약 당사자, 제품 에디션, DPA, 데이터 리전, 하위처리업체, 보안조치와 국외 처리 고지를 확인한다. Google은 Workspace용 Gemini 콘텐츠가 허가 없이 도메인 밖 모델 학습에 사용되지 않는다고 설명하지만 실제 ALTON 계약·설정과 일치하는지 검증해야 한다. 참고: [Google Workspace with Gemini 데이터 보호 안내](https://support.google.com/meet/answer/13952129?co=DASHER._Family%3DBusiness-Enterprise&hl=en).
9. **전자서명**: 단일 DocuSign 서명으로 계약 전체와 필수 개인정보 처리 조항을 함께 수락하는 방식, 전자문서 수신 동의, 종이 사본 요청, 기록 접근·보존 및 회사 선서명 순서가 E-SIGN과 캘리포니아 UETA에 맞는지 확인한다. 참고: [미 연방 E-SIGN Act](https://www.govinfo.gov/app/details/PLAW-106publ229).
10. **성년 학생**: 학생 본인이 계약자일 때 결제자가 다른 경우의 승인·환불 수령자, 개인정보 요청권, 주소·통지, 과거 보호자 계정 접근권한 종료를 정한다.
11. **보관·삭제**: 1년·3년·7년 기간의 정확한 기산점, 동일 정보가 여러 자료에 포함될 때의 우선기간, 계정 폐쇄·삭제 요청·법적 보존과 백업 삭제의 관계를 확인한다.
12. **이용중단과 환불 — 정식 사용 차단 쟁점**: AI 처리 중단 요청의 효력 시점, 본인확인, 이미 임박한 예약의 취소, 보류 수업권 해제와 환불 산식 적용을 확인한다. 현재 제품정책 초안은 관할을 나누지 않고 다음과 같이 구성했다: 구매일부터 7일 이내이고 해당 구매분으로 유료수업이 시작·소진되지 않은 경우 실제 결제금액 전액 환불, 유료수업이 시작된 경우 또는 7일 경과 후에는 실제 결제금액에서 소진 횟수와 구매 당시 할인 전 단건가를 기준으로 공제, 더 유리한 강행법규 우선. 아래 관할별 쟁점이 해소되고 변호사가 최종 문구를 승인하기 전에는 계약서를 실제 발송하지 않는다.
    - 미국 FTC의 3영업일 Cooling-Off Rule은 소비자의 주거지나 판매자의 통상 영업장소가 아닌 특정 대면 판매에 관한 규칙이고, 전적으로 온라인·우편·전화로 이루어진 판매에는 적용되지 않는다고 FTC가 설명한다. 참고: [FTC Cooling-Off Rule 소비자 안내](https://consumer.ftc.gov/articles/buyers-remorse-ftcs-cooling-rule-may-help), [FTC 규칙 페이지](https://www.ftc.gov/legal-library/browse/rules/cooling-period-sales-made-home-or-other-locations).
    - 조사 범위에서는 캘리포니아의 일반 온라인 튜터링 서비스에 일률적으로 적용되는 7일 전액환불 의무를 확인하지 못했다. 이는 “의무가 없다”는 법률 결론이 아니므로, 캘리포니아 소비자법·교육서비스 규정과 실제 판매·광고 방식을 변호사가 확인해야 한다.
    - 한국 전자상거래법이 적용되는 소비자에게는 원칙적인 7일 청약철회 규정이 적용될 수 있으나, 용역 제공 개시 및 가분적 용역의 이미 제공된 부분에 관한 예외·범위가 문제될 수 있다. 국경 간 온라인 교육에 대한 적용, 고지·동의 방식, 이미 제공된 수업과 잔여 수업권의 구분을 한국 변호사가 확인해야 한다. 참고: [대한민국 대법원 판례정보 — 전자상거래법상 용역 제공 개시·가분적 용역 쟁점](https://www.law.go.kr/LSW/precInfoP.do?precSeq=237005).

## 3. 사용 전 확인 목록

- 계약 원문과 생성 HTML의 승인 버전·해시를 연결하고 실제 봉투에는 HTML 계약 문서 하나와 계약자 서명 탭 하나만 포함할 것
- 미성년 학생은 보호자, 성년 학생은 학생 본인을 실제 DocuSign 수신자·서명자로 지정할 것
- 계약 버전, 계약자 유형, 학생 연령, 개인정보처리방침 버전과 완료 감사증명을 함께 보관할 것
- 가족계약은 체험 완료 뒤에만 체결하고 과거 체험에 소급 적용하지 않을 것
- 체험 예약 전에 학생별 유효한 안내·동의 기록을 확인하고 Smart Notes가 적용되지 않으면 체험을 진행하지 않을 것
- 정규수업 시작 전 유효한 계약 버전과 Smart Notes 적용 여부를 fail-closed로 확인할 것
- Google 원본을 학생·계약자에게 공유하지 않고 선생님 검토 확정 리뷰만 제공할 것
- AI 결과만으로 출석·수업권·환불·정산을 자동 확정하지 않을 것
- Google 요약 회의록 원본·텍스트 형태 처리 결과 1년, 확정 리뷰 3년, 계약 기록 7년 삭제와 실패 재처리를 검증할 것
- 개인정보처리방침, 계약 결정 문서와 체험 화면의 필수 처리·중단 요청 표현을 실제 운영 전에 함께 검증할 것
