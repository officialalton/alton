## 4. 적용 원칙

1. 새 조건은 위 적용 시작일 이후 시작하는 수업과 명시된 업무에만 적용됩니다.
2. 적용 시작일 전에 완료되거나 시작한 수업, 과거 정산 항목과 이미 발급된 정산서는 변경하지 않습니다.
3. 통화가 변경되면 기존 통화 정산과 새 통화 정산을 분리합니다. 임의 환율로 과거 금액을 환산하지 않습니다.
4. 본 합의서에서 변경하지 않은 원계약 조항은 그대로 유지됩니다.
5. 관리자 화면 변경, 메시지 또는 구두 합의만으로는 시급이 변경되지 않으며 양 당사자의 전자서명이 필요합니다.
