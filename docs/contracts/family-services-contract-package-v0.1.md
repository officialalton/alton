1. 학생과 선생님이 수업 중 모두 동의하고 다음 일정에 지장이 없는 경우, 부족한 시간을 같은 날 연속하여 진행할 수 있다.

3. 회사는 장애가 있었다는 이유만으로 선생님에게 전체 예정시간 비용을 자동 지급하지 않으며, 실제로 인정된 제공시간과 운영정책에 따라 처리한다.

2. 중도해지 환불 시 이미 제공된 수업은 구매 당시 고지된 **할인 전 단건 정상가**로 다시 계산한다.
3. 기본 환불액은 다음 방식으로 산정한다.

# 5. R3 및 DocuSign 구현 필드 맵

## DocuSign 역할

- `guardian_or_adult_student`: 보호자 또는 성인 학생
- `company_signer`: ALTON 서명권자
- 학생은 별도의 법적 서명이 필요한 경우에만 추가 역할로 둔다.

## 필수 계약 스냅샷

- `contract_id`
- `contract_template_id`
- `contract_template_version`
- `household_id`
- `child_id`
- `guardian_profile_id` 또는 성인 학생 ID
- `order_form_version`
- `price_version_id`
- `refund_policy_version`
- `privacy_policy_version`
- `guardian_consent_policy_version` (해당 시)
- `currency`
- `package_price_minor`
- `single_lesson_list_price_minor`
- `lesson_quantity`
- `lesson_duration_minutes`
- `docusign_envelope_id`
- `docusign_status`
- `signed_at`
- `signed_pdf_drive_artifact_id`

## 계약 상태 권장안

`draft → ready_for_signature → sent → viewed → signed → active → completed|terminated|cancelled`

DocuSign 이벤트 수신 실패 또는 데이터 불일치는 계약 상태와 분리하여 `reconciliation_needed` 또는 관리자 검토 큐로 처리한다.

## 구현 원칙

1. ALTON DB의 계약·가격·정책 버전이 원본이다.
2. DocuSign은 서명 절차와 완료 증명에 사용한다.
3. 서명완료 PDF는 Google Shared Drive에 장기 보관하고 DB에서 파일 ID를 추적한다.
4. 동일 DocuSign 이벤트는 `provider + event_id` 기준으로 한 번만 적용한다.
5. 이벤트 순서가 뒤바뀌어도 이미 확정된 상위 상태를 잘못 되돌리지 않는다.
6. 계약서 본문에 특정 외부 서비스명을 과도하게 고정하지 않는다. DocuSign 교체 가능성을 남기되 현재 구현은 DocuSign을 사용한다.
7. 실제 고객 발송 전 변호사 검토와 DocuSign Sandbox E2E를 완료한다.
