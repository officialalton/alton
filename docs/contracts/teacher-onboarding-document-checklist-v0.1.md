# ALTON 선생님 계약·온보딩 제출서류 체크리스트 v0.1

> 목적: 계약 후보 선정부터 계정 활성화 전까지 필요한 자료를 최소한으로 안전하게 수집한다.
>
> 원칙: 세금번호, 신분증과 은행정보는 이메일·채팅·일반 문서함이 아니라 제한된 보안 채널로 받는다. 필요하지 않은 주민등록번호 전체, 여권 사본과 금융정보를 관행적으로 수집하지 않는다.

## 1. 모든 선생님 공통

- [ ] 법적 성명
- [ ] 개인 이메일과 전화번호
- [ ] 거주 주소, 시간대와 실제 수업 수행 국가·지역
- [ ] 국적 및 미국 세법상 U.S. person 여부 확인
- [ ] 이력서
- [ ] 최종 학력·재학·졸업 증빙
- [ ] 관련 시험성적·자격·경력 증빙 [실제 요구하는 항목만]
- [ ] 담당 가능 과목·시험·학년·언어 목록
- [ ] 신원확인 완료 기록 [확인 방법과 담당자만 기록, 불필요한 원본 사본 금지]
- [ ] 이해상충·겸업 공개
- [ ] 학생 안전·행동기준 확인
- [ ] 비밀유지·개인정보·정보보안 확인
- [ ] 교재·산출물 IP 조항 확인
- [ ] AI 보조 사용 및 제3자 자료 이용기준 확인
- [ ] 지급계좌 정보 [보안 채널]
- [ ] 비상 연락처 [필요성 결정 후]
- [ ] 범죄경력·아동안전 확인 동의 [실제 정책·현지법 확정 후]

## 2. 한국 등 미국 밖에서 수업하는 비미국 개인

- [ ] IRS Form W-8BEN
- [ ] 세법상 거주 국가와 현지 납세·사업자 정보 [해당 시]
- [ ] 주된 수업 수행지가 미국 밖이라는 확인
- [ ] USD 지급을 받을 계좌 또는 지급수단
- [ ] 현지 세금계산서·영수증 발행 의무 확인
- [ ] 한국 노동법상 근로자성·개인사업자 원천징수·부가가치세 처리 검토 결과 [한국 전문가 확인]

한국 거주자라도 미국 시민·영주권자 등 U.S. person이면 W-8BEN 대신 W-9 절차를 사용합니다.

## 3. 미국 세법상 U.S. person 또는 미국 내 업무 수행자

- [ ] IRS Form W-9 [U.S. person]
- [ ] 실제 업무 수행 주와 거주 주
- [ ] 주별 근로자/독립계약자 분류 검토
- [ ] 독립계약자로 확정되면 1099-NEC·사업자 지급 절차
- [ ] 근로자로 확정되면 W-4, I-9, 주별 세금·신규고용·급여 서류
- [ ] 주별 배경조회·아동안전 확인 통지와 동의
- [ ] 주별 유급병가·비용상환·근로시간 정책 수령 확인 [근로자인 경우]

## 4. 계약 문서

- [ ] 선생님 계약서 서명 완료
- [ ] 최초 보수 부속서: USD $50/시간, 지급통화·수수료·적용일
- [ ] 개인정보·보안 부속서
- [ ] 학생 안전·행동기준
- [ ] 지식재산권·기밀유지 조항
- [ ] 해당 국가·주 부속서
- [ ] 세금서류 유효성 확인

## 5. 시스템 활성화 게이트

- [ ] 계약 서명 완료(`contract_signed`)
- [ ] 관리자 기본정보 확인(`admin_base_info`)
- [ ] 유효한 현재 시급·통화 설정(`valid_rate`)
- [ ] 온보딩 완료(`onboarding_complete`)
- [ ] `@alton.education` Workspace 계정 발급(`workspace_issued`)
- [ ] 최초 로그인(`first_login`)
- [ ] ALTON 신원 연결(`identity_linked`)

7개 조건이 모두 충족되기 전에는 선생님을 `active`로 전환하거나 학생에게 배정하지 않습니다.

## 6. 자료 갱신·보관

- [ ] 주소·세금지위·지급계좌·업무 수행지 변경 신고 절차 안내
- [ ] W-8BEN 등 만료·변경 가능 세금서류 재확인 일정
- [ ] 시급 변경 시 새 합의서와 새 적용일 기록
- [ ] 계약·세금·시급·정산·지급 기록은 현재 제품정책상 종료 후 7년 보관
- [ ] 신분증 원본·배경조회 원자료는 법적 필요와 최소기간을 정한 뒤 제한 보관
- [ ] 계약 종료 시 Workspace·ALTON·Drive 접근권한 회수
