# ALTON 선생님 계약 — 사용자 결정 필요 항목 v0.1

## 1. 지급통화와 수수료

이번 초안은 사용자 요청의 `$50`을 **USD $50/정산 인정시간**으로 해석하고 지급통화도 USD로 두었다.

결정이 필요한 사항:

- 한국 선생님도 실제로 USD로 지급할지
- 한국 선생님에게 KRW로 지급하려면 고정 KRW 시급을 별도로 합의할지
- 송금수수료, 중개은행 수수료와 환전비용을 회사와 선생님 중 누가 부담할지

현재 제품정책은 선생님 기본 지급통화를 KRW로 두지만 다른 통화를 허용한다. USD $50을 계약조건으로 삼으려면 임의 환산하지 말고 USD로 지급하거나, 서명된 합의서에서 KRW 고정 시급을 따로 정하는 것이 안전하다.

## 2. 수업 외 업무의 보수

시급 $50이 다음 업무를 포함하는지 결정해야 한다.

- 수업 준비
- 수업 후 24시간 이내 리뷰 확정
- 과제 확인·피드백
- 필수 온보딩·교육
- 관리자 회의·품질개선 회의
- 교재·문제·콘텐츠 제작

권장안:

- 정규적인 짧은 준비·리뷰는 수업 120분 보수에 포함할 수 있도록 예상 범위를 명확히 표시
- 회사가 참석을 요구하는 교육·회의는 별도 유급시간으로 기록
- 콘텐츠 제작은 범위·납기·보수를 별도 발주서로 합의
- 미국에서 근로자로 분류되는 경우에는 계약상 “포함” 표시와 무관하게 법적으로 유급인 모든 시간을 기록·지급

## 3. 미국 기반 선생님의 계약형태

- 미국 전역에 하나의 독립계약자 계약을 바로 사용하지 않는 것을 권장한다.
- 실제 업무 수행 주를 먼저 확인하고 근로자/독립계약자 분류를 검토한다.
- 특히 캘리포니아에서 수업하는 선생님은 시간제 근로자 구조를 우선 검토한다.
- 근로자로 운영하려면 급여주기, 초과근무, 유급병가, 비용상환, 보험과 주별 고용서류를 별도로 결정해야 한다.

## 4. 계약 종료

해외 독립계약자 초안에는 양측 14일 전 통지 종료를 제안했다. 다음 중 확정이 필요하다.

- 14일 전 통지
- 30일 전 통지
- 특정 기간 없이 언제든 종료하되 이미 확정된 수업만 이행

학생 안전, 개인정보 침해, 허위서류와 중대한 위반은 즉시 정지·종료할 수 있도록 했다.

## 5. 기초서류와 신원·안전 확인

- 학력·경력 중 반드시 검증할 항목
- 범죄경력 또는 아동안전 확인을 어느 국가·주에서 요구할지
- 신원확인 제공자와 보관방식
- 한국 주민등록번호·여권 사본 등 고위험 정보의 수집 필요성
- 비상연락처 수집 여부

불필요한 고위험 신원정보는 수집하지 않고 “확인 완료” 결과만 보존하는 것을 권장한다.

## 6. 국제 분쟁 해결

한국 기반 개인과 미국 LLC 사이 계약에 캘리포니아법을 제안했지만, 중재기관·중재지·언어·비용과 한국 강행법규 적용은 아직 미확정이다. 실제 사용 전 한국 계약·노동·세무 전문가와 미국 변호사의 검토가 필요하다.
