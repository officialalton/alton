## C. 최신 제품정책을 문안에 그대로 반영한 항목

다음 항목은 이번 초안에서 새로 결정하지 않고 현재 확정 정책을 사용했다.

- 계약은 자녀 1명 단위이며 다른 자녀에게 자동 적용되지 않음
- 고정 만료일 없는 계속 계약, 자동 갱신·자동 결제 없음
- 추가 20회권 구매는 계약 갱신이 아니라 별도 구매
- 현재 기본 정규수업은 1:1, 120분
- 기본 수업권 유효기간은 구매일부터 12개월
- 학생의 24시간 전 취소는 무료, 24시간 미만 취소는 수업권 1장 소진
- 수업 시작 후 15분까지 미접속하고 최종 노쇼 확정 시 수업권 1장 소진
- 학생 지각 시 원래 종료시각에 종료하고 보충시간을 만들지 않음
- 선생님이 10분 이상 지각하면 미제공 시간을 보충시간으로 처리
- 미사용·미보류 유료 수업권만 환불 가능
- 보호자 중도 종료 환불액은 `실제 패키지 결제액 - (소진 횟수 × 구매 당시 실제 단건 판매가)`, 별도 해지 위약금 없음
- 무료·프로모션·보상 수업권은 환불 제외
- 회사 사유 종료 시 미사용 유료 수업권을 패키지 실제 결제단가로 환불하고 할인 회수 없음
- 환불 승인 후 5영업일 이내 결제대행사에 요청, 원 결제 통화·수단으로 처리
- 무활동 조건이 모두 충족된 상태가 12개월 지속되면 30일 전 고지 후 휴면 종료 가능
- 보호자는 AI 회의록과 수반 텍스트 전사를 사전 거부·추후 철회할 수 있고, 거부해도 수업은 계속 제공
- 계약 버전별 DocuSign 전자서명, 완료본·감사증명서는 회사 Shared Drive에 보관
