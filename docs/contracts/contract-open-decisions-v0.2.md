## B. 아직 사용자 또는 변호사 확인이 필요한 항목

### 1. 회사 설립 후 갱신

- LLC 설립 완료일과 캘리포니아 등록명을 계약 템플릿에 반영
- 신규 계약의 당사자를 Do Kyung Kim에서 LLC로 전환
- 설립 전에 체결된 계약을 LLC가 승계하는 방식은 실제 승계 시 간단한 통지·동의 문안으로 처리

### 2. 캘리포니아 밖으로 판매지역을 넓힐 때

- 해당 주의 소비자보호·교육서비스·환불 요건 검토
- 강제 중재와 집단·배심 포기가 실제로 필요한지 그때 재검토
- 기존 계약에는 새 분쟁조항을 소급 적용하지 않음

### 3. 개인정보 운영 설정

- 실제 SMTP 이메일 제공업체가 정해지면 개인정보처리방침에 업체명 추가
- 체험 단계에는 보호자 계정·학생·동의 문구/정책 버전·동의 시각·IP를 기록하고, 만 13세 미만에 이 방식이 충분한지는 정식 출시 전 변호사 확인
- 정규수업 전환 시에는 학생별 가족 기본계약 DocuSign 서명과 해당 시 최초 결제 거래를 추가 기록
- 정부 신분증은 별도 필요가 확인되지 않는 한 수집하지 않음
- 제품정책의 보존기간은 정식 오픈 전 최종 검토

### 4. 선생님 계약

선생님 계약은 가족·학생 계약과 분리해 별도로 작성한다. 선생님 계약에는 최소한 독립계약자 지위, 한국에서의 서비스 제공, 보수·정산, 세금서류, 비밀유지, 학생정보 보호, 교재·수업 산출물의 지식재산권, 계정·장비·Google Workspace 이용, 품질·안전 의무, 계약 종료와 자료 반환·접근권한 회수를 포함해야 한다. 현재 가족 계약 초안은 선생님과 회사 사이의 관계를 정하지 않는다.

## C. 최신 제품정책을 문안에 그대로 반영한 항목

다음 항목은 이번 초안에서 새로 결정하지 않고 현재 확정 정책을 사용했다.

- 계약과 체험 동의는 학생 1명 단위이며 다른 학생에게 자동 적용되지 않음
- 고정 만료일 없는 계속 계약, 자동 갱신·자동 결제 없음
- 추가 수업권 구매는 계약 갱신이 아니라 별도 구매
- 현재 기본 정규수업은 1:1, 120분
- 기본 수업권 유효기간은 구매일부터 12개월
- 학생의 24시간 전 취소는 무료, 24시간 미만 취소는 수업권 1장 소진
- 수업 시작 후 15분까지 미접속하고 최종 노쇼 확정 시 수업권 1장 소진
- 학생 지각 시 원래 종료시각에 종료하고 보충시간을 만들지 않음
- 선생님이 10분 이상 지각하면 미제공 시간을 보충시간으로 처리
- 미사용·미보류 유료 수업권만 환불 가능
- 구매일부터 7일 이내이고 해당 구매분으로 유료수업이 시작·소진되지 않으면 실제 결제액 전액환불
- 유료수업 시작 후 또는 구매일부터 7일 경과 후 환불액은 `실제 결제액 - (소진 횟수 × 구매 당시 할인 전 실제 단건 판매가)`, 별도 해지 위약금 없음
- 무료·프로모션·보상 수업권은 환불 제외
- 회사 사유 종료 시 미사용 유료 수업권을 해당 구매의 실제 결제단가로 환불하고 할인 회수 없음
- 환불 승인 후 5영업일 이내 결제대행사에 요청, 원 결제 통화·수단으로 처리
- 유효 수업권과 예정 수업이 모두 없으면 계속적 서비스 이용관계를 비활성 상태로 관리 가능
- 체험과 정규수업 모두 Smart Notes 필수. Google AI가 발화를 처리해 요약 회의록과 텍스트 형태의 처리 결과를 만들 수 있으며, 영상·원본 음성 녹화와 별도 Meet 발화 문자화 기능은 사용하지 않음
- Google 원본은 고객에게 통상 직접 제공하지 않고 선생님이 검토·수정한 리뷰를 제공하되 개인정보 열람·정정 권리는 제한하지 않음
- 처리 중단 요청은 접수하지만 Smart Notes만 끄고 체험·정규수업을 계속하는 옵션은 없음. 정규수업 예약·잔여 수업권은 기존 취소·환불정책으로 정리
- 계약 버전별 DocuSign 전자서명, 완료본·감사증명서는 회사 Shared Drive에 보관

## D. 변호사 검토가 필요한 문안

- 서비스 제공 지역별 청약철회와 환불 제한
- 회사의 안전·위반 사유 즉시 제한 또는 종료 시 환불 처리

- 전자서명과 전자통지 동의의 주별 요건
- 미성년자·COPPA 및 주별 개인정보법에 따른 보호자 동의
- 보존기간, 삭제권과 법적 보존 의무의 충돌
- 교재 지식재산권 및 학생 창작물 이용허락 범위

## E. 기존 v0.1과의 관계

- 기존 `family-services-contract-package-v0.1.md`, `parent-education-services-agreement-v0.1.md`, `lesson-entitlement-purchase-confirmation-v0.1.md`는 모두 대체된 과거 참고자료이며 신규 계약·화면의 기준으로 사용하지 않는다. v0.2 기본계약과 함께 사용할 구매확인서는 `lesson-entitlement-purchase-confirmation-v0.2-draft.md`이다.
- `family-services-contract-package-v0.1.md`의 가정 단위 기본계약 구조는 최신의 자녀별 계약 원칙과 충돌하므로 v0.2의 기준으로 사용하지 않았다.
- v0.1에서 미확정으로 남아 있던 학생 취소·노쇼와 기본 유효기간은 최신 제품정책으로 확정되어 v0.2에 반영했다.
- v0.1 환불식의 “법적으로 허용되고 사전에 고지된 공제액”은 현재 확정 제품정책에 없는 공제이므로 v0.2에서 제거했다.
