## 4. 사용 및 환불 핵심 안내

1. 수업권은 회사 사이트에서 담당 교사가 공개한 가능 시간에 예약하여 사용합니다.
2. 정규 수업권 1회는 위에 표시된 수업시간을 기준으로 합니다.
3. 취소·지각·노쇼에 따른 수업권 처리는 구매 당시 적용되는 정책 버전에 따릅니다.
4. 중도 해지 환불의 기본 계산식은 다음과 같습니다.

   `환불 예정액 = 실제 결제금액 - (사용 완료 수업 횟수 × 위에 저장된 할인 전 1회 정상 단가) - 법령상 허용되는 기타 공제액`

5. 적용 법령이 위 조건보다 우선하는 경우 해당 법령을 따릅니다.

회사는 이 구매확인서를 변경 불가능한 거래 스냅샷으로 보관하고, 보호자가 서비스에서 조회하거나 이메일로 받을 수 있도록 합니다. 구매 후 가격이나 정책이 변경되어도 이 구매확인서에 저장된 거래 조건은 변경하지 않습니다.
