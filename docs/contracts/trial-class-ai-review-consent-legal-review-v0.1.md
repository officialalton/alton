# 체험수업 및 AI 수업리뷰 안내·동의 v0.1 — 법률 검토 메모

> 내부 검토용 / 화면에 표시하지 않음 / 법률 자문 아님

## 정식 출시 전 필수 확인

1. **COPPA 적용과 보호자 확인 방식**: 만 13세 미만 학생의 발화가 온라인으로 처리되는 경우, 보호자 계정 로그인·학생 연결·능동 확인·시각·IP 기록이 검증 가능한 보호자 동의에 충분한지 확인한다. FTC는 아동 개인정보를 수집하기 전에 직접 고지와 검증 가능한 보호자 동의를 요구하고, 아동의 음성이 포함된 오디오 파일을 개인정보로 설명한다. 참고: [FTC COPPA FAQ](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions), [FTC 6단계 준수 안내](https://www.ftc.gov/business-guidance/resources/childrens-online-privacy-protection-rule-six-step-compliance-plan-your-business).
2. **직접 고지의 완결성**: 개인정보처리방침 링크만 제시해서는 충분하지 않을 수 있으므로 체험 예약 화면 자체에 수집 항목, 목적, 필수성, Google 처리, 권리와 동의 방법을 이해하기 쉽게 표시했는지 확인한다.
3. **Google을 통한 처리**: Google이 서비스 제공에 필수적인 처리업체인지, 제3자 공개에 관한 별도 선택이 필요한지, 실제 계약·DPA·하위처리업체·데이터 위치·모델 학습 제한과 삭제 기능을 확인한다.
4. **캘리포니아 통신 동의**: 별도 영상·원본 음성 녹화를 하지 않더라도 발화를 Google AI가 실시간 처리하고 텍스트 결과를 만드는 데 예약 단계의 단일 보호자 확인이 충분한지 검토한다. 학생 본인 또는 선생님에 대한 별도 고지·동의 요건도 확인한다.
5. **원본 비공유와 개인정보 권리**: Google 원본을 고객에게 통상 직접 제공하지 않는 운영정책과 개인정보 열람·사본·정정·삭제 권리를 구분한다. 권리 요청 시 다른 참가자의 권리와 기밀정보를 보호하면서 제공할 범위와 형식을 정한다.
6. **처리 중단의 효과**: Smart Notes가 필수인 체험·정규수업을 처리 중단 요청 후 계속 제공하지 않는 구조가 개인정보 권리 행사에 대한 부당한 불이익으로 평가되지 않는지, 서비스에 객관적으로 필요한 처리인지 확인한다.
7. **보관기간**: 체험 Smart Notes 원본 1년, 확정 리뷰 3년, 동의 기록 7년, 로그 1년과 백업 35일의 기산점·법적 근거·최소 필요성을 확인한다.
8. **중요 변경과 재동의**: 목적·정보 범위·처리업체·영상/음성/화면 처리·보관기간·공개 범위의 중요한 변경 기준과 이미 체험을 마친 학생의 기존 정보에 대한 적용을 확인한다.

## 제품·문서 차단 조건

- 체험 동의 화면이 구현되기 전 Smart Notes 체험을 시작하지 않는다.
- 만 13세 미만 보호자 확인 방식이 변호사에게 승인되기 전 정식 출시하지 않는다.
- Google Meet 자체의 필수 표시·확인 기능을 우회하지 않는다.
- 향후 영상 또는 원본 음성 녹화를 도입하려면 새 기능 스펙, 개인정보처리방침·화면 문구 개정과 필요한 재동의를 먼저 완료한다.
