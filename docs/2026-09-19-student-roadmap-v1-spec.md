# 학생 프로필 · 대학 준비 로드맵 V1 — 제품 오너 지시 원문 (2026-09-19)

> 이 문서는 제품 오너가 채팅으로 전달한 지시를 그대로 옮긴 것이다. 별도 세션(브랜치
> `feature/student-roadmap-v1`, 워크트리 `ALTON-student-roadmap-v1`)에서 이 스펙을
> 기준으로 진행한다. 구현 착수 전 CLAUDE.md의 "새 기능 착수 전 1장 정리" 규칙에 따라
> 조사·설계 보고를 먼저 제출할 것.

## 지시 원문

다음 신규 작업축으로 `학생 프로필 · 대학 준비 로드맵` V1을 설계·구현하세요. 현재 통합
작업과는 별도 브랜치에서 진행하고, 기존 학부모 포털 통합이 끝난 뒤 최종 통합 대상으로
넘기세요.

### 진입점

- 학생·학부모 포털: 메인 탭 `홈` 다음에 `로드맵` 추가
- 교사: 담당 학생의 커리큘럼 관리 화면과 수업 화면에 `학생 프로필 · 로드맵 보기` 읽기
  전용 진입점 추가
- 관리자: 운영 화면에서 전체 열람·수정 가능
- 교사는 읽기 전용이며 학생 프로필을 수정할 수 없음

### V1 학생 프로필

처음부터 모든 정보를 한 번에 강제하지 말고, 섹션별로 저장·보완 가능한 프로필로
만드세요.

1. **기본 학업 정보**: 학년, 졸업 예정 연도, 학교, 교육과정, GPA/등수(선택), 현재
   수강 과목
2. **시험 정보**: SAT/ACT 응시 이력, 최고 점수, 목표 점수, 다음 응시 계획
3. **관심 분야와 대학 목표**: 관심 전공·진로, 희망 국가/대학 유형, 관심 대학 목록,
   지원 목표 시기
4. **활동과 수상**: 활동명, 분야, 역할, 참여 기간, 시간, 리더십·성과, 수상명과 수상
   수준
5. **준비 현황**: 에세이, 추천서, 포트폴리오, 봉사·인턴십 등 준비 항목의 현재 상태

학생·학부모는 프로필을 작성·수정할 수 있고, 교사는 읽기만 할 수 있게 하세요. 재정·
가족·민감한 배경 정보는 V1에서 수집하지 않거나, 필요해도 학부모·관리자만 보도록 별도
설계하세요.

### 로드맵 화면

- 상단: 프로필 완성도, 현재 학년, 목표 대학/전공, 다음 핵심 마일스톤
- 본문: 월별 또는 학기별 마일스톤
- 각 마일스톤: 해야 할 일, 목표 시점, 상태, 관련 자료 또는 메모
- 학생·학부모가 같은 로드맵을 상시 열람
- 교사는 동일 내용을 읽기 전용으로 열람

AI OS 월간 종합 리뷰는 V1에서 자동 생성하지 마세요. 대신 향후 AI가 이 프로필·수업
리뷰·과제·시험 결과를 읽어 월간 보고서를 작성할 수 있도록 데이터 모델과 화면 자리를
준비하세요. 입학 가능성 점수나 합격 확률은 근거 데이터·모델이 준비되기 전까지 표시하지
마세요.

### 착수 전 요구사항

구현 전 현재 학생·학부모 프로필, 학교·시험·활동 데이터, 권한 모델을 조사하고, 기존
테이블 재사용 가능 여부와 필요한 신규 스키마를 설계 보고로 먼저 제출하세요.

## 진행 순서 (BRANCH-WORKFLOW.md 기준)

1. `CLAUDE.md` → `docs/CURRENT.md` → `docs/BRANCH-WORKFLOW.md` 순으로 먼저 읽는다.
2. 기존 학생/학부모 프로필 관련 테이블(`profiles`, `students`, 학교/시험/활동 관련
   기존 컬럼이 있는지), 권한 모델(RLS 패턴)을 조사한다.
3. 재사용 가능한 것과 신규 스키마가 필요한 것을 구분한 설계 보고를 작성해 제품
   오너에게 먼저 제출한다(구현 착수 전).
4. 승인 후 섹션별 저장 가능한 프로필 폼 → 로드맵 화면 → 교사 읽기전용 진입점 →
   관리자 전체 열람/수정 순으로 구현한다.
5. 이 브랜치는 기존 학부모 포털 통합(진행 중인 다른 세션 작업)이 끝난 뒤 별도로
   최종 통합 대상이 된다 — 지금 당장 `preview/m4-integration-verification`에 병합하지
   않는다.
