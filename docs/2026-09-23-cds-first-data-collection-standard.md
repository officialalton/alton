# CDS 우선 데이터 수집 표준 (2026-09-23 제정, 11차 세션)

이 문서는 **표준(절차 규범)**이다. 특정 세션의 작업 기록이 아니라, ALTON 프로젝트에서
대학 학업지표·학비·재정지원·전공 정보를 다루는 **모든 향후 세션이 반드시 따라야
하는 절차**다. 제품 오너가 10차 세션(프린스턴)에서 실제로 수행한 방식을
"매번 진행할 때마다"의 가이드로 지정했다.

이 표준을 만들게 된 계기: 10차 세션에서 프린스턴 데이터의 SAT/ACT/GPA 지표가
`cohort='admitted'`(합격자)로 잘못 저장돼 있던 것을 발견·정정했다. CDS 원문을
직접 확인하지 않고 추측/관행으로 채운 데이터가 실제로 컨설턴트·학생에게 잘못된
정보를 노출할 뻔한 사례다. 재발 방지가 이 표준의 핵심 목적이다.

## 1. 항상 CDS를 1차 출처로 찾는다

대학 학업지표·학비·재정지원을 다룰 때는 추측이나 2차 정리 사이트(예: 랭킹
사이트 요약)가 아니라, 그 학교의 **최신 공식 Common Data Set(CDS) PDF 또는
웹버전을 우선 출처로 찾는다.**

- 검색 패턴: `"[대학명] common data set"`
- 보통 대학 **IR(Institutional Research)** 페이지에 게시됨
  (예: `ir.princeton.edu/other-university-data/common-data-set`)
- 파일명 패턴 예: `CDS_20XX-20XX_[학교명].pdf`, 또는 IR 페이지 내 연도별
  섹션 링크(B/C/G 등)로 나뉜 웹버전
- 못 찾으면: 그 학교 입학처(admissions) 공식 웹페이지를 2차 출처로 대체하되,
  아래 4번대로 `verification_status`를 정직하게 낮춘다. 추측으로 값을 채우는
  것은 어떤 경우에도 금지.

## 2. CDS를 찾으면 최소 섹션 B/C/G를 전부 읽고 아래 항목을 빠짐없이 추출한다

- **섹션 C (신입생 입학)**: SAT 영역별(EBRW/Math) 25/50/75 백분위, ACT
  영역별(Composite/Math/English/Writing/Science/Reading) 25/50/75 백분위,
  점수구간 분포, SAT/ACT 제출률, GPA 평균, GPA 4.0 비율(전체/제출자/미제출자
  구분), 고교 석차 상위10%(수집 여부 포함 — 미수집이면 "N/A(미수집)"으로
  명시, 빈칸으로 두지 않음), 지원자/합격자/등록자 수(성별·거주지 구분 있으면
  포함), 합격률, 등록률(yield), 대기자명단(제공수/수락수/합격수)
- **섹션 B (재학생 현황)**: 1년 재학유지율(retention), 6년 졸업률(grad rate)
- **섹션 G (학비)**: 학비, 기숙사비, 필수수수료 — **해당 항목이 어느 학년도
  기준인지 반드시 확인하고, 입학지표(C섹션, 보통 전년도 가을학기 기준)와
  연도가 다르면 notes에 명시**(프린스턴 사례: 입학지표는 Fall 2025, 학비는
  2026-2027 학년도 기준으로 서로 달랐다)

## 3. Cohort 구분은 타협 불가

CDS의 C9-C12 (SAT/ACT/GPA 관련 섹션)는 **거의 항상 "등록한 신입생
(enrolled first-year)" 기준이지 "합격자(admitted)" 기준이 아니다.** 이 둘을
혼동해서 저장하면 안 된다.

- 저장 전 반드시 CDS 원문에서 해당 표의 제목/각주를 직접 확인해
  `cohort='enrolled'`인지 `cohort='admitted'`인지 `cohort='applicant'`인지
  정확히 판정한다.
- 프린스턴에서 이 오분류가 실제로 있었고 10차 세션에서 정정했다 — **같은
  실수가 다른 학교에서도 반복될 수 있으니, 각 학교 작업 시 매번 원문을
  다시 확인한다** (다른 학교의 기존 저장값을 그대로 신뢰하지 않는다).

## 4. 모든 값에 출처·검증상태를 정직하게 남긴다

- CDS 원문에서 확인한 값: `verification_status='official'`,
  `source_url_id`는 CDS 게시 페이지 URL(신규면 `source_type='common_data_set'`로
  등록), `verified_at`=작업일, `notes`에 `"CDS [연도], [수집방식: 웹크롤 or
  관리자 수기]"` 형식으로 남긴다.
- CDS를 못 찾아 대학 공식 입학 웹페이지(2차 출처)로 대체한 경우:
  `verification_status='secondary'`로 낮춰 저장. 그 페이지 값도 불확실하면
  `'unverified'`로 더 낮춘다. **추측으로 채운 값은 어떤 verification_status로도
  저장하지 않는다 — 아예 행을 만들지 않고 "미확보"로 남긴다.**
- 이 구분(`official` / `secondary` / `unverified` / 미확보)은 UI에도 그대로
  노출되어야 한다(신뢰도를 사용자에게 숨기지 않는다).

## 5. 학과(전공) 목록은 전체를 수집한다

그 학교의 공식 학사요람(academic catalog) 또는 전공 목록 페이지에서
**전체 전공을 수집**한다. 일부(상위 인기 전공 등)만 넣고 끝내지 않는다.
기존에 일부만 있는 경우 전체 삭제 후 재작성하지 말고 **additive**로 빠진
전공을 추가한다.

## 6. 이 표준의 적용 범위

이 문서는 `feature/university-info-sources` 브랜치와 그 후속 브랜치에서
대학 데이터(학업지표/학비/재정지원/전공)를 다루는 **모든 세션**에 적용된다.
새 세션을 시작하는 담당자는 작업 전에 이 문서를 먼저 읽어야 한다
(`docs/CURRENT.md`에 포인터가 있다).

## 7. 200개교 완료 후 반드시 할 일 (아직 아님)

**200개교 전체 처리가 끝나면**, 별도 세션에서 최종 통합보고서를 작성해야
한다. 제품 오너 지시: "CDS 내용에 있는 것들 중 입시 컨설턴트와
학생/학부모가 알아야 하는 정보들은 다 노출이 되어야 해. 그거에 맞춰서 UI 도
조정해야하고." — 즉 CDS에 있는 정보 중 컨설턴트·학생·학부모가 실제로
참고할 만한 것은 전부 공개 화면에 노출되어야 하며, 그에 맞춰 UI도 계속
확장해야 한다. **이 작업은 200개교가 다 끝난 마지막 세션의 책임이다 —
지금(11차 세션, 200개교 중 일부만 처리) 하지 않는다.** 이 지시는 200개교가
끝날 때까지 매 세션의 인계 기록에 계속 전달되어야 한다.
