# P2/P3 3단계 — 역할별 UAT 절차

작성: 2026-09-12. 대상: 제품 오너 피드백 1~7 중 **데이터 구조·서버 배선이 끝난 범위**.
UI 품질(피드백 7의 전문적 화면 구성·디바이스 대응)은 이 절차의 대상이 아니다 —
아래 §4에 남은 범위를 따로 적었다.

## 1. 사전 준비

- 실행 ID: `p2p3s3-<날짜>` 형식으로 정하고, 이번 UAT에서 만든 계정·가족·학생·수업에 전부 붙인다.
- 공식 시연 계정(지훈/박서연 등 seed)은 **건드리지 않는다**. 조회만 한다.
- 종료 후 실행 ID 단위로 정리하고, 공식 계정이 그대로인지 확인한다.
- Wise 실송금·`CRON_SECRET`·Production 활성화는 이번에도 범위 밖이다.

## 2. 역할별 절차

### 2-1. 교사 — 예약 없는 회차 준비 (피드백 1)

1. 교사 포털 → 커리큘럼 → 학생 선택 → 학생별 운영 커리큘럼.
2. 예약이 **하나도 없는** 학생을 고른다. 회차 목록에서 아무 회차의 `회차 준비`를 누른다.
3. 확인:
   - 예정 수업이 없어도 화면이 열린다.
   - "아직 이 학생의 예정된 수업이 없습니다" 안내가 보인다.
   - 목표를 적고 포커스를 벗어나면 저장된다(다시 들어와도 남아 있다).
   - 교재·문제 후보가 이 회차의 키워드로 검색된다. `담기`/`빼기`가 동작한다.
   - 후보가 없으면 "공개 교재가 없습니다" / "공개된 문제가 없습니다"가 각각 구분되어 보인다.
4. 같은 학생에게 수업을 하나 예약한 뒤 준비 화면을 다시 연다.
   - 예정 수업이 목록에 뜨고 `이 수업에 연결`이 동작한다.
   - 연결 뒤 `연결됨 · 수업 열기`로 바뀐다.

### 2-2. 교사 — 준비와 고정의 분리 (피드백 2)

1. 위에서 연결한 수업의 `회차 준비` → 준비 내용을 더 고친다.
2. **수업을 시작하기 전에** 확인:
   - 준비 내용이 계속 수정된다(고정 안내가 뜨지 않는다).
   - `수업 열기`로 세션뷰에 들어갔다 나와도 여전히 수정된다 — 화면 진입은 수업 시작이 아니다.
3. 수업 목록에서 `수업 시작`을 누른다.
4. 시작 뒤 확인:
   - 준비 화면이 더 이상 구성을 바꾸지 못한다.
   - 문제 원본을 관리자 화면에서 고쳐 새 버전을 공개해도, 이 수업 화면의 지문·보기·정답·해설이 그대로다.

### 2-3. 학생 — 필기 범위 (피드백 4)

1. 학생 계정으로 같은 수업의 세션뷰를 연다.
2. 교재 탭에서 `나만 보는 필기`로 바꾸고 필기한다.
3. 교사 계정을 **동시에** 열어둔 채 확인:
   - 교사 화면에 그 필기가 실시간으로 그려지지 않는다.
   - 교사가 새로고침해도 보이지 않는다.
4. `함께 보는 필기`로 바꾸고 필기하면 교사 화면에 실시간으로 나타난다.
5. 저장 표시(`✓ 저장됨`)와 연결을 끊었을 때의 저장 실패 문구를 확인한다.

### 2-4. 보호자 — 조회 범위 (피드백 6)

1. 보호자 계정으로 같은 학생의 수업을 연다.
2. 확인: 학생 개인 교재 필기와 문제 풀이 기록이 **보이지 않는다**.

### 2-5. 직접 주소 접근 (피드백 6)

담당이 아닌 교사 계정으로 다음 주소를 직접 입력한다.

- `/teacher/session-prep/<다른 교사의 sessionId>` → 권한 안내 화면
- `/session/<다른 교사의 sessionId>` → 404

## 4. 남은 범위 — UI 품질 (피드백 7)

데이터·권한·배선은 끝났지만 아래는 다음 라운드다.

- 세션뷰 정보 구조와 역할별 모드 정리(개발자 도구 인상 제거)
- 교재·문제 학습 화면의 전문적 구성 — 긴 지문, 이미지, 수식, 문제 번호·난이도·배점
- 문제별 풀이 화이트보드의 화면 배치와 진입 동선
- 커리큘럼 회차 → 준비 → 실제 수업 → 복습의 시각적 연속성
- 데스크톱·iPad·Apple Pencil·모바일 대응
