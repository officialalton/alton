# P2/P3 3단계 — 역할별 UAT 절차

작성: 2026-09-12. 대상: 제품 오너 피드백 1~7 중 **데이터 구조·서버 배선이 끝난 범위**.
UI 품질(피드백 7의 전문적 화면 구성·디바이스 대응)은 이 절차의 대상이 아니다 —
아래 §4에 남은 범위를 따로 적었다.

## 1. 사전 준비

- 실행 ID: `p2p3s3-<날짜>` 형식으로 정하고, 이번 UAT에서 만든 계정·가족·학생·수업에 전부 붙인다.
- 공식 시연 계정(지훈/박서연 등 seed)은 **건드리지 않는다**. 조회만 한다.
- 종료 후 실행 ID 단위로 정리하고, 공식 계정이 그대로인지 확인한다.
- Wise 실송금·`CRON_SECRET`·Production 활성화는 이번에도 범위 밖이다.

## 2. 역할별 절차

### 2-1. 교사 — 예약 없는 회차 준비 (피드백 1)

1. 교사 포털 → 커리큘럼 → 학생 선택 → 학생별 운영 커리큘럼.
2. 예약이 **하나도 없는** 학생을 고른다. 회차 목록에서 아무 회차의 `회차 준비`를 누른다.
3. 확인:
   - 예정 수업이 없어도 화면이 열린다.
   - "아직 이 학생의 예정된 수업이 없습니다" 안내가 보인다.
   - 목표를 적고 포커스를 벗어나면 저장된다(다시 들어와도 남아 있다).
   - 교재·문제 후보가 이 회차의 키워드로 검색된다. `담기`/`빼기`가 동작한다.
   - 후보가 없으면 "공개 교재가 없습니다" / "공개된 문제가 없습니다"가 각각 구분되어 보인다.
4. 같은 학생에게 수업을 하나 예약한 뒤 준비 화면을 다시 연다.
   - 예정 수업이 목록에 뜨고 `이 수업에 연결`이 동작한다.
   - 연결 뒤 `연결됨 · 수업 열기`로 바뀐다.

### 2-2. 교사 — 준비와 고정의 분리 (피드백 2)

1. 위에서 연결한 수업의 `회차 준비` → 준비 내용을 더 고친다.
2. **수업을 시작하기 전에** 확인:
   - 준비 내용이 계속 수정된다(고정 안내가 뜨지 않는다).
   - `수업 열기`로 세션뷰에 들어갔다 나와도 여전히 수정된다 — 화면 진입은 수업 시작이 아니다.
3. 수업 목록에서 `수업 시작`을 누른다.
4. 시작 뒤 확인:
   - 준비 화면이 더 이상 구성을 바꾸지 못한다.
   - 문제 원본을 관리자 화면에서 고쳐 새 버전을 공개해도, 이 수업 화면의 지문·보기·정답·해설이 그대로다.

### 2-3. 학생 — 필기 범위와 영속 저장 (피드백 2·4)

1. 학생 계정으로 같은 수업의 세션뷰를 연다.
2. 교재 탭에서 `나만 보는 필기`로 바꾸고 필기한다.
3. 교사 계정을 **동시에** 열어둔 채 확인:
   - 교사 화면에 그 필기가 실시간으로 그려지지 않는다.
   - 교사가 새로고침해도 보이지 않는다.
4. `함께 보는 필기`로 바꾸고 필기하면 교사 화면에 실시간으로 나타난다.
5. 저장 표시(`✓ 저장됨`)와 연결을 끊었을 때의 저장 실패 문구를 확인한다.
6. 개인 필기를 남긴 뒤 새로고침·로그아웃 후 재접속·다른 기기에서 같은 수업을 연다.
   개인 필기가 그대로 복원되어야 한다(서버 저장).
7. `함께 보는 필기` / `나만 보는 필기`를 오가도 기존 필기의 공개 범위가 바뀌거나
   다른 쪽으로 복사되지 않아야 한다.

### 2-6. 문제 풀이 화이트보드 (피드백 5)

1. 학생 계정으로 수업의 `문제` 탭을 연다.
2. 문제 1의 `풀이판 열기` → 필기 → 문제 2로 옮겨 풀이판을 연다.
   각 문제의 풀이가 섞이지 않아야 한다.
3. 새로고침 후 다시 열면 각 풀이가 그대로 남아 있어야 한다.
4. `다시 풀기` → 새 회차가 생기고, `지난 풀이`에서 이전 회차를 다시 볼 수 있어야 한다.
5. `풀이 제출` 후 정답·해설이 열리고, 제출한 풀이는 더 이상 고칠 수 없어야 한다.
6. 교사 계정에서 같은 풀이판을 열면 학생 원본은 읽기만 되고, 교사의 필기는
   `피드백으로 기록됩니다` 레이어로 들어가야 한다.
7. 수업 종료 후 복습에서도 당시 문제 버전과 풀이·피드백이 함께 열려야 한다.

### 2-4. 보호자 — 읽기 전용 열람 (2026-09-12 정책 개정)

앞선 "보호자는 요약만" 지시는 철회됐다. 보호자는 **연결된 자녀의 학생 화면을
읽기 전용으로** 본다. 기존 학부모 포털 요약 기능은 그대로 유지된다.

1. 보호자 계정으로 자녀의 수업을 연다(`/session/<sessionId>`).
2. 볼 수 있어야 하는 것: 교재, 문제, 교사 공용 필기, 자녀의 문제 풀이, 교사 피드백, 복습 기록.
3. 볼 수 **없어야** 하는 것: 자녀의 개인 교재 메모(학생 본인만).
4. 정답·해설은 자녀에게 열리는 시점과 같아야 한다 — 자녀가 제출하기 전에는 보호자에게도 보이지 않는다.
5. 할 수 **없어야** 하는 것: 답안 제출, 필기 작성·수정·삭제, 수업 시작, 준비 구성 변경.
   버튼이 없는 것으로 끝내지 말고, 개발자 도구로 쓰기 요청을 직접 보내도 거부되는지 확인한다.
6. 자녀가 둘 이상인 보호자는 각 자녀의 화면에서 다른 자녀의 내용이 섞이지 않는지 확인한다.
7. 연결되지 않은 학생의 `sessionId`를 직접 입력하면 아무것도 보이지 않아야 한다.

### 2-5. 직접 주소 접근 (피드백 6)

담당이 아닌 교사 계정으로 다음 주소를 직접 입력한다.

- `/teacher/session-prep/<다른 교사의 sessionId>` → 권한 안내 화면
- `/session/<다른 교사의 sessionId>` → 404

## 3. 이번 UAT에서 확인하지 않는 것

- Wise 실송금, 정산 Production 활성화
- P4-3(교사 서류) 구현 — 설계 상태 유지

## 4. 자동 검증 / 실기기 확인 구분

### 자동 검증으로 이미 확인한 것(통합·컴포넌트 테스트)

- 예약 없는 회차 준비와 수업 연결, 시작 시점 최신 준비 고정, 중복 시작 차단
- 고정된 문제 버전 읽기, 제출 전 정답·해설 비노출
- 필기 범위별 조회·기록 권한(보호자 읽기 전용·쓰기 전면 차단 포함), 자녀 간 분리
- 개인 필기의 서버 영속 저장과 범위 변경 불가
- 문제별 풀이판 분리, 재풀이 회차 구분, 교사 피드백 별도 레이어

### 제품 오너의 실기기 확인이 필요한 것

- 교사·학생 **동시 접속** 시 공용 필기의 실시간 반영과 개인 필기의 미반영
- iPad + Apple Pencil 필기감(지연, 팜 리젝션, 지우개)
- 모바일 실제 단말에서의 읽기 편의(긴 지문 스크롤, 풀이판 크기)
- 네트워크 끊김 상태에서의 저장 실패 문구와 복구

## 5. 남은 범위 — 화면 완성도 (피드백 6)

- 커리큘럼 → 회차 준비 → 수업 → 복습을 같은 정보 구조·디자인으로 연결
- 교재·문제 읽기 영역을 중심에 둔 레이아웃 정리
- 이미지·수식 렌더링
