# 단어장 2차 — 1장 정리 (2026-09-15)

제품 오너 지시(2026-09-15, 범위 축소본): ALTON SAT 공용 단어장 200단어×10권(2,000단어) 실 데이터 채우기 + 상시 누적 학습 자산화 + 수업 중 통합 + 교사 포털 시험 발급 UI + 오답 복습 흐름.

## 1. 사용자 흐름
- **학생**: 어느 화면(학생 포털/수업 화면)에서든 내 단어장 + 배정된 공용 단어 + 학습 상태(오답·복습 대상) 확인. 시험 응시 → 제출 → 결과(오답 단어는 뜻·예문과 함께 재노출) → "복습 시험 만들기"로 재시험.
- **교사**: 수업 화면 또는 교사 포털에서 학생(복수 선택 가능, 그룹 엔티티는 없음 — 다중 선택) + 단어 범위(권·난이도·위치 구간) + 문항 수 + 마감일 지정 → 즉석 시험 발급. 수업 중에는 참고/배정한 단어만 그 세션에 연결.
- **보호자**: 자녀 단어장·시험 이력 읽기 전용.
- **관리자**: 공용 단어장 CRUD(이번엔 시딩 스크립트로 채움, 화면 CRUD는 범위 밖 — 스크립트가 곧 관리 도구).

## 2. 데이터와 권한
- 기존 `vocab_library_words`에 `difficulty`(1~5), `source_note` 추가. 실 데이터는 검증 스크립트(`scripts/vocab-library-seed.ts`)로 권별 200개씩 채움 — 관리자 화면 수기 입력 아님.
- `vocab_review_items`(학생별 오답 복습 큐, 원본 단어 스냅샷 보관 — 원본이 나중에 바뀌어도 그 시점 뜻 유지) — RLS는 기존 `vocab_words`와 동일 패턴(`student_id=auth.uid() or teaches_student() or is_guardian_of() or is_admin()`).
- `vocab_session_links`(세션 하나에 연결된 라이브러리/커스텀 단어 — 세션 화면은 전체 단어장을 복제하지 않고 이것만 봄).
- `vocab_quizzes`에 `due_at` 추가. RLS를 기존 owner/creator 전용에서 `teaches_student`/`is_guardian_of`/`is_admin` 포함으로 확장(보호자·다른 조회 경로도 봐야 하므로).
- `assign_vocab_quiz` RPC 재정의(간단한 `teaches_student()` 헬퍼 재사용, `due_at` 파라미터 추가). 신규 RPC `link_vocab_words_to_session`(교사가 수업 중 단어 연결), `assign_library_words_to_student`(교사가 공용 단어를 학생 개인 단어장에 복사 배정 — student_id 원본 유지, `assigned_by` 컬럼으로 구분).

## 3. UAT 데이터
- 로컬 시딩 스크립트 실행 결과(권별 완료 수·중복·오류 수정)는 이 문서와 별도 보고 파일(`docs/2026-09-15-vocab-content-batch-1.md` 등)에 기록. Preview 확인은 기존 UAT 학생/교사/보호자 테스트 계정 재사용(신규 계정 발급 불필요 — 읽기 위주 기능).

## 4. UI 기준
- 학생: 기존 `VocabLibraryTab`에 "복습 대상" 섹션 추가, 시험 결과 화면에 오답 단어 카드(뜻/예문) + "복습 시험 만들기" 버튼.
- 세션 화면: 기존 `VocabTab`을 교체 — 이 세션에 연결된 단어만 나열, 교사는 "단어 배정"(라이브러리 검색)·"즉석 시험" 버튼.
- 교사 포털: 신규 탭/패널 — 학생 다중 선택, 권/난이도/구간 선택, 문항 수, 마감일, 발급. 발급 이력(학생별 상태: 대기/완료/점수) 목록.
- 보호자: 읽기 전용 패널(단어장 목록 + 시험 이력, 응시 버튼 없음).

## 5. 검증과 성능
- 권 하나(200단어) 끝까지: 생성 → 결정적 검증(중복 단어/뜻, 예문에 표제어 포함 여부, 반의어 자기참조 금지) → DB 삽입 → 학생 단어장 노출·가리기 토글·4지선다 시험·채점·오답 복습 연결까지 실제 확인 후, 같은 파이프라인으로 나머지 9권.
- 통합 테스트: RLS(교사/보호자/학생 조회 범위), `link_vocab_words_to_session`/`assign_library_words_to_student`/`assign_vocab_quiz` 권한 경계, 오답→복습 큐 적재·재시험 클리어.
- 실시간 push, 문제은행 작업은 범위 밖(보류).
