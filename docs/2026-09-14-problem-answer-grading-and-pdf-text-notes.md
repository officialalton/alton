# 2026-09-14 — 문제 풀이·채점 흐름 정리 / PDF 텍스트 필기·전체 지우기 (1장)

제품 오너 UAT(학생 포털 수업 화면) 지시를 그대로 옮긴 결정. 배경 설명 없음.

## 1. 사용자 흐름

| 유형 | 학생 | 제출 | 채점 | 정답·해설 |
|---|---|---|---|---|
| 객관식 `mc` | 선택지 하나를 **클릭**하면 답이 저장된다. 채점 전엔 다른 선택지로 바꿀 수 있다. 풀이판 없음. 아래 연습장(선택) | 없음(클릭이 곧 답) | **자동**(정답 인덱스 비교) → 교사가 `채점 완료`로 확정 | 교사 채점 뒤 |
| 서술형 `essay` | 아래 연습장에 답을 쓴다(자동 저장). | 없음 | 교사 수동(정답/부분/오답 + 한마디) | 교사 채점 뒤 |
| 풀이형 `math` | 풀이판 열기 → 풀이 → `풀이 제출`(기존) | 있음 | 교사 수동 | 교사 채점 뒤 |

- "문제를 푼다고 무조건 정답·해설이 열리지 않는다." 학생은 **교사가 채점을 끝낸 문제만** 정답·해설을 본다(서버가 payload 에서 뺀다).
- 교사: 문제마다 `채점` 구역 — 학생 답(객관식은 자동 채점 결과 포함)·연습장/풀이판을 보고 `정답 / 부분 / 오답` + 한마디 → `채점 완료`. 다시 채점 가능. 학생 화면은 채널 알림 + 새로고침으로 따라온다.
- **연습장 탭은 없앤다.** 문제 아래 연습장으로 대체됐다.
- PDF 필기: `T 텍스트` 도구(클릭한 자리에 글 상자, 교사·학생 각자 레이어), `전체 지우기`(자기 레이어·이 페이지만).

실패·취소: 답 저장 실패 → 선택 표시를 되돌리고 사유 표시. 채점 실패 → 사유 표시. 채점된 문제의 답은 바꿀 수 없다(서버 거부).

## 2. 데이터와 권한

- `session_problem_work` 에 `auto_correct`, `grade('correct'|'partial'|'incorrect')`, `grade_comment`, `graded_at`, `graded_by`.
- `submit_problem_attempt`: 선택지가 오면 고정 버전의 `correct_index` 와 비교해 `auto_correct`. **채점 전이면 객관식 선택지만 바꿀 수 있다**(고정 트리거 완화 — 서술 답안·필기 경계는 그대로 고정).
- `grade_problem_attempt(work, grade, comment)`: 담당 교사·관리자만. 채점 후 답 변경은 거부.
- `session_problem_formats(session)`: 수업 관계자에게 문제 유형만 돌려준다(학생은 `problems` 를 직접 못 읽는다).
- 정답·해설 공개 조건: 교사·관리자 항상 / 학생·보호자는 `graded_at` 이 있는 문제만.
- PDF 페이지 `전체 지우기` = `event_type='clear_all'` (`append_page_stroke_events` 가 `tool:'clear'` 세그먼트를 그렇게 기록). 기존 RLS 그대로(학생은 자기 레이어, 교사는 교사 레이어). 텍스트는 `tool:'text'` + `text`·`size` 필드 — 스키마 변경 없음.

## 3. UAT 데이터
기존 Preview 의 제품 오너 계정(교사·학생)으로 확인. 자동 테스트는 로컬 DB.

## 4. UI 기준
- 객관식: 선택지 버튼이 곧 답. 선택 뒤 "답 저장됨". 채점 뒤 정답 표시(초록)·내 답·결과 배지·해설.
- 서술형: 안내 한 줄 + 연습장 자동 펼침. 풀이형: 기존.
- 교사 `채점` 구역은 문제 카드 아래. 학생이 아직 풀지 않았으면 그렇게 말한다.

## 5. 검증
- 통합 테스트: 자동 채점, 채점 전 재선택 허용·채점 후 거부, 교사만 채점, 학생 payload 에 채점 전 정답 없음, 페이지 clear_all 기록·재구성.
- 컴포넌트 테스트: 유형별 화면, 교사 채점 흐름, 텍스트 도구·전체 지우기.
