## 1. 신규 보호자, 자녀 3명 온보딩
- [ ] 관리자 → 상담 칸반에서 신규 상담 건 확인
- [ ] "체험 온보딩 안내 발송"에서 학생 추가 버튼으로 3명(이름/이메일/학년/과목) 입력 후 발송
- [ ] 온보딩 링크는 보호자 앞으로 **1개만** 생성되는지
- [ ] 링크 확인 시 신규 보호자 계정 + household 1개 생성
- [ ] 학생 3명 각각 Auth 계정 생성 + 개별 비밀번호 설정 초대 발송(메일 3통 각각 다른 링크)
- [ ] 칸반에 학생별 카드 **3개** 생성 확인, 원래 상담(가족) 카드는 그대로 이력으로 남고 더 이상 움직이지 않는지
- [ ] 형제자매 배지(👨‍👩‍👧)로 같은 가족임을 알아볼 수 있는지

## 2. 기존 보호자, 새 자녀 추가
- [ ] 기존 보호자 이메일로 같은 흐름 진행 → 기존 계정/household 재사용되는지(신규 생성 안 됨)
- [ ] 새 자녀만 학생별 카드로 추가되는지

## 3. 발송 진입점 두 곳 동일 동작
- [ ] 칸반 카드 상세에서 발송 폼 열었을 때도 1행+`학생 추가`로 여러 명 입력 가능한지
- [ ] `TrialOnboardingPanel` 화면에서도 동일하게 동작하는지
- [ ] 둘 다 학생 1명만 넣는 기존 방식도 문제없이 되는지(회귀 확인)

## 4. 부분 실패·재시도
- [ ] 학생 중 1명 이메일을 일부러 잘못 입력(중복/형식오류 등)해 계정 생성 실패 유도
- [ ] 나머지 형제자매는 정상 처리되는지(카드/계정/초대 모두 생김)
- [ ] 실패한 학생만 재시도 버튼으로 재처리 가능한지
- [ ] 재시도 두 번 연속 눌러도 중복 계정/카드 안 생기는지

## 5. Smart Notes 비게이트 확인
- [ ] 체험 수업 진행 중 Smart Notes가 아직 연결 안 된 상태(`pending`)에서도
  - [ ] 수업 종료 처리가 막히지 않는지
  - [ ] 선생님이 리뷰 초안 저장·공개 확정 가능한지
  - [ ] 정규 전환이 막히지 않는지
- [ ] 나중에 Smart Notes가 연결되면 리뷰에 링크만 추가되고 기존 확정 리뷰 내용은 안 바뀌는지

## 6. 학생 1명 기존 흐름(회귀)
- [ ] 학생 1명짜리 온보딩이 예전과 동일하게 문제없이 동작하는지
