FAQ

자주 묻는 질문입니다.
크레딧은 어떻게 사용되나요?

구매일로부터 12개월간 유효하며, 세션 변경·취소는 24시간 전 요청 시에만 환불됩니다.

수업 변경/취소는 어떻게 하나요?

학생 계정에서 직접 요청할 수 있으며, 월 3회까지 가능합니다. 학부모 계정에서는 요청이 제한됩니다.

담당 선생님이 갑자기 바뀔 수 있나요?

선생님의 부득이한 사정 시 관리자가 우선적으로 재배정을 지원합니다.

학원 정책 안내

Alton Education 서비스 운영 정책입니다.

크레딧: 구매일로부터 12개월 유효, 만료 30일 전 알림, 자녀 간 이동 가능.

세션 변경/취소: 월 3회까지, 24시간 전 요청만 환불. 노쇼도 취소 횟수에 포함. 학생만 요청 가능.

선생님 노쇼/취소: 학생 측 크레딧은 항상 보존되며, 반복 시 관리자가 재매칭을 지원합니다.
