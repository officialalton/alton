# 학부모 ↔ 관리자 상담 신청·메신저 V1 사양

> 작성일: 2026-09-17  
> 상태: 제품 정책 확정, 구현 대기

## 목표

학부모가 관리자에게 상담을 신청하거나 일반 메신저로 소통할 수 있게 한다. 수업 운영
대화는 만들지 않는다.

## 권한 범위

- 학부모: 자기 명의로 만든 상담 신청과 그 메시지, 일반 메신저만 생성·열람·응답할 수 있다.
- 관리자: 모든 상담 신청과 메신저를 관리·응답·상태 변경할 수 있다.
- 학생: 접근 권한과 화면이 없다.
- 선생님: 접근 권한과 화면이 없다.
- 다른 보호자에게는 자동으로 공유하지 않는다. 공동 열람은 후속 정책으로 분리한다.

## 두 기능 구조

학부모 포털에는 `상담 신청`과 `메신저` 두 기능만 둔다.

- `상담 신청`: 구조화된 상담 요청을 만든다.
- `메신저`: 학부모와 관리자가 일반 사항을 대화하는 스레드다.
- 상담 신청 상세에도 해당 상담 건의 대화가 이어질 수 있다.
- 별도 문의 티켓, 문의 분류, 문의 상태는 만들지 않는다.

## 학부모 화면

학부모 포털에 `상담 신청`과 `메신저` 진입점을 둔다.

### 상담 신청

- 대상 자녀 선택
- 상담 주제
- 내용
- 희망 연락 방식과 시간대
- 요청 상태와 관리자 답변·일정 확인

상태: `신청됨 → 확인 중 → 일정 조율 중 → 일정 확정 → 완료`.

### 메시지

- 학부모와 관리자 사이의 일반 대화 스레드를 제공한다.
- 읽지 않은 관리자 답변 수를 메신저 진입점에 표시한다.
- 첨부, 음성 메시지, 단체 대화는 V1 범위에서 제외한다.

## 관리자 화면

관리자 포털에 `상담 신청·메신저` 지원함을 둔다.

- 상담 신청 / 메신저 / 전체 필터
- 상담 상태, 담당 관리자, 최근 메시지, 미응답 시간 기준 정렬
- 상담 신청 상세에서 학부모 정보, 대상 학생, 요청 내용, 대화, 상태 변경을 한 화면에서 처리
- 상담 요청은 일정 제안·확정 정보를 같은 요청에 기록
- 완료된 상담과 메신저 대화는 읽기 전용 이력으로 보존

## 데이터와 안전성

- 상담 신청과 메신저는 학부모 계정 기준으로 분리하고 RLS로 학생·선생님 접근을 차단한다.
- 상담 신청 메시지와 일반 메신저 이력은 삭제 대신 보존 상태를 사용한다.
- 상담 일정·결제·계약·수업 기록을 메시지 본문에 복제하지 않고, 필요한 경우 해당 제품 기록을 참조한다.
- 이메일·푸시 알림은 V1 범위에서 자동 발송하지 않는다. 앱 내 읽지 않음 표시부터 제공한다.

## V1 완료 기준

1. 학부모가 상담 신청을 만들고 일반 메신저를 사용할 수 있다.
2. 관리자가 지원함에서 상담 상태와 메신저 대화를 관리할 수 있다.
3. 상담 상세에서 양쪽이 메시지를 이어서 보낼 수 있다.
4. 학생·선생님·다른 보호자는 권한이 없다.
5. 읽지 않음 상태와 완료 이력이 역할별로 정확히 보인다.
6. 상담 일정 확정은 요청 상태와 일정 정보만 기록하며, 기존 예약·계약 흐름을 우회하지 않는다.
