## 1. 배경 — 왜 스케줄링/화상회의를 바꾸는가

지금까지 예약은 캘린들리, 화상 수업은 줌으로 진행해왔다. 그런데 학생이 실제로 예약을 확정해도 우리 시스템에 전혀 반영이 안 되는 문제를 발견했고, 원인을 추적한 결과 "예약이 확정되면 실시간으로 알려주는" 캘린들리의 핵심 기능이 **유료 플랜에서만 열리는 기능**이었다는 걸 확인했다. 이걸 켜려면 선생님 한 명 한 명이 개인적으로 유료 플랜을 쓰거나, 우리가 캘린들리 조직 계정(선생님 전원을 팀원으로 초대하는 방식)을 유료로 써야 하는데, 어느 쪽이든 **선생님이 늘어날수록 인당 비용이 계속 나가는 구조**다.

## 2. 결정 — 구글 워크스페이스로 전환

- **관리자·선생님 계정**: 우리 회사 도메인(`alton.education`)의 구글 계정으로 통일한다. 선생님이 합류하면 회사가 그 도메인 계정을 발급한다.
- **학생·학부모 계정**: 회사가 계정을 만들어주지 않는다. 대신 **본인 구글 계정(무료 개인 Gmail 포함) 보유를 서비스 이용 조건**으로 안내한다.
- **예약**: 캘린들리 → 구글 캘린더 기반의 자체 예약 화면으로 교체.
- **화상 수업**: 줌 → 구글 미트로 교체.
- **계약서 서명**: DocuSign → **구글 전자서명(eSignature)으로 전환**한다. 단, 구글 쪽은 계약 발송·서명완료 확인을 자동으로 처리하는 기능(API)이 없어서, 지금 DocuSign이 자동으로 하고 있는 부분(매칭 확정 시 자동 발송, 서명 완료 시 자동으로 학생 상태 전환)이 **관리자가 직접 확인/처리하는 수동 단계로 바뀐다** — 이 트레이드오프를 감수하고 전환하기로 결정.
- **모든 계약서·문서·첨부파일은 구글 드라이브에 저장하고, 화면에서는 그걸 그대로 띄워서 보여주는 방식으로 전환**한다. 계약서(학부모/학생/선생님), 관리자 "문서" 화면(법인설립/세무/계약템플릿 등 회사 공식 문서), 수업 세션뷰의 "보충 자료" 탭(선생님·학생이 올리는 파일)까지 전부 포함 — Supabase Storage 등 별도 파일 저장소를 쓰지 않고 구글 드라이브 하나로 통일한다.
- **수업 세션뷰(교재+필기+단어장+AI문제생성+과제+연습장 통합 화면)**: 우리 서비스의 핵심 차별점이라 지금처럼 자체 개발을 유지한다. 구글 클래스룸 같은 기성 도구로 옮기지 않는다.
- **연습장의 "Docs" 서브탭만 예외적으로 구글 문서(Google Docs)를 그대로 가져다 쓴다** — 지금은 외부 링크만 올려두는 수준이라 부실했는데, 처음부터 우리가 실시간 공동편집 에디터를 새로 만드는 대신 구글 문서를 화면 안에 그대로 띄우는 방식으로 해결한다.
- **메시지**: 지금 서비스 안에서 쓰는 채팅 기능을 그대로 유지한다(Gmail로 옮기지 않음). 이미 잘 동작하고 있어서 바꿀 이유가 없다.

## 3. 왜 전면 재개발이 아니라 기존 코드를 고쳐나가는가

지금 나온 문제들은 전부 특정 부분에 한정된 것들이다: (1) 예약/화상 연동 하나를 다른 서비스로 교체하는 것, (2) 아직 안 만든 화면들을 채우는 것, (3) 버그 한 건. 반면 학생 포털 전체, 수업 세션뷰, 관리자의 사용자·매칭·커리큘럼·수업권·정산·계약, 결제, 로그인 — 이 전부 실제로 잘 동작하고 있고 문제 리포트가 없었다. 이걸 다 버리고 새로 만드는 건 손실만 크고 지금 문제 해결에는 도움이 안 돼서, 기존 서비스를 계속 확장하는 방향으로 진행한다.

## 4. 실행 순서 (8단계)

각 단계는 착수할 때 별도로 상세 기획을 다시 잡는다. 아래는 순서와 이유만 정리한 것이다.

1. **예약/화상 전면 개편** (캘린들리+줌 → 구글 캘린더+미트) — 지금 실제로 고장나 있는 부분이라 최우선. 수업 취소/재예약/지각통보 기능도 여기서 같이 만든다(지금까지 예약 인프라가 없어서 못 만들었던 기능).
2. **선생님용 정산 화면** — 관리자는 이미 선생님별 정산 내역을 계산/지급 처리하고 있는데, 정작 선생님 본인이 자기 정산 예정 금액·히스토리·계좌 정보를 보는 화면이 없다. 이걸 만든다.
3. **관리자 운영 화면 4종** — 상담 관리, QC(선생님 품질 관리), 회사 문서 보관함(구글 드라이브 기반), 중간관리자(슈퍼바이저) 권한 체계. + 계약 화면에 선생님용 계약 서브탭 추가 + **계약서 서명을 DocuSign에서 구글 전자서명으로 전환**(파일도 구글 드라이브 저장으로 이관).
4. **포털 공통 계정메뉴** — 공지사항, 회원정보 변경, 관리자 문의, FAQ, 학원 정책 안내, 알림, 시간대 설정. 학생·학부모·선생님 포털 전부에 필요한 공통 기능이라 한 번에 만든다.
5. **학부모 포털 마무리** — 선생님 프로필+메시지 탭 추가, 통계 탭 추가, 홈 화면 위젯 수정. (예약 버튼이 잘못 노출되는 버그는 이 단계를 기다릴 필요 없이 언제든 먼저 고칠 수 있다.)
6. **선생님용 교재 화면** + 홈 대시보드 나머지 위젯.
7. **수업 세션뷰 — 보충 자료 탭** (선생님/학생이 파일을 올리고 공유하는 기능, 구글 드라이브 저장 기반).
8. **연습장 Docs 서브탭 → 구글 문서 임베드로 교체.**

## 5. 이번 계획에서 제외한 것 (검토는 했으나 안 하기로 한 것)

- 채팅을 Gmail로 전면 이관하는 것 — 이미 잘 동작 중이라 제외
