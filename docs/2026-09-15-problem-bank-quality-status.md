# 문제은행 AI 생성 품질 — 현황 요약 (2026-09-15 야간, 기획자 검토용)

## 오늘 고친 것 (전부 커밋·Preview 반영·non-prod DB 적용 완료)

**생성 파이프라인**
- 오답 자리별 구조화 계획 → 개별 생성(자리당 최대 2회, 병렬) — "네 오답을 한 번에 다시 쓰지 않는다"
- 보강 대기함을 좁게: 계약+독립검사 통과 + 잔여 오답 실패 1~2건일 때만, 요청 수 이하로 제한
- 어려움 문항 처리를 순차 → 동시 4개 병렬(속도 목표: 문항당 1분, 10문항 10분 — 달성)
- **정답-해설 대조**: 정답을 알려주지 않고 해설만으로 독립적으로 결론 선택지를 물어, 어긋나면 정답 자리를 해설 쪽으로 맞춤. **초안 저장 시점**에 실행(공개 시점 아님 — 생성 경로와 무관하게 모든 초안이 저장되는 순간 이미 정답이 맞아야 한다는 원칙)
- 해설로도 결론을 못 내리면(정답이 선택지에 아예 없는 경우) **저장 자체를 거부**하거나(수동 작성) 구조적 실패로 전체 재생성(AI 생성) — 관리자 검수 큐에 절대 노출 안 함
- 그림에 직선 두 개가 있고 교점을 묻는 문항은 실제 계산해서 정답과 대조(결정적, AI 불필요)
- "식 + 임계값 조건 두 개" 문항은 선택지를 직접 대입해 조건을 만족하는 게 정확히 하나인지 대조
- 선택지 자체가 그래프 4개인데 실제 그래프 없이 "Graph A" 텍스트로 때운 경우 거부
- 그림 라벨에 LaTeX 제어문("\ell")이 그대로 노출되는 경우 거부
- 선택지 문자열 안에 AI가 남긴 자기 라벨("B) …") 제거
- "그림 확인함" 수동 클릭 요구 제거(미리보기가 이제 항상 자료를 보여주므로)
- UI 버그 2건: 생성 중 무관한 버튼에 "공개 중…" 오표시, 표가 좌우로 잘리던 문제

**과목별 전체 교재 보기**(문제은행과 별개 기능, 오늘 완료)
- 과목→단원→키워드→자료 트리, 학생·교사·보호자 세 포털 전부 지원(보호자는 최초 구현)
- 자료 상세 화면 이전/다음 이동, HTML 교재 읽던 위치 저장

## 시도했다가 잠정 보류한 것

**어려움 수학 4단계 재구조화**(자료+문항 → 독립 풀이 → 오답 → 최종 검수): 정답을 생성 단계가 지어내지 않고 별도로 확정하자는 발상 자체는 맞지만, 실제로 5문항 돌려보니 0/5 통과(문항당 평균 295회 호출)로 아직 못 씀. 원인은 파악됨(자료 스키마 필드 누락, 선택지 표기 규칙 충돌, 교점 검사 오탐) — 코드는 남겨뒀고 다음에 마저 고쳐야 함. **지금은 기존 경로(오늘 낮에 개선한 것)를 그대로 씀.**

## 지금 수치로 아는 것

- 어려움 난이도 표본(6개 대표 유형 중 5개 확인): 최종 통과율 60~100%(유형별 편차 큼), 문항당 47~106초
- **Linear equations in two variables(좌표평면 필요) 유형은 여전히 저조**(초기 측정 10개 중 1개만 통과) — 별도 튜닝 필요, 오늘 손 못 댔음
- 오늘 실제로 새로 나온 오류(전부 위 목록으로 수정): 정답이 선택지에 없음, 정답 표시와 해설 불일치, 두 직선 교점 계산 틀림, "조건 만족" 문제에서 정답이 두 개, 그래프 라벨 깨짐, 그래프 선택형을 텍스트로 흉내

## 남아있는 위험(다음에 봐야 할 것)

1. **"그래프가 아예 틀린" 경우가 렌더러 자체 버그인지는 아직 미확인** — 오늘 나온 사례는 전부 AI의 계산 오류였고 렌더러 버그는 아직 발견 못 함. 다른 사례가 더 나오면 렌더러 코드도 봐야 함.
2. 위 4단계 재구조화 완성 여부 — 완성되면 어려움 수학 통과율이 더 오를 걸로 예상하지만 지금은 보류 상태.
3. 통합 테스트 병렬 격리(테스트 인프라 결함, 제품 결함 아님) — 계속 열린 항목.
4. `Linear equations in two variables` 등 특정 세부 기술의 낮은 통과율 — 유형별 개별 튜닝 필요.
