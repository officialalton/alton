# 커리큘럼 콘텐츠·수업 준비·세션 운영 설계

**상태:** 제품 오너 승인 (2026-09-07)  
**목적:** 즉석 AI 문제 생성에 의존하지 않고, 검수된 교재·문제를 커리큘럼과 학생별 진도에 맞춰 수업과 과제로 조합한다.

## 1. 결정

ALTON은 아래 네 층을 분리한다.

1. **콘텐츠 라이브러리:** 관리자만 문제·해설·교재 조각·키워드를 생성, 검수, 공개한다. AI는 관리자 콘텐츠 제작 화면에서 초안, 해설 보조, 태그 추천에만 사용한다. 수업 중 신규 문제 생성은 제공하지 않는다.
2. **기본 커리큘럼:** 과목과 레벨 아래에 단원, 권장 순서, 학습 목표, 키워드, 권장 교재 조각과 문제 묶음을 연결한 공통 원본이다.
3. **학생별 운영 커리큘럼:** 기본 원본의 사본이 아니라 추가·제외·재정렬·진도 상태를 담는 레이어다. 선생님은 검수된 라이브러리 콘텐츠로 학생 전용 보강 단원을 조립할 수 있다. 기본 원본과 다른 학생의 계획에는 영향을 주지 않는다.
4. **수업 준비·세션·과제:** 선생님은 수업 전 이번 회차의 활성 키워드와 사용할 콘텐츠를 고른다. 세션은 이를 기본으로 사용하며, 수업 중에도 검수 콘텐츠를 더 불러오거나 보강 단원을 추가할 수 있다. 과제는 새 문제 생성이 아니라 기존 문제의 조합이다.

## 2. 콘텐츠와 키워드

- 키워드는 과목별 공용 사전으로 관리한다. 자유 태그 입력을 기본 경로로 두지 않는다.
- 단원은 여러 키워드를 가진다. 교재 조각과 문제는 하나 이상의 공용 키워드에 연결된다.
- 교재는 단원 전체 문서가 아니라 키워드에 연결할 수 있는 작은 교재 조각으로 관리한다.
- 문제 역시 키워드에 연결한다. 세션의 문제 탭은 활성 키워드 칩을 보여 주고, 선택한 키워드 문제만 필터링한다.
- 키워드는 교재·문제·과제의 분류와 추천 기준이다. 학생 단어장을 자동 생성하거나 채우지 않는다.

## 3. 학생 개인 단어장

단어장은 커리큘럼 콘텐츠가 아니라 학생의 개인 학습 도구다.

- 학생은 수업 중 교재의 모르는 단어를 클릭해 자기 단어장에 추가한다.
- 정의, 예문, 암기 상태 등은 학생 개인 상태로 관리한다.
- 선생님은 단어장을 커리큘럼 키워드로 자동 구성하거나 편집하지 않는다.
- 세션의 교재·문제·과제는 활성 키워드를 쓰고, 단어장은 기존 개인 단어장 흐름을 유지한다.

## 4. 학생별 진도와 단원 변경

미래 세션 전체에 단원을 미리 고정하지 않는다. 학생별 운영 커리큘럼은 단원별 상태와 실제 진행만 원본으로 둔다.

단원 상태는 `미시작`, `진행 중`, `완료`, `보강 필요`, `건너뜀`이다. 시스템은 활성 키워드, 수업에서 사용한 콘텐츠, 과제 결과를 참고 정보로 제공하지만, 상태 전이는 선생님이 확정한다.

- 선생님은 기본 단원을 추가·제외·재정렬할 수 있다.
- 선생님은 라이브러리에서 다른 단원을 불러오거나, 검수된 교재·문제·키워드를 조합한 학생 전용 보강 단원을 만들 수 있다.
- 변경은 현재와 이후 수업의 추천에 반영한다.
- 시작 또는 완료된 세션의 콘텐츠 버전과 기록은 바꾸지 않는다.

## 5. 수업 준비와 세션뷰

### 수업 준비

선생님은 수업 전에 현재 단원, 권장 교재 조각, 핵심 키워드, 미사용 문제 수를 확인한다. 이번 회차에서 다룰 활성 키워드와 교재·문제를 선택한다. 준비 메모와 후보 상태는 선생님 내부 정보다.

### 수업 중

세션뷰는 `교재`, `문제`, `과제`, `단어장` 탭을 제공한다.

- 교재와 문제 탭은 같은 단원·활성 키워드 문맥을 공유한다.
- 문제를 실제 수업에 사용한 경우에만 사용 이력을 남긴다. 단순 열람은 사용 처리하지 않는다.
- 단어장 탭은 학생 개인 단어장으로, 커리큘럼 콘텐츠 후보나 선생님 준비 정보를 보이지 않는다.
- 수업 중 커리큘럼 조정 패널에서 검수 콘텐츠를 불러오거나 학생 전용 보강 단원을 추가할 수 있다.

### 학생 화면

학생은 확정되어 배정된 과제와 자신의 단어장만 본다. 선생님의 콘텐츠 후보, 내부 메모, 미공개 콘텐츠, 준비 중 커리큘럼 변경은 보이지 않는다.

## 6. 과제(모의고사) 조립

선생님은 단원과 활성 키워드, 총 문항 수를 선택해 과제를 만든다. 후보는 해당 키워드의 관리자 검수·공개 문제에서 고른다.

- 기본값은 수업에서 실제 사용 처리되었거나 학생이 답안을 제출한 문제를 제외한다.
- `수업 사용 문제 포함`, `학생이 이미 푼 문제 포함` 선택을 제공한다.
- 각 후보 문제에 사용 상태와 횟수를 보여 준다.
- 선생님은 자동 구성 후 문제를 교체·삭제하고 과제를 확정한다.
- 확정된 과제만 학생에게 공개한다.

## 7. 권한과 공개 경계

| 행위 | 관리자 | 선생님 | 학생 |
| --- | --- | --- | --- |
| 콘텐츠 원본 생성·검수·공개 | 가능 | 불가 | 불가 |
| 학생별 커리큘럼 조정·보강 단원 조립 | 가능 | 담당 학생만 가능 | 불가 |
| 수업 준비·내부 메모 | 가능 | 담당 수업만 가능 | 불가 |
| 과제 조립·확정 | 가능 | 담당 학생만 가능 | 풀이만 가능 |
| 개인 단어장 편집 | 불가 | 불가 | 본인만 가능 |

## 8. 구현 순서와 경계

1. 관리자 콘텐츠 라이브러리와 공용 키워드 사전, 검수·공개 상태를 설계한다.
2. 기본 커리큘럼의 단원·키워드·교재 조각·문제 묶음 연결을 만든다.
3. 학생별 운영 커리큘럼의 오버레이와 선생님 단원 조정 화면을 만든다.
4. 수업 준비에서 활성 키워드와 콘텐츠를 고르는 흐름을 만든다.
5. 세션뷰의 교재·문제 탭을 배정된 콘텐츠와 연결한다. 기존 학생 개인 단어장 흐름은 보존한다.
6. 문제 사용 이력과 과제 조립·확정·학생 풀이를 연결한다.

각 단계는 이전 단계의 원본·권한·상태를 직접 확인하는 통합 테스트를 포함한다. AI 문제 생성은 세션뷰에서 제거하거나 관리자 검수 대기 콘텐츠 제작 흐름으로 이관할 때까지 사용자에게 생성 기능으로 노출하지 않는다.

## 9. 명시적 제외

- 선생님의 원본 문제·교재 직접 공개
- 학생 단어장의 커리큘럼 키워드 자동 등록
- 시작·완료된 세션의 콘텐츠 재배정 또는 기록 수정
- AI 생성물을 검수 없이 수업·과제에 노출
- 미래 전체 세션의 단원·문제 고정 배정
