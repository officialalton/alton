# 구글 워크스페이스 전면 전환 + 전체 목업 갭 로드맵

## 배경

프로덕션에서 학생이 Calendly로 실제 예약을 확정해도 `sessions` 테이블에 전혀 반영되지 않는 버그를 추적하는 과정에서, 근본 원인이 코드 버그가 아니라 **Calendly 웹훅이 유료 플랜(개인 계정 기준 Standard 이상, 조직 계정 기준 Teams 이상)에서만 열리는 기능**이라는 걸 확인했다 — 즉 지금 구조로는 선생님이 늘어날수록 인당 비용이 발생한다.

이 문제를 계기로, 목업 초기 스펙 대비 실제 구현이 어디까지 왔는지 4개 포털(학생/학부모/선생님/관리자)+세션뷰를 병렬로 전수조사했고, 예상보다 훨씬 많은 화면이 누락되어 있는 것을 확인했다(아래 "전체 갭 인벤토리" 참조). 사용자는 이번 기회에 **스케줄링·화상회의를 포함해 관리자/선생님 계정 체계 자체를 구글 워크스페이스로 통일**하기로 결정했고, 남은 갭들도 이번엔 빠뜨리지 않도록 전체를 한 번에 계획에 포함해달라고 요청했다.

이 문서는 구현 계획이 아니라 **스코프 확정 + 순서가 정해진 로드맵**이다. 각 단계는 실행 시점에 별도의 스펙 문서와 구현 계획을 다시 거친다.

## 결정 사항 — 구글 워크스페이스 전환

- **관리자 + 선생님 계정**: 회사 도메인(`alton.education`) Google Workspace 계정으로 통일한다. 선생님이 온보딩되면 관리자가 회사 도메인 계정을 발급한다(현재의 "선생님이 자기 개인 Calendly 링크를 등록" 방식 폐기).
- **학생/학부모 계정**: 회사가 계정을 발급하지 않는다. 대신 **구글 계정 보유를 이용 조건으로 명시**한다 — 가입 시 본인 구글 계정(개인 Gmail 포함)이 필요하다고 안내한다.
- **스케줄링**: Calendly → **Google Calendar**(freebusy 조회 + 이벤트 생성) 기반 자체 예약 UI로 교체.
- **화상회의**: Zoom → **Google Meet**로 교체(Calendar 이벤트 생성 시 `conferenceData`로 Meet 링크 자동 생성).
- **계약/전자서명**: DocuSign → Google eSignature 전환 가능성 조사 완료(아래 참조) — **이번 로드맵에서는 결정 보류**, 계약 단계 스펙 때 다시 판단.
- **교육용 툴(구글 클래스룸 등)**: 조사 완료 — **사용 불가**(아래 참조).
- **메시지/드라이브**: 이번 전환 스코프에 포함하지 않는다. 기존 인앱 메시지(`chat_threads`)와 연습장(082 티켓, 진행 중)을 그대로 유지한다 — "구글 안에서 다 되니까" 라는 이유만으로 이미 잘 동작하는 자체 기능을 갈아엎지 않는다.

### 조사 결과 1 — Google eSignature (계약)

- Business Standard 이상 플랜에 **추가 비용 없이 포함**되어 있고(Business Standard/Plus, Enterprise Starter/Standard/Plus, Enterprise Essentials(+Plus), Education Plus), 서명자 최대 10명, 서명 순서 지정(순차/동시) 가능, 완료 시 감사 추적(audit trail) 자동 첨부.
- **결정적 제약**: 프로그래밍 방식으로 서명 요청을 생성하는 공식 API가 없다 — Google Docs/Drive UI에서 "Tools > eSignature"로 사람이 직접 눌러서 보내야 하는 구조. 지금 `contracts-actions.ts`가 DocuSign API로 자동 발송 + 웹훅으로 서명완료 시 학생 상태를 자동으로 `active`로 바꾸는 흐름(072 티켓)을 그대로 대체할 수 없다 — 이걸 Google eSignature로 바꾸면 관리자가 매 계약마다 수동으로 "서명 요청" 버튼을 눌러야 하고, 서명 완료 감지도 자동 웹훅이 없어 별도 폴링/수동 확인이 필요하다.
- **권장**: 계약 자동화 흐름이 이미 잘 동작 중이므로(문제 리포트 없었음), 이번 전환에서는 DocuSign을 유지하고 Google eSignature 전환은 스코프에서 제외한다. 나중에 관리자가 "수동 단계가 늘어나도 괜찮다"고 명시적으로 판단하면 그때 별도 스펙으로 재검토한다.

Sources: [Google Docs eSignature 안내](https://support.google.com/docs/answer/12315692), [Google Workspace eSignature 리소스 페이지](https://workspace.google.com/resources/esignature/)

### 조사 결과 2 — 교육용 툴(Google Classroom 등)

- Google Workspace for Education(Classroom 포함)은 **"정부 인증을 받은 K-12/고등교육 인가 기관으로서 국가/국제 공인 자격을 학생에게 수여하는 기관"**만 자격이 된다.
- 튜터링 센터/방과후 교육/기업 교육 기관은 **영리·비영리 여부와 무관하게 명시적으로 자격 제외 대상**이다.
- 즉 Alton은 Google Workspace for Education 자체를 신청할 수 없고, 따라서 **Google Classroom을 포함한 어떤 Education 전용 기능도 사용 불가**다. 쓸 수 있는 건 오직 일반 **Business 플랜**(Calendar/Meet/Drive/Docs/eSignature 등) 뿐이며, 이건 기존 계획(Calendar+Meet)과 이미 일치한다.

Sources: [Google Workspace for Education 자격 요건](https://knowledge.workspace.google.com/admin/getting-started/editions/qualifications-for-google-workspace-for-education), [Google Workspace 관리자 커뮤니티 — 개인 과외 교사 사례](https://support.google.com/a/thread/83618626)

## 로드맵 (실행 순서)

각 단계는 착수 시점에 별도 브레인스토밍→스펙→계획 사이클을 거친다.

1. **스케줄링/화상 전면 개편** — Calendly+Zoom → Google Calendar+Meet, 학생 취소/재예약/지각통보(021)도 함께. 지금 실제로 고장난 부분이라 최우선.
2. **선생님 정산 뷰**(074) — 관리자 정산 데이터를 선생님 시점으로.
3. **관리자 운영 탭 4종** — 상담(085)/QC(084)/문서(087)/슈퍼바이저(088) + 계약 탭 선생님 서브탭.
4. **포털 공통 계정메뉴 인프라** — 공지사항/회원정보변경/관리자문의/FAQ/학원정책, 알림벨, 시간대선택. 학생/학부모/선생님 3개 포털이 공유할 컴포넌트라 한 번에.
5. **학부모 전용 마무리** — 선생님 서브탭+메시지, 통계 탭, 홈 위젯 수정(4번 인프라 위에서 작업). **레슨 탭 예약버튼 노출 버그는 이 단계를 기다리지 않고 언제든 독립적으로 먼저 고칠 수 있는 1줄짜리 격리 수정.**
6. **선생님 교재 탭** + 홈 대시보드 남은 위젯.
7. **세션뷰 보충 자료 탭.**

## 스코프 제외 (이번 로드맵 범위 밖)

- Google eSignature 전환 — 위 조사 결과에 따라 보류
- Google Classroom/교육용 툴 — 자격 미달로 사용 불가, 재검토 불필요
- 메시지/드라이브의 구글 이관 — 기존 기능이 이미 동작 중이라 제외
- 082(연습장 실시간 공동편집)는 별도 트랙 유지, 이 로드맵에 흡수하지 않음
