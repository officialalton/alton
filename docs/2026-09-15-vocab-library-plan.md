# 단어장 재구성 — 1장 정리 (2026-09-15)

CLAUDE.md "새 기능 착수 전 1장 정리" 규칙에 따라 작성. 착수 전 확인이 필요한 세 가지(College Board 5,000단어 구축 방식·유사어/반의어/예문 품질 검증·교사 실시간 시험 방식)는 아직 결정되지 않아, 이번 라운드는 **그 세 가지를 뺀 나머지 전부**를 먼저 만든다.

## 1. 사용자 흐름
- 학생 포털·세션뷰 단어장 진입 → **단어장 / 시험** 두 탭.
- 단어장 탭: 좌측에 "내 단어장" + "College Board 1~10권" 목록 → 하나 선택 → 카드 목록(영어 기본, 한글 뜻 보기 토글, 뜻 가리기/단어 가리기 토글).
- 내 단어장: 단어 추가·수정·삭제. College Board 권: 읽기 전용.
- 시험 탭: "시험 만들기" → 단어장 복수 선택 + 문항 수 입력 → 4지선다(뜻 맞히기) 생성 → 응시 → 채점·저장 → 이력 목록(재응시 가능).

## 2. 데이터와 권한
- 기존 `vocab_words`(학생별 "내 단어장") 확장: `antonym_words text[]`, `example2 text` 추가. 이미 있는 `student_id`·RLS 그대로.
- 신규 `vocab_library_books`(1~10권, 전 학생 공용, 관리자만 관리 — 이번 라운드는 시드 데이터만) / `vocab_library_words`(권별 단어, 유사어 2·반의어 2·예문 2).
- 신규 `vocab_quizzes`(문항 배열을 jsonb 로 통째 저장 — owner_id 학생, source 는 어느 단어장을 골랐는지, status pending/completed, score/answers). RLS: 본인 것만 읽기/응시.
- **College Board 5,000단어 실제 채우기는 범위 밖**(구축 방식 결정 필요) — 이번엔 스키마 + 표본 데이터(1권 일부)만.
- **교사가 수업 중 즉석 시험을 학생 화면에 실시간으로 띄우는 것도 범위 밖**(실시간 채널 필요 여부 결정 필요) — 이번엔 교사가 만든 시험이 학생 단어장 화면에 "대기 중"으로 보이는 것까지만(새로고침 필요, 실시간 push 아님).

## 3. UAT 데이터
- 기존 세션 UAT 계정 재사용. 별도 실행 ID 불필요(신규 테이블, 기존 학생 데이터에 영향 없음).

## 4. UI 기준
- 목업 없음 — 기존 세션뷰·학생 포털 톤(카드, 라운드 버튼)을 따른다. 모바일 375px에서 카드 1열, 시험 문항 4지선다 세로 배치.

## 5. 검증과 성능

- 통합 테스트: RLS(다른 학생 단어장 접근 차단), 시험 채점 정확성.
