## M4 — 상담→체험→정규 전환 통합

### 완료된 것
- 상담 신청부터 계약 서명까지 관리자가 **하나의 화면(칸반 보드)** 에서 처리한다. 5단계:
  상담 신청 → 상담 일정 확정 → 체험 신청 → 체험 일정 확정 → **계약**.
- 선생님 배정도 이 화면 안에서 (과목 클릭 → 담당 가능 선생님 클릭) 방식으로 처리.
- 보호자가 "정규 진행 희망"을 누르는 순간 카드가 자동으로 "계약" 칸으로 넘어간다.
- **계약 서명이 완료되면 상담이 자동으로 종료 처리**되어 "지난 상담" 탭으로 이동한다(4가지
  종료 유형별 통계 자동 분류).
- 체험 수업 리뷰: 선생님이 카테고리별 의견을 작성하는 화면이 "정규수업" 탭(실제 수업
  목록)으로 옮겨졌다 — 리뷰를 공개 확정하면 그 수업이 "지난 수업"으로 넘어간다.
- 학생 프로필 완성(생년월일·학교·학년 필수 / SAT·GPA·AP과목·비교과활동·목표대학·관심전공
  선택) — 최초 로그인 직후 필수 단계로 추가.
- 상담·선생님 가용시간 등록 화면 전면 개선 — 같은 요일에 겹치지 않는 여러 시간대 등록 가능,
  Google Calendar 스타일 주간 그리드.
- 4개 포털(학부모/학생/관리자/선생님) 전부에 개인 시간대 설정 추가(서머타임 자동 반영).

### 이번 라운드에서 확정·반영된 정책(더 이상 결정 필요 아님)
- **학생 프로필**: 생년월일·학교명·학년 필수 / 나머지 선택(변경 없음). 생년월일은 학생
  최초 1회 입력 후 직접 변경 불가(기존 유지). **관리자 "확인 완료" 버튼**을 추가해
  확인자·확인시각만 기록(복잡한 신원확인 절차 없음) — **체험수업권 지급 전에 이 확인이
  완료돼 있어야 한다**(게이트 추가). SAT 미입력은 0이 아니라 **null**로 저장(기존 0인
  데이터는 실제 0점인지 미입력인지 구분 불가해 오픈 전 상태를 전제로 그대로 보존, 앞으로의
  입력만 구분). GPA는 척도(4.0/4.3/4.5/5.0)를 함께 저장.
- **체험 리뷰 카테고리 5개(학업 태도/이해도/참여도/과제 이행/종합 의견)**: 현행 유지
  확정. 체험 단계에서 정규수업 리뷰 형식을 미리 보여주는 것이 목적이며, 운영 이력이 없어
  스냅샷·버전관리는 만들지 않는다.
- **학생 이메일/초대 흐름**: 기존 설계(prospect 이메일=보호자 계정 이메일, 학생 이메일은
  체험 전 필수 입력 후 비밀번호 설정 초대로 검증) 그대로 확정 — 재설계 없음. 이번엔 운영
  누락만 보완: 상담 칸반 온보딩 폼에서 필수값이 비었거나 이메일 형식이 틀리면 발송 버튼이
  비활성화되고 서버에서도 재검증한다. 발송 실패는 관리자 화면에 실패 배너로 노출된다.
  재발송해도 중복 계정은 생성되지 않는다(멱등).

## M5(R7) — 수업 상태·출석·정산 근거

### 완료된 규칙
- 24시간 전 취소 → 수업권 안 빼고 선생님한테도 안 줌
- 24시간 안 남기고 학생이 늦게 취소 → 수업권 1장 소진, 선생님 120분치 지급
- 수업 시작 15분 지나도 학생 안 들어오면(노쇼 확정) → 수업권 1장 소진, 120분 지급
- 학생 지각(그래도 결국 들어옴) → 예정 종료 그대로, 수업권 1장 소진, 120분 지급, 보충 없음
- 선생님이 늦게 들어온 경우 → 당일 즉석 합의로 연장 가능, 부족하면 "보충시간"으로 남김
- 선생님 사유로 실제 제공 시간이 90분 미만이면 → 자동으로 품질관리(QC) 경고
- 회사·Meet 장애로 아예 시작 못함 → 수업권 원상복구, 정산 0분, 재예약 가능
- 회사·Meet 장애로 중단됨 → 못 준 시간만큼 보충시간 + 정산은 120분을 넘지 않게 상한

### 이번 라운드에서 발견·수정된 실제 버그
**정산 과지급 버그** — 선생님 지각이나 장애로 늘어난 수업 시간이 그대로 지급 대상에
반영되고, 그 미이행분이 나중에 다른 수업에 보충으로 이관되면 원 수업과 보충 수업 양쪽에서
각각 전액이 지급돼 **이중 지급**이 될 수 있는 구조였다. 실제 제공 시간 기준으로 다시
계산하도록 수정했고, 아래처럼 귀책별로 정확히 120분 상한이 걸리는지 전부 테스트로 재확인
완료:
- 선생님 귀책, 원 수업 110분 제공 + 나중에 보충 10분 = 총 120분 지급
- 선생님이 당일 10분 연장해 120분을 다 채움 = 총 120분 지급(보충 채무 자체가 안 생김)
- 선생님 귀책 보충으로 인한 총 지급이 120분을 넘지 않음
- 회사·Meet 장애 중단 시 원 수업+보충 합계도 120분 상한 준수
- 보충시간을 예약에 "붙였다"는 사실만으로는 지급 안 됨(실제 완료 판정 후에만 반영)

### 이번 라운드에서 확정된 정책(더 이상 결정 필요 아님)
- **보충시간 만료**: 발생 후 **30일**. 발생시킨 선생님의 미래 정규수업에만 적용 가능,
  선생님이 바뀌어도 새 선생님에게 승계되지 않음. 만료 기한은 어떤 사유로도 연장되지
  않는다(연장하려면 관리자가 새로 등록).
- **재판정(잘못된 최종판정 정정) 시 수업권 처리**: 완전 자동화 대신, 재판정 전/후 필요한
  수업권 조정 내용을 시스템이 자동으로 계산해 "대사 작업"으로 만들어두고, 관리자가 확인 후
  한 번에 반영하는 방식으로 개선했다(중복 반영 방지 포함). 이미 지급된 정산은 즉시
  수정하지 않고 나중에(R10 단계) 역분개 처리 대상으로만 표시해둔다.
