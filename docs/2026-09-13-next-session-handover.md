`20261317000000`으로 세 계층을 이었다:

  화면을 여는 것만으로 임시 예약이나 수업 기록을 만들지 않는다(6절).
- 공용 구성 패널 — 키워드 붙이기/떼기, 교재 담기·빼기·순서, 자동/직접 구분,
  키워드로 들어올 **문제 미리보기**(관리자·선생님 층은 미리보기 전용).

  예정 수업 카드, 수업 화면 머리말. **이름은 전부 `수업 준비`**.
  `수업 열기`·`수업 시작`은 다른 동작이라 이름을 유지했다.

- **문제 자동 구성의 편집.** 문제 선택은 학생별 운영본에만 있다

  문제 층을 둘 것인지가 정해지지 않았다 — 정하기 전에는 미리보기로 둔다.
- **AI 생성·문제 구성 조건·명시적 재구성**이 이 패널에 아직 붙지 않았다.

## 2. 유지해야 할 확정 정책

- **자동 공개 없음**: 문제는 손으로 쓰든 AI가 만들든 draft로 들어오고, 검수 요청과
  공개를 사람이 누른다. 초안에는 공개 버튼이 렌더되지 않는다.
- **보관은 숨김이지 삭제가 아니다**: 신규 선택·자동 구성 후보에서만 빠지고, 기존
  연결과 과거 기록은 그대로 조회된다. 보관 때문에 과거 수업을 못 열면 안 된다.
- **초기 상속은 자동, 보정은 수동**: 회차를 처음 만들 때는 관리자 기준본이 자동으로
  내려온다. 이미 있는 회차를 나중에 채우는 것은 선생님이 눌러야 한다.
- **자동 갱신이 사람 손을 덮어쓰지 않는다**: `source=manual`과 제외 기록, 선생님이
  맞춘 순서는 자동 동기화가 건드리지 않는다.
- **과거 기록은 소급해 고치지 않는다**: 과거 수업의 `material_section` 매니페스트
  행은 그대로 읽는다. 정책이 바뀌었다고 과거의 사실을 바꾸지 않는다.
- **서버 액션은 예외를 던지지 않는다**: `{ ok, error }`로 돌려준다. 던진 예외는
  Production에서 Minified React error로 마스킹돼 사유가 사라진다.
- **내부 오류·ID·기술 상태값을 화면에 노출하지 않는다.**
- 관리자 문서 경로(회사 문서·preflight·교사 제출 서류)는 `requireAdmin()`.
  비관리자는 capability가 있어도 거부된다.
- Production 활성화, Wise 실송금, `CRON_SECRET` 설정은 하지 않는다.
- 다른 세션의 미커밋 변경을 대신 조작하지 않는다.

### 2026-09-13 추가 확정 — 준비와 수업 화면 통합

이번 지시로 확정됐다. 아래와 충돌하는 이전 기술은 이쪽이 우선한다.

- **모든 계층에 회차 키워드와 기본 구성이 이어진다**: 관리자 기준본 → 선생님 기본
  템플릿 → 학생별 운영본. 선생님이 같은 키워드를 다시 지정하는 흐름을 두지 않는다.
- **별도 '회차 준비' 페이지를 없애고 준비 기능을 세션뷰 안으로 통합한다.** 모든 진입
  버튼 이름은 `수업 준비`로 통일한다. 진입 위치는 관리자 과목 템플릿의 각 회차,
  선생님 과목 템플릿의 각 회차, 선생님 학생별 과목 템플릿의 각 회차, 예정 수업 카드.
  기존 URL도 회차·편집 대상·수업 문맥을 유지해 통합 화면으로 연결한다.
- **세 계층은 같은 UI를 재사용한다.** 상단에 `관리자 기준본 / 내 기본 구성 / ○○ 학생`과
  과목·회차를 표시해 수정 대상을 분명히 한다. 관리자·선생님 기본 화면은 교재·문제를
  미리보고 기본 구성을 편집하고, **실제 예약·수업 시작·학생 답안·수업 기록은 학생별
  문맥에서만** 다룬다.
- **자동 구성·연결이 기본 흐름이다.** 매번 '기본 구성 가져오기'·'담기'·'수업에
  연결하기'를 눌러야 하는 필수 단계를 두지 않는다. 문제 목록은 저장하며 화면 진입마다
  바뀌지 않는다. 수동 조정과 하위 개별 구성은 자동 갱신으로 덮어쓰지 않는다.
- **예약 없이 진입하고, 실제 수업 시작 때만 고정한다.** session ID나 예약이 없어도
  회차 기준으로 `수업 준비`를 열 수 있어야 하고, 화면 진입을 위해 임시 예약이나 실제
  수업 기록을 만들지 않는다. 화면 진입·준비 저장·예약 연결은 수업 시작이 아니다.
  실제 `수업 시작`에서만 최신 구성과 교재·문제 버전을 한 번 고정한다. 같은 회차를
  여러 수업에 써도 수업별 스냅샷·필기·풀이는 분리한다.
- **역할·필기 정책 유지**: 학부모에게 구성 편집과 교사 전용 초안을 노출하지 않는다.
