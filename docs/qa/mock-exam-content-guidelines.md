# 모의고사·문항 콘텐츠 작성 가이드 (오너 확정 2026-10-02)

새 문항을 만들거나 가져올 때 반드시 지킨다. 어기면 생성·임포트 게이트가 거부한다.

## 언어
1. **학생 화면은 영어가 기본**이다(응시·결과·참조표·신고 양식·버튼). 한글은 해설 토글로만 제공한다.
2. **지문·질문·선택지는 영어만**. 한글이 한 글자라도 있으면 거부(`findResidue`, 조립 후보 제외).
3. **해설은 두 벌**: `explanation`(한국어 3~5문장) + `explanation_en`(같은 내용의 영어 3~5문장, 한글 없음, 학생에게 설명하는 어조).
   - 결과 화면은 영어 해설이 있으면 영어를 기본으로 보여주고 `English | 한국어` 토글을 제공한다. 영어가 없으면 한글만 나온다 → **새 문항은 영어 해설 없이 만들지 않는다.**
   - 생성 단계(세션 모드·API 모두) 출력 스키마에 `explanation_en`이 필수이며, 없거나 한글이 섞이면 탈락한다. 임포트는 `explanationEn`을 `p_explanation_en`으로 저장한다.

## 텍스트 표기
4. 금액은 `$45`로 쓰지 말고 `45 dollars`로 쓰거나 `\$45`로 이스케이프한다(`$…$`는 수식 구분자). 렌더러가 방어하지만 데이터에서 지킨다.
5. 지문(`passage`)에 질문 문장을 복사해 넣지 않는다. 자극 자료가 없는 수학 문항은 지문을 비워 둔다(임포트의 `dedupeStem`이 중복은 걸러 준다).
6. 해설의 선택지 참조는 글자(A~D)로만 한다.

## 도형·그래프
7. 표기된 각도·길이와 그림이 어긋나지 않게 그린다(같은 값 = 같은 픽셀 길이). 높이·지름·반지름은 양끝 눈금이 있는 치수선으로 표시한다.
8. 좌표평면의 축 이름 `x`, `y`는 화살촉과 눈금에 가리지 않게 굵게 표시한다.

## 확인 절차
- 새 배치는 임포트 전에 `scripts/qa/check-explanation-en.py` 류의 자동 검사(한글 잔존·수식 보존·숫자 보존)를 통과시킨다.
- 시각 자료가 있는 문항은 시각 검수 게이트(G9)를 거친다.
