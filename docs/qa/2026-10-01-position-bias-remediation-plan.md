# 기존 원격 문항 정답 위치 편향 교정 계획 (문서만, 미실행)

작성 전제: 원격 접근·실행 없음. 원문은 로컬 `final/passed.json`에서 가져온다. 실제 원격 반영은 총괄이 한다.

## 1. 문제
mock_exam 520, general 908 등 기 임포트 문항의 정답 위치가 치우쳐 있다(RW A 약 48%, D 약 5%). 풀 전체의 위치 분포가 곧 조립 세트·학생 시험의 분포가 되므로 추측 전략으로 점수가 오염된다.

## 2. 교정 방식(문항 단위)
1. 대상 선별: 선택지가 숫자·단위·오름차순 관례(Math 숫자형)이거나 선택지 안에 글자 토큰이 있는 문항은 제외. 나머지가 대상.
2. 목표 위치 배정: 섹션(RW/Math)·skill 단위로 A~D 회전 배정(`diversity.ts targetLetterFor`, 채택 59건에 쓴 `shuffle-adopted.ts`와 같은 방식). 전체 분포를 25% ±5%로 수렴.
3. 재배치: 정답만 목표 위치로 옮기고 나머지는 상대 순서 유지(`reorder`). perm 기록.
4. 해설 글자 치환: 해설의 선택지 글자 참조를 새 순서로 치환(`remapExplanation`). 글자 참조가 없는 문항은 결정적 섞기만.
5. 재검증: 글자 참조가 있던 문항만 Fable·Opus 블라인드 풀이 + 해설 일치 감사. 실패하면 원래 순서로 되돌리고 교정 제외로 기록.
   - 비용: 문항당 약 $0.14(동기). 대상 중 글자 참조 비율을 채택 59건에서 본 값(약 78% 대상 중 전부)으로 보수적으로 잡으면 mock_exam 520건 약 $55, general 908건 약 $95. 참조 없는 문항은 API 비용 0. 배치 API면 절반.
   - 대안(저비용): 글자 참조가 있는 문항은 해설의 글자를 "이 선택지"식으로 일반화하지 않고, 치환 후 Sonnet 감사 1회만($0.02/건) + 10% 표본을 Fable·Opus로 검증. 권장은 전수 Fable·Opus가 아니라 "치환 규칙 정확도를 채택 59건 결과로 먼저 측정 → 오류율이 낮으면 표본 검증" 이다.

## 3. 원격 반영 방식
전제 확인 필요: 문항 버전 불변 규칙(`problem_versions` 불변)과 조립 세트·응시 스냅샷.
- 권장: **전용 정의자 RPC**(`review_problem_difficulty`와 같은 패턴, 예: `reorder_problem_options(problem_id, version_id, new_options, new_correct_index, new_explanation, perm, run_id)`).
  - 새 버전을 만들면 `current_version` 교체로 이미 조립된 세트 문항이 바뀌거나 스냅샷이 갈라질 수 있고, 버전 수가 늘며 검수 이력이 끊긴다. 선택지 순서는 동일 문항의 표현 교정이므로 제자리 갱신 + append-only 이력 테이블(`problem_option_reorder_history`: 이전·이후 options/correct/explanation, perm, run_id)이 맞다.
  - 불변 트리거는 RPC 안에서만 우회하도록(난이도 RPC와 동일) 하고, 호출자는 service role/관리자로 제한.
- 조립 세트: 조립은 문항 **스냅샷**을 세트에 복사하므로 이미 만든 세트·응시 기록의 스냅샷은 영향 없음(난이도 변경이 스냅샷을 바꾸지 않는 것과 동일 원칙). 단 아직 응시 기록이 없는 draft 세트는 새 순서를 반영하려면 재조립이 필요. 이 전제는 마이그레이션 작성 전에 조립 코드에서 재확인한다(이 문서는 코드 확인 결과가 아니라 난이도 RPC 설계 기준의 전제).
- 새 마이그레이션이 필요하므로 이 세션은 만들지 않는다. 총괄 승인 후 별도 작업.

## 4. 실행 순서(제안)
1. (로컬) 대상 선별·재배치·치환 산출물 생성, 분포·치환 통계 보고.
2. 채택 59건 결과로 치환·재검증 통과율 확인 → 재검증 범위 결정.
3. 재검증 배치 실행(상한 승인 필요).
4. 총괄이 RPC 마이그레이션 → 비프로덕션 적용 → 산출물 적용 → 분포 쿼리로 확인.
5. 응시 기록이 있는 문항은 제자리 갱신 대신 건너뛰고 별도 목록화(스냅샷은 보존되나 통계 해석 혼선 방지).

## 5. 위험
- 해설 글자 치환 오류(관사 "A", 따옴표 안 글자, "Choice A and B" 류): 재검증과 표본 검수로 제어. 이번에 "A is/and" 류를 참조로 인식하도록 규칙 보강.
- "모두/위 중 없음" 류 선택지, 지시 선택지 순서 의존 문항: 대상에서 제외하도록 선별에 키워드 규칙 추가 필요.
- 숫자 선택지 Math는 교정 불가 → Math 분포는 생성 단계 목표 위치 주입(사전 수정 1)으로만 해결. 기존 Math 편향은 일부 남는다.
- 원격 반영 중 동시 조립·응시: RPC에서 행 잠금, 응시 기록 존재 여부 검사.
