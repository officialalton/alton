## A. 지금 — 2026-09-14 야간 배치 Preview UAT (UAT 대기)
1. 문제은행: 유형 고르고 `AI로 만들기`(난이도) → 초안 미리보기(수식·표·**도형 SVG**) → `그림 확인함` → `전체 공개`.
2. 수업 준비에 담기 → 수업 화면에서 **SPR 숫자 답 저장 → 교사 `채점 완료` → 정답·해설 열림**, 목차 정답/부분/오답·점수.
3. 과제: 교사 발급(풀에서 체크, 회수) → 학생 포털 과제 탭(수업별 탭) → 풀이 → 채점. 수업 문제와 답·필기 **분리** 확인.
4. 문제 화면 전체 필기(교사·학생, 과제 탭 포함) / PDF `T 텍스트`·`전체 지우기` / 창 크기 변경 뒤 필기 유지 / 연습장 실시간.
5. 진행 중 수업 `수업 구성 변경`. 학생 `수업 준비` → 수업 화면. 커리큘럼 회차 키워드 칩.
6. 관리자 `교재` 탭(키워드별/단원별/목록), `노출용 이름`, `Drive 원본 없는 교재 보관 (전체)`, `과목 자료 동기화`.
7. (P3 10차) 문제 화면 클릭 정상 / 서술형 글 상자 저장 → 교사 채점 / PDF T 상자 크기 / 수업 준비 후보 문제 클릭 미리보기 / 키워드 20개 넘는 회차에서 자동분 20개만 들어오는지.
8. 이전 배치에서 UAT 대기로 남은 것: P0-2(관리자 키워드 저장 재확인), P0-5(다자녀 정규 진행 동의), P0-6(지인 추천 다자녀 매칭), P1 체감 성능(느린 계정 실측).
