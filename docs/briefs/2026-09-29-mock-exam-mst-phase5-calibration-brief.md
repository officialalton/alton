# 모의고사 적응형(MST) Phase 5 — 캘리브레이션 브리프

> **범위 변경 (2026-09-29, 오너 확정)**: 자동 보정·자동 제안·주간 자동 집계·모델 자동 교체는 만들지 않는다. 구현 범위는 (1) **관리자 전용 통계 화면** — 아래 '지표' 1~6을 표시하고 표본 30건 미만이면 '표본 부족' 표시, 목표 구간(30~50%)·경고(70~80% 초과)를 시각적으로 강조, (2) **관리자 임계값 조정** — 섹션별 새 version 발행(이력: 누가·언제·이전 값), 진행 중 응시는 시작 때 고정된 버전 유지. 판단과 조정은 관리자가 한다. 점수 모델 앵커는 UI 없이 코드 상수로 필요할 때 교체한다. 아래 본문은 지표 정의 참고용이며 '주기'·'제안서 템플릿' 항목은 범위에서 제외.


작성: 2026-09-29. 기준: `docs/2026-09-28-sat-adaptive-mock-exam-redesign-plan.md`, Phase 2~4 브리프(`2026-09-29-mock-exam-mst-phase2-brief.md`). 현재 라우팅: 두 섹션 모두 M1 정답률 **0.70 이상 -> higher**(정책 v2, 제품 오너 확정 2026-09-29, 마이그레이션 `20261930000000`).

## 목표
- **어려운(higher) 경로 비율 30~50%**를 목표 구간으로 한다(섹션별 각각).
- **한쪽 경로가 70~80%를 넘으면 임계값을 조정한다**: higher가 80% 초과면 임계값을 올리고, lower가 80% 초과(higher 20% 미만)면 내린다. 70% 초과~80%는 경고(다음 주기 재측정), 80% 초과는 조정 후보로 오너에게 보고.
- 응시 데이터가 쌓인 뒤 예상 점수 모델(`lib/mock-exam/score-estimate.ts`, 현재 v0-linear)을 교체하고 **과거 attempt 점수는 불변**으로 둔다.

## 선행 조건
- 표본: 섹션당 **완료(graded) MST 응시 30건 이상**일 때만 임계값 제안(미만이면 "표본 부족" 표시만). 보충 실사용이 적은 동안은 UAT·내부 테스트 응시를 제외(계정 구분).
- 문항 풀 충족: `docs/qa/2026-09-29-mock-exam-pool-requirement.md`의 R&W 부족분이 해소되기 전에는 캘리브레이션 결과가 문항 구성 편향에 오염되므로 해석하지 않는다.

## 수집 항목 (응시 완료마다, 이미 있는 것 우선)
- 섹션별: M1 정답 수/문항 수, 경로(`rw_m2_route`/`math_m2_route`), 정책 버전(`*_route_policy_version`), M2 정답 수, 모듈별 소요 시간.
- 문항별: 응답, 정오, 소요 시간, 문항 난이도 라벨·skill·영역, 세트·모듈·경로 변형(`problem_response_stats` 활용).
- 집계 전용 뷰(관리자·service_role만): 학생·보호자 JWT에는 경로·난이도·정책 일절 비공개(Phase 3·4 비노출 원칙 유지).
- 학생 식별 최소화: 집계는 학생 단위 중복 응시(재응시)를 별도 표시, 첫 응시만 분포 계산에 사용.

## 지표 (섹션별)
1. 경로 분포: higher 비율 = higher 수 / 전체, 정책 버전별.
2. M1 정답률 분포(히스토그램 5%p 구간)와 임계값 주변 밀집도 - 임계값 +-5%p에 몰려 있으면 경계 민감도 경고.
3. M2 난이도 적합도: 경로별 M2 평균 정답률(목표 lower 60~75%, higher 40~60%) - 벗어나면 문항 난이도 라벨·풀 재검토.
4. 문항 품질: 문항별 정답률·변별도(상위/하위 27% 정답률 차) - 변별도 0.1 미만·정답률 10% 미만/95% 초과는 검수 후보.
5. 소요 시간: 모듈 시간 소진율, 시간 초과로 미응답 비율.
6. 점수 모델: 원점수 -> 예상 범위의 경로별 분포 일관성(동일 원점수가 경로별로 크게 갈리면 모델 보정 대상).

## 주기
- 주 1회 자동 집계(관리자 전용 화면 `문항 풀`/MST 분석 서브탭 또는 리포트), 월 1회 임계값·모델 검토 회의 자료화.
- 임계값 변경은 항상 **새 version**(`mock_exam_set_routing_policy`), 이미 시작한 응시는 시작 때 고정된 버전 유지(불변 규칙). 변경 전후 비교를 위해 버전별 지표를 분리한다.

## 산출물·완료 기준
- 관리자 읽기 전용 분석 화면(또는 SQL 리포트)과 위 지표 계산의 테스트(순수 함수 + 통합).
- 임계값·모델 변경 제안서 템플릿(현재 값, 표본 수, 분포, 제안 값, 예상 영향, 롤백 방법).
- 학생·학부모 권한 통합 테스트로 새 집계 경로에서도 경로·난이도가 새지 않음을 재확인.

## 결정 필요(오너)
- 표본 임계 30건이 적절한지(현재 실사용 규모 대비), 목표 구간 30~50%의 섹션별 차등 여부, 조정 주체(자동 제안 + 오너 승인).
