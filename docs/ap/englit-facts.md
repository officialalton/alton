## 2. 앱 구성으로 옮긴 규칙 (`lib/ap-exam/englit-rules.ts`, 하한 내림·상한 올림 관용)
- MC 55 = 정확히 5묶음, 묶음 8–13문항, 한 묶음은 한 장르, 연속 위치. 장르 문항 수: 단편 23–27 / 시 19–25 / 장편·희곡 8–10. 산문 묶음(단편+장편) ≥ 2, 시 묶음 ≥ 2.
- 7범주 범위(55문항): 인물 8–11 / 배경 1–4 / 플롯·구조 8–11 / 서술자·화자 11–15 / 어휘·이미지·상징 5–8 / 비교 5–8 / 논증 5–8. 목표(제안): 10·2·10·13·6·7·7.
- FRQ 3 = q1 시 분석 · q2 산문 분석 · q3 문학 논증 각 1. 풀 시험 레이아웃: MC 60분 + FRQ 120분(`lib/ap-exam/layouts.ts`).

## 3. UNVERIFIED / 열린 항목
1. **MC 지문 길이·줄 수·문항 순서**: 공식은 묶음 크기(8–13)와 장르 최소 개수만 공표한다. 지문 단어 수(시 100–330, 산문 480–800)는 CED 샘플(시 FRQ 100–400단어, 산문 FRQ 600–800단어)에서 정한 **내부 가정**이다.
2. **줄 번호 표기**: 공식 샘플은 5줄마다 번호를 표시하고 문항은 "lines 21–27" 식으로 가리킨다. Bluebook 의 디지털 표시(줄 번호 위치·접기 방식)는 직접 확인하지 못했다 — 앱은 5줄마다 번호를 표시하고, 산문은 56자 폭으로 접은 줄을 센다.
3. **Q3 작품 목록의 실제 구성**: 공식 목록(약 40편)은 해마다 다르고 직접 대조하지 않았다. 앱의 목록은 ALTON 이 고른 실제 출판 작품 40편(제목·저자 고정)이며 공식 목록이 아니다.
4. Row B 의 공식 문구 전체와 Q별 Decision Rules 는 [ced] p.153–161 에서 읽었으나, 앱의 루브릭 문안은 ALTON 요약이다(공식 문구 복제 아님). 공식 SG(Scoring Guidelines) 최신 해와 문구가 다를 수 있다 — VERIFY.
5. 에세이 길이 제한·붙여넣기·맞춤법 자동 고침 정책(Bluebook): 미기재.
6. 단원별 차시(CED: ~10 / ~17)는 참고용 라벨.
