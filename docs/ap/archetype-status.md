## bio data_short v2 (Bio 데이터 해석 + 정량 분석 번들)
- 상태(2026-10-08 갱신): **수정 후 재검증 대기 (usable/validated 아님)** — 아래 v9 결과는 `v9-bio-data-short` 버전 증거로 보존. 직전 표기 "usable (조건부 검증)" 은 철회 — 구성 동결 실행 v9-bio 첫 통과 3/4. 반복 개선 없이 이 상태로 기록한다.
- 근거: 동결 구성 `config/ap-frozen/bio-data-short.v9.json`(해시 일치 후 실행, 수선 없음, 새 시드 4개 2000~2003). 결정적 게이트 4/4, 번들 전체 검토 통과 3/4(k1·k2·k3). 비용 $0.212 / 상한 $0.4.
- 부분 통과를 번들 검증으로 세지 않는다: 통과한 3건은 번들 전체(A~D+참조 검사+5기준 검토) 통과 건이다.
- 실패 1건(k0, 품질 거절): D 모범 답안에 70 °C 문항과 무관한 "too cold" 기전이 섞이고, 단일 설명 루브릭이 "denaturation만" 답을 받는지 불명확. 설계 결함 가능성 -> 무료 보완 후보(D 모범답안 온도 방향 분기, 루브릭 문구). 이번 라운드에서는 수정·재검증하지 않음.
- 하네스·도구·파싱 오류: 0건. 무효 측정: v8-bio-r (승격 근거 제외, `validity.json`).
- 개념(토픽 3.2) 증거는 D 파트만. A~C는 데이터 기술로만 집계.

## v10 수정(무료, 유료 검증 미실행)
- D 모범 답: 온도 방향에 맞는 기전 분기(낮은 수준이 최적보다 뜨거우면 변성, 차가우면 충돌 감소). 방향 불일치는 설계 검사 `temp_direction_mismatch` 로 차단(단위 테스트 4건).
- D 루브릭(승인된 단일 설명 규칙 유지): 증거(값)+기전을 한 설명으로 연결해야 1점. 변성 용어는 모양/활성 부위 변화의 표현으로 인정하되 **값 인용 없이 'denaturation' 만 쓰면 0점**(common_errors 에 명시). 방향이 맞지 않는 기전도 오답.
- 무료 검사: 신규 시드 120개 모두 통과. 새 동결 구성 `config/ap-frozen/bio-data-short.v10.json`(v9 구성은 이제 해시 불일치 -> 실행 중단, 의도된 동작).
- 기존 통과 항목 영향: k1·k2·k3(v9), v8 4건은 온도 방향 결함 없음(catalase 아님). k0 만 결함. 루브릭 문구 모호성은 구버전 전체에 해당하지만 해당 항목들은 구버전 문구로 통과했으므로 버전 증거로 보존하고, v10 검증에는 포함하지 않는다.
