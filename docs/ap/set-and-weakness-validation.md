# 세트 검증 · 약점 분석 검증 기준

## 1. 세트(풀 모의·MC 연습) 검증 — 공개 게이트
- **공식 기준 일치**: 단원 비중(과목별 공식 범위), 스킬 비중(예: Calc MC P1 50–70 / P2 15–30 / P3 10–20; Micro 스킬1 30–42 / 스킬2 37–47 / 스킬3 16–25, 수치 20–30%), 섹션·시간·배점·허용 도구(계산기 파트). 공식 범위 밖인 비중은 `internal_proposal`로 표시하고 오너 승인 전 사용 금지.
- **번들 완전성**: 세트 문항(MC 자료 세트)·FRQ 파트는 구성원 전부 포함, 루브릭 행 전부 연결. 일부만 있는 번들은 공개 불가.
- **세트 간 중복 0**: 동일 문항·번들·자료 재사용 금지(기존 `assemble-unique` 원칙 확장). 유사 문항(숫자만 다른 변형) 비율 보고.
- **고난도 편중 없음**: 난이도 잠정값 분포가 `exam_prep` 중심이고 `advanced_supplement` 비율 상한(예: 15%)을 넘지 않음. 정답 위치 분포 균등.
- **라벨**: 풀 구조 충족 시에만 Full Practice Exam. 미충족은 MC/FRQ Practice.
- **채택 상태**: 모든 문항 `adopted + human_reviewed`. 한 건이라도 미검수면 세트 공개 불가.
- 비공식 가중(내부 제안)은 데이터에 `weight_source='internal'`로 구분, UI에서 "official"로 표시 금지.

## 2. 약점 분석 검증
- **단원별과 스킬별을 분리 집계**(단원 약점 ≠ 스킬 약점). 둘 다 표시.
- **한 문제 오답으로 약점 판정 금지**: 최소 근거 문항 수(예: 단원/스킬당 ≥4문항, 정답률 임계 이하)를 만족해야 "weak" 표시, 미만은 "More practice needed to tell". 모든 약점 카드에 **근거 문항 수**(예: "missed 3 of 5") 표시.
- **FRQ**: 루브릭 행 감점을 파트 스킬에 연결해 스킬 약점에 반영(자기 채점/전문가 채점 한정; AI 참고 점수는 약점 판정에 사용 금지).
- **연결**: 약점 카드 → 오답노트(My Notebook 필터: 프로그램/과목/단원/스킬) → 같은 단원·스킬 후속 연습(MC Practice 자동 구성) → 상담 CTA(약점 컨텍스트 전달).
- **검증 테스트**: 단원·스킬 집계 단위 테스트(경계: 3문항 미만, 이중 집계), FRQ 감점→스킬 매핑 테스트, 표시 근거 수 DOM 테스트, 비채점 응시·미응시 제외.
