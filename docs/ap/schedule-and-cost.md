# AP 일정·비용 개략 (실측 전 추정, 승인 필요)

> **Phase 1b 갱신 절이 샘플 비용·일정을 대체한다.**


## 순서 제안(10과목 모두 포함, 제외 없음)
근거: 시험 구조 단순성·검증 자동화 가능성·수요·변경 위험.
1. **샘플 3과목: Calculus AB → Microeconomics → Biology** (검증 방식이 각각 계산/그래프 논리/자료·설계 대표 유형). 파이프라인 3종 검증.
2. **1차 확장(결정적 검증 강점)**: Calculus BC(AB 재사용), Macroeconomics(Micro 재사용), Physics 1, Chemistry.
3. **2차 확장(검증기 신규 필요)**: Computer Science A(Java 실행 샌드박스), Statistics(2027 신규 CED 안정화 확인 후), English Language(에세이 3종, 가장 주관적 — AI 채점 참고 피드백 한계 큼).
- Statistics는 대개편이라 신 CED 해설서·샘플 문항 공개를 확인한 뒤 착수. 영어 언어는 FRQ가 55%라 MC-only 제공 라벨 엄수.

## 일정(1인 개발+오너 검수, 주 단위, 개략)
| 단계 | 내용 | 기간 |
|---|---|---|
| P0 | 오너 결정 회신, 샘플 비용 승인 | 승인 시점 |

| P2 | 3과목 샘플 생성·검증·인간 검수, 수율 보고 | 1~2주(P1과 병행 가능) |

## 비용 개략
- 샘플 3과목: 예상 $26, 상한 $50(generation-and-review-plan §4).
- 전 10과목 목표(과목당 50 MC + 5 FRQ + 풀 세트 2개분 보강) 외삽: 채택 수율 25% 가정 시 과목당 후보 약 200 MC + 20 FRQ → 과목당 약 $60~90, 10과목 **$600~900(배치)**. 샘플 실측 수율로 재산정 후 별도 승인.
- 인간 검수 시간이 지배 비용: 과목당 채택 문항 검수 약 20~30시간 가정(수율·자동 검증으로 단축 가능).
- 인프라 추가 비용: Java 샌드박스(CS A)는 로컬/서버리스 실행 방식 결정 필요(open-decisions).

## 갱신(Phase 1b)
- 샘플 3과목 API 비용: **안 B ≈ $47 (상한 $80) / 안 A ≈ $30 (상한 $55)**, 전문가 검수 **16시간 / 10시간**(`generation-and-review-plan.md` 갱신 절).
- 일정: Phase 1b 설계 승인 후 P1(스키마·응시 골격) 2~3주와 샘플 생성·검증(1주) + 전문가 100% 검수(약 1~1.5주, 오너/교사 일정 의존) → 샘플 보고까지 **약 3~4주**. 전체 12~17주 추정은 샘플 수율 반영 후 재산정.
- 10과목 외삽(과목당 MC 50 + FRQ 5 + 풀 세트 2): 과목당 API $50~100 + 전문가 검수 과목당 20~40시간(3과목 이후 표본 검수 전환 시 감소). 전 10과목 $500~1,000 + 검수 인력이 지배 비용. 샘플 실측 후 확정.
- 참조 분석 확장 7과목은 오너 승인 후 과목 착수 때 수행(과목당 약 3~4시간 분석, API 비용 없음).

## 실측 갱신(2026-10-08 밤, 샘플 생성 완료)
