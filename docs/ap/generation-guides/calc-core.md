# AP Calculus 공통 코어 가이드 (AB·BC 공유)

AB 가이드(`calc-ab.md`)와 BC 가이드(`calc-bc.md`)는 이 문서를 공통 전제로 한다. 설정(코드)은 `lib/ap-generation/subjects/calc-ab.ts`(공통 코어 + AB)와 `calc-bc.ts`(BC 델타)이며 **이 문서와 설정이 파이프라인의 단일 출처**다(`scripts/ap-generation/pipeline2.ts`가 프롬프트·범위·검증을 설정에서 만든다).

## 1. 생성 원칙(코드 우선)
1. **정답·표·그래프 수치·선택지·루브릭 구조는 Python 원형(`scripts/ap-generation/archetypes/*.py`)이 계산한다.** 모든 원형은 sympy 기호 경로 + 독립 수치 경로(scipy quad/Simpson/중앙차분/brentq/부분합)로 이중 검증한 뒤에만 팩을 낸다.
2. 오답은 **이름 붙은 오개념**에서 코드가 계산한 값이다(예: `f'g'`, 곱의 미분 둘째 항 누락). 오개념 설명(`why`)은 값과 일치해야 한다.
3. LLM은 **문장만** 쓴다(문제 지문 다듬기, FRQ 파트 문장). 코드가 쓴 수치·수식 블록(`$...$`)을 바꾸면 폐기하고 템플릿 문장으로 대체한다. 해설은 코드가 만든다(정답 근거 + 선택지별 오개념) — 해설 속 파생 수치 환각 방지.
4. 이후 단계: 결정적 게이트 → 독립 풀이(Opus, 정답 비공개) → 5기준 검토 + 참조 패턴 대조(Sonnet) → 난이도 별도 호출(Sonnet) → 상위 10% Fable 표본 → 근접 중복 게이트. 모델 일치는 보조 증거일 뿐 난이도·품질의 충분 근거가 아니다.

## 2. 시험 구조(2027, AB·BC 공통)
MC 42문항·100분(파트 A 29문항·62분 계산기 불가 / 파트 B 13문항·38분 그래핑 계산기 필수), 4지선다. FRQ 6문항·90분(파트 A 2문항·30분 계산기 / 파트 B 4문항·60분 불가), 문항당 9점. MC 스킬 비중: P1 50–70%, P2 15–30%, P3 10–20%(Practice 4는 FRQ에서만).

## 3. 표기 규칙
수식은 `$...$` LaTeX. 도함수 `f'(x)`·`dy/dx`, 적분은 `dx` 포함. 계산기 문항은 소수 셋째 자리, 계산기 불가 문항은 **정확값**(분수·π·e의 거듭제곱; 소수 근사 선택지 금지 — 결정적 게이트 `decimal_options_in_no_calculator_item`). 자연로그는 `ln`, 각은 라디안, 단위는 영어 단어("feet per second"). 계산기 문법(fnInt 등) 금지.

## 4. 계산기 규칙
- 불가(파트 A형): 손으로 풀리는 값만. 정확값 선택지.
- 필수(파트 B형): 수치 적분, 초월방정식 해, 비친화적 함수의 점에서의 도함수처럼 손으로는 비효율적일 때만. 손으로 풀리는 문항에 계산기 필수 표기 금지.
- 계산기는 그래프·방정식 풀이·수치 도함수·수치 적분 네 가지만 쓴다. FRQ는 설정(setup)을 보이게 한다.

## 5. 자료(스테이뮬러스) 유형: 생성·검증
| 유형 | 생성 | 코드 검증 |
|---|---|---|
| 표 | 함수에서 값 계산 후 지정 자릿수 반올림, 또는 정수 선택 | 모든 칸 재계산, 표 값만으로 키 재도출 |
| 그래프 | 꼭짓점·구간 부호·단조 데이터(`stimulus.data`)로 명세, 그림은 나중에 렌더링 | 영점·넓이·부호를 유리수로 재계산, 수치 적분 교차 검증 |
| 함수식 | 작은 정수 매개변수의 닫힌 형태 | sympy 기호 결과 vs 수치 |
| 기울기장 | 숨은 미분방정식에서 격자점 기울기 계산 | 모든 선택지 방정식을 모든 점에서 평가, 키만 전부 일치 |
| 급수(BC) | 부분합·판정법 표 | 부분합 거동·sympy 수렴 판정(`calc-bc.md`) |

## 6. 난이도 레버
허용: 표현 변환 수, 추론 단계 추가, 정리 가설 확인, 절차 선택, 오개념이 풍부한 선택지. **금지**: 긴 계산·불친절한 수, 모호한 서술, 읽기 부하·무관한 맥락, 범위 밖 지식(AB 기준 BC 내용), 표기 함정. 난이도 라벨은 잠정(`basic_learning`/`exam_prep`/`advanced_supplement`)이며 학생 데이터 전에는 확정하지 않는다.

## 7. 부하 한계
MC 45–130초, 지문 100단어 이하, 선택지 4개, 값 선택지는 같은 형식(자릿수·형태). FRQ 15분·9점(파트 3–6개, 파트 점수 1–5). 공식 참조: 2026 Q3는 1/1/2/5점 4파트이므로 "파트 균등" 요구는 금지.

## 8. FRQ 루브릭 행 패턴
- 모든 파트를 **setup / answer / justification / units·interpretation** 행으로 분해, 단위 행은 계산 행의 점수를 막지 않는다.
- 정당화 행은 **검증할 조건**을 적는다(연속, 미분가능, f'/f'' 부호, 수렴 판정법의 조건).
- 의존 행은 `requires_row_id`(예: 해 구하기에서 분리 → 적분 → 상수 → 해).
- 수치 행은 허용 오차(소수 셋째 자리, 문항당 반올림 감점 1점 이내)와 `requires_numbers`.
- 허용 대체 답: 동치 적분식(순서·부호), 구간 끝점 포함 여부(열린 구간 요구 시 불포함 우선 + 포함 허용 표기), 이전 파트 오류의 일관된 이월.
- 허용 문구(`optional_phrases`)와 필수 요소(`required_elements`)를 분리 저장한다.

## 9. 결정적 검증기(항목 유형별)
- MC: 4지·키 유효·고유 텍스트, 값 유일성(오답 값≠키 값), 오답마다 오개념, 서술형 오류 문구·길이 단서·비병렬 금지, 표 참조, MC 비평가 스킬 금지, 시간 45–130초·지문 길이, 금지어(BC 범위 밖/AB), 계산기 표기 일치, 계산기 불가 문항 정확값, LLM 지문의 수치·수식 블록 보존.
- FRQ: 행 점수 합 = 파트 점수, 총점 9, 의존 행 참조 존재, 스킬 코드 공식, 계산 파트 정답 행·정당화 파트 이유 행, 프롬프트 수치 보존, 자료 존재, 15분 이내.
- 세트: 근접 중복 게이트(3-gram Jaccard>0.8·완전 중복), 원형별 채택 수 제한.
- 독립 풀이: Opus가 정답 비공개로 풀고 MC는 선택 인덱스, FRQ는 수치 행 값 일치(±0.15%)로 대조.

## 10. 재사용·중복 규칙(AB ↔ BC)
공유 토픽은 같은 `content_key`(`calculus:<코드>`)를 가진다. AB에서 채택된 문항은 **BC 문항으로도 태깅할 수 있다**(공통 토픽·BC 범위 안일 때만). 한 과목의 세트·시험 안에서는 문항 하나를 한 번만 쓴다(중복 0 규칙 유지). 같은 문항이 AB·BC 양쪽 세트에 나올 수 있는지는 오너 정책(`open-decisions.md`)을 따른다.
