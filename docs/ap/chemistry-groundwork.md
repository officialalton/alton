## 4. 규약(코드로 강제)
- **상수**: `chem_common.CONSTS` 한 곳(R=8.314/0.08206, F=96,485, Kw=1.0e-14, h, c, N_A) — 테스트가 CED 값과 같은지 단언한다.
- **유효숫자·단위**: 값은 `$...$` 안, 단위는 `\text{ }`, 과학적 표기는 `sci()`, 3자리(pH 소수 둘째 자리). 본문 속 `\mathrm`·`\text` 가 `$` 밖에 나오지 않음을 테스트한다.
- **선택지 간격**: 숫자 선택지는 서로 **8% 이상**(`num_opts`). pH·원자량·전지 전위·정수 개수처럼 단위가 작은 값은 절대 간격(예: pH 0.15, 원자량 0.25 amu, E° 0.1 V) — 예외 목록은 `test_chem_p0.ABS_GAP`.
- **오개념**: 오답마다 이름 붙은 오개념(≥15자, 서로 달라야 함); 키가 가장 길고 평균의 1.6배를 넘으면 반려하는 TS 규칙(`key_much_longer`)을 Python 테스트가 미리 잡는다(2026-10-13 4개 원형 수정).
- **이중 경로**: 각 원형 `blueprint.verification.independent_path` 에 "A vs B" 형태로 기록(Python 코드는 두 경로 일치를 `agree()` 로 강제, 불일치 시 `ValueError`).
- **수치 진실 테스트**: facts 만으로 테스트가 다시 계산한 값과 키가 일치(이상 기체·결합 기체·묽힘·1차 붕괴·pH·ΔG–K·광자·패러데이·네른스트·전지 전위·한계 반응물·수율·적정·K·K 조작·Ksp·ICE·초기 속도·가열 곡선·에너지 도표·평균 원자량·Rf·열량·부분 압력 등 32개 원형).
- **FRQ**: 파트마다 공식 스킬 코드와 1점 행(expression·numeric·diagram·graph·claim·justification), 모범 답안 "ALTON reference answer for self-review — not official AP scoring".

2. **변형 원형 부족 스킬**: 1.B·2.A·2.B·2.F·6.A–6.C·6.E–6.G 는 원형이 하나뿐이라 두 풀 세트 사이 look-alike 우려. 두 번째 세트 전에 스킬당 1–2개 추가 권장(무료 엔지니어링, 약 $0).
3. **개념 정확성**: 이중 경로는 *계산*을 잡고 *개념 가정*(예: 이상 용액, 완충 근사)은 못 잡는다. 열량·헤스·결합 엔탈피 등 표 값(일반 교재 값)은 공식 값과의 소수 자리 차이가 있을 수 있다 → Opus 독립 풀이와 표본 검토 대상. 알려진 단순화: 약산 pH 는 물의 자동 이온화 포함 정확해, 완충 pH 는 헨더슨–하셀바흐(정확 평형과 0.02 이내 확인).
4. **FRQ 키 신뢰**: 서술 행은 `required_elements` 뿐이라 자동 독립 검증은 불가(Opus 풀이 대조). 구조식·그래프 그리기 행은 자동 채점 불가(종이 손글씨).
5. **파이프라인 무료 배선 점검 통과(2026-10-13)**: `AP_FIXED_WORDING=1 AP_REQUIRE_BLUEPRINT=1 AP_LIST=chem_p1_mc|chem_p1_frq pipeline2.ts plan|blueprint|check --subject ap_chemistry` — MC 칸 21(단원별 2/2/4/2/2/2/2/3/2)·후보 88건 중 블루프린트 실패 0·결정적 게이트 통과 88, FRQ 칸 7·28건 중 실패 0·통과 28(호출 비용 0, 산출물은 확인 후 삭제). 남은 것은 풀 세트용 `cells.ts`·`stock.ts`·`assemble-draft.ts`·`full-set-rules.ts` 배선(단원 bounds 9단원·FRQ 7유형)으로 파일럿 뒤 단계다.
6. **LaTeX**: 값 선택지 `\text{ }`·과학 표기. `$` 균형·바깥 TeX 없음은 테스트하지만 KaTeX 렌더 표본 확인은 파일럿 때.
