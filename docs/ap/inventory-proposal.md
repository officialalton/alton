# AP 재고 목표 제안 — 2026-10-09 (정책 개정 반영: 영구 "한 세트만" 규칙 없음)

> 개정: 오너 결정으로 AP 에는 영구 "한 문항 한 세트" 규칙이 없다. 전체 길이 모의고사는 기본 중복 회피(겹침 0), 단원 연습·오답 복습은 재사용 가능, 겹침 허용은 세트 유형별 매개변수. 목표는 (a) 무료 AB 부분 연습 → (b) 풀 AB 세트 1개 칸만 설정하고 수업 용도 목표는 수요 확인 전까지 두지 않는다. 숫자: `data/ap/stock/stock-targets.proposed.json`(MC 100 = Part A 29×3 + Part B 13, FRQ 서로 다른 6유형 × 유효 2). 파일 기준 부족: MC 48, FRQ 4(신규 유형 4.2·4.5 각 2). 아래 원문은 비교용 이력이다.

숫자는 **제안**이며 임의 확정이 아니다. 근거가 되는 현재 수치는 `docs/ap/ab-set-feasibility.md`.

## 1. "문항 하나는 한 세트에만" — 확정 정책인가?
- **SAT 모의고사**: 확정 정책. `docs/POLICY-DECISIONS.md` 46행("모의고사 세트 간 문항 중복은 아예 없어야 한다 … 재사용 금지·재고 부족 시 세트 수를 줄이거나 문항을 추가 생성", 10-07 오너 정책), `docs/CURRENT.md` 16행(엄격 조립기 `assemble-unique.ts`, 중복 0 단언). SAT 는 지금도 세트 간 중복 0 이며 이 제안이 SAT 에 영향을 주지 않는다.
- **AP 모의고사**: 오너가 AP 에 대해 별도로 확정한 문서는 찾지 못했다. `docs/ap/set-and-weakness-validation.md` 의 "세트 간 중복 0 … `assemble-unique` 원칙 확장"은 **제가 설계 문서에 SAT 원칙을 확장한 제안**이었고, 조립 스크립트(`assemble-ap-set.ts`, `lib/ap-exam/assemble.ts`)가 같은 관행으로 구현했다. 즉 AP 는 "SAT 확정 정책의 준용 + 조립 스크립트 관행"이며 AP 전용 오너 확정은 아니다.
- 비재사용의 목적(SAT 정책에서 읽히는 것): 같은 학생이 여러 세트를 풀 때 같은 문항을 보면 점수·약점 분석이 왜곡되고 "새 모의고사" 가치가 떨어진다.

## 2. 비재사용 vs 제한적 재사용의 생성 비용 차이 (AB 풀 세트 = MC 42 + FRQ 6)
세트 수 S, 한 세트가 이전 세트들에서 가져올 수 있는 최대 문항 수 k(총량 상한, 보수적 단순화)일 때 필요한 고유 문항 = 42 + (S−1)(42−k). 단가는 코드 우선 AB 실측: MC $0.042·FRQ $0.068 / 사용 가능 고유(수선·재검토 포함, Fable 표본 제외). 문항군 상한(세트당 군당 2개)과 렌더·화면 검증 비용은 제외.
| 세트 수 | MC 필요(재사용 0) | MC k=6(≈14%) | MC k=10(≈24%) | MC 생성비(0 / k=6 / k=10) | FRQ 필요(0 / k=1) | FRQ 생성비 |
|---|---|---|---|---|---|---|
| 1 | 42 | 42 | 42 | $1.8 | 6 / 6 | $0.4 |
| 3 | 126 | 114 | 106 | $5.3 / $4.8 / $4.5 | 18 / 16 | $1.2 / $1.1 |
| 5 | 210 | 186 | 170 | $8.8 / $7.8 / $7.1 | 30 / 26 | $2.0 / $1.8 |
| 10 | 420 | 366 | 330 | $17.6 / $15.4 / $13.9 | 60 / 51 | $4.1 / $3.5 |
- **생성 비용 차이는 작다**(10세트에서 MC 약 $2~4). 진짜 병목은 API 비용이 아니라 **원형·문항군 다양성**이다: 세트마다 같은 템플릿의 숫자 변형이 반복되면 비재사용이어도 학생에게는 비슷한 문항이다(현재 AB MC 문항군 36개, FRQ 4개). 재사용 허용으로는 이 병목이 풀리지 않는다.
- 쌍(pair)별 겹침 상한(예: 두 세트 간 최대 4문항)을 쓰면 위 총량 모델보다 더 많은 고유 문항이 필요하다(조합 설계 제약). 비용 차이를 더 줄이지 못하고 조립 복잡도만 오른다 → **비재사용 유지를 권장**, 재고 부족 시 세트 수를 줄이는 SAT 방식과 동일.

## 4. 수업 용도(lesson) 재고 — 별도 요건
- 용도는 변환 시점에 고정(`purpose` 불변). 무료 모의고사 재고와 **분리 계산**한다.
- 제안 기준(수업 용도): CED 토픽 단위로 "토픽당 개념 확인 MC ≥ 3 + 연습 MC ≥ 3, 단원당 FRQ 유형 ≥ 1"(AB 81개 토픽 → MC 약 486, FRQ 단원 8개 이상). 수업은 세트 중복 제약이 없고 **토픽 폭이 핵심**이라 모의고사 재고와 필요 문항·원형이 다르다(토픽 가중이 아닌 균등 커버).
- 현재 AB 기준선: 토픽 커버리지(사용 가능 재고가 있는 토픽 수 / 81)는 `data/ap/stock/summary.json`의 cells 로 산출 가능(이번 라운드 미산출).
