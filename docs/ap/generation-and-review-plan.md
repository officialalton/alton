# AP 생성·검증·검수 계획 + 3과목 샘플 비용 추정 (오너 승인 전, 비용 지출 없음)

> **Phase 1b(2026-10-08)로 §3~§4 수치는 아래 '갱신' 절이 대체한다**(전문가 100% 검수·구조 커버리지 반영). 파이프라인 단계는 acceptance-criteria-and-review-pipeline.md가 우선.


## 1. 원칙
- 사전 생성·검수 완료 세트만 제공(실시간 생성 없음). SAT 적응형/4모듈 미적용. MC + FRQ 처음부터 포함.
- 공식 문항·지문·이미지 복제 금지: CED의 학습 목표·스킬·구조만 입력, 출력은 독창 문항. 유사도 검사(공식 공개 기출 텍스트 n-gram/임베딩)는 반려 사유 `copyrighted_resemblance`.
- **정답 검증과 난이도 검수는 분리**. 다중 모델 일치는 정답 *오류 탐지*에만 사용하고 hard 근거로 쓰지 않는다. 난이도는 CED 인지 수준 태그 + 교사 판정 + 실제 응시 정답률로만 승격.
- FRQ AI 채점은 "참고 피드백"(ai_reference) 라벨, 점수 합산·1~5 환산 없음.

## 2. 파이프라인(문항당)
1. 생성(Sonnet 5.5, 단원·주제·스킬·난이도 지정, 삭제 주제 금지 목록 주입) → 후보
2. **과목별 결정적/구조 검증**(아래 표) → `auto_verified`
3. 독립 모델 풀이 검증(다른 모델: Opus 5.5, 정답 키 비공개로 풀이 → 불일치는 `needs_repair`/반려)
4. 품질·범위·모호성·번역 어색함 검수(Sonnet 5.5) + 난이도 태깅(근거 분리 저장)
5. 인간 검수(교사/외부 검수자) 샘플링 후 `adopted`. 샘플 단계는 100% 인간 확인.

| 과목 | 정답 검증 방식 |
|---|---|
| Calc AB/BC, Physics 1, Chemistry | 계산 검증: SymPy/수치 적분·미분, 단위·유효숫자 재계산(코드 실행), 그래프 문항은 데이터 spec에서 재도출 |
| Statistics, Biology | 자료·설계 검증: 표/요약통계 재계산, 검정 조건 점검, 실험 설계(대조군·변수) 체크리스트, 삭제 주제 필터 |
| Micro/Macro | 그래프 방향·균형 검증: 곡선 이동 방향 규칙 표, 균형가격·수량 산술, 경제학 용어 일관성 |
| CS A | 코드 실행: Java 채점 샌드박스에서 정답 출력/부분 코드 실행, 4개 오답이 실제로 다른 출력인지 확인 |
| English Language | 근거·선지 중복 검사: 정답 근거 문장 인용 필수, 선지 간 의미 중복·복수 정답 가능성 검사, 지문은 독창(공식 지문 사용 안 함) |

FRQ는 번들(자극+파트)당 루브릭(점수 규칙·모범답안·흔한 오류)을 같은 파이프라인에 태우고 모범답안은 위 검증 방식으로 재풀이한다.

## 3. 3과목 샘플 계획 (Calculus AB, Biology, Microeconomics)
- 산출: 과목당 MC 20 + FRQ 번들 2 채택 → 총 MC 60 + FRQ 6.
- 수율 게이트: 채택/초기 후보 ≥ 25%. 따라서 과목당 MC 후보 80, FRQ 후보 8 생성(총 MC 240, FRQ 24).
- 게이트 평가: 25% 미달·정답 오류율 > 5%·예산 초과 시 전체 확대 중단하고 프롬프트/검증 재설계 후 소규모 재시도 승인 요청.
- 산출 보고: 과목·단원별 후보→채택 깔때기, 반려 사유 분포, 모델별 비용, 인간 검수 소요 시간.

## 5. 이후 목표(샘플 통과 시)
- 과목당 MC 50 + FRQ 번들 5, 풀 세트 2개(공식 구조 맞춤). 전 10과목 규모 추정은 샘플 실측 수율로 재산정(schedule-and-cost.md의 개략치 참고).

## 6. 관리자 화면 요구
단원별 재고(채택/목표), 검수 상태 칸반(후보/자동검증/난이도 검수/인간 검수/채택/반려), 반려 사유 집계, 단계별 비용, 깔때기. 설계는 data-design §4.

## 7. 검증(테스트) 계획
- **SAT 회귀**: 기존 mock-exam·MST·점수 추정·노트·무료 회원 통합 테스트 전부 불변 통과(`exam_program` 기본값 sat).
- **시간 규칙**: `section_layout` 기반 섹션별 타이머·계산기 파트 전환·재개 시 남은 시간, 공식 표와 일치 단위 테스트.
- **자동 저장**: MC 선택·FRQ 타이핑 autosave, 중단·재접속 복원, 제출 후 잠금.
- **정답 노출 차단**: 채점 전 정답·해설·루브릭이 payload/REST에 없음(기존 non-disclosure 테스트 패턴 확장).
- **교차 사용자 격리**: 다른 학생의 응시·FRQ 응답 접근 불가 RLS 통합 테스트.
- **미검수 세트 차단**: 상태가 `adopted+human_reviewed` 아닌 문항을 가진 세트는 공개·시작 불가.
- **라벨 규칙**: MC-only 세트가 "Full" 라벨을 못 받음.
- **AP 점수 미표시**: 결과 화면에 1~5 환산 값 없음(스냅샷/DOM 테스트).

## 갱신(Phase 1b): 샘플 계획·비용 재산정
- 파이프라인 변경: 범위·스킬·시험적합성 검토를 정답 검토와 분리한 **별도 호출**로 추가, 채택 후보 **전문가 100% 검수**(3과목).
- 샘플 풀(안 B, 권장): Calc AB MC 30 + FRQ 4, Biology MC 30 + FRQ 4, Micro MC 30 + FRQ 3 (주요 구조 전체 커버, data-design §11). 수율 25% 가정 후보: MC 120×3=360, FRQ 16+16+12=44.
- 단가(배치, `batch-lib.ts`): 후보당 MC = 생성 $0.018 + 독립 풀이 $0.033 + 검토 2호출 $0.020 = $0.071; FRQ = $0.044 + $0.088 + $0.040 = $0.172.
| 항목 | 안 B(권장) | 안 A(20 MC+2 FRQ) |
|---|---|---|
| MC 후보 비용 | 360×0.071 = $25.6 | 240×0.071 = $17.0 |
| FRQ 후보 비용 | 44×0.172 = $7.6 | 24×0.172 = $4.1 |
| 반려·수선 재호출 30% | $10.0 | $6.3 |
| 고난도 표본 최종 확인(Fable) | $3.5 | $2.7 |
| **API 합계(배치)** | **≈ $47 (상한 $80)** | **≈ $30 (상한 $55)** |
| 전문가 검수 시간(채택 MC 90/60, FRQ 11/6 × 6분·25분 + 세트·구조 검토) | ≈ 16시간 | ≈ 10시간 |
- 실시간(비배치) 호출 시 약 2배. 결정적 검증(SymPy 등)은 API 비용 0.
- 수율 25% 미달 시: 기준은 유지하고 생성 프롬프트·검증기를 수정한 소규모 재시도 승인을 요청(비용 상한 내). **수율을 맞추려고 채택 기준을 낮추지 않는다.**
