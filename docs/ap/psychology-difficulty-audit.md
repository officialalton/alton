범위: 읽기 전용 점검 + 새 원형·재고 생성(모델 비용 **$5.17**, 하드 캡 $6) + 정확 배정 + 새 버전 교체 계획. **DB 쓰기·적재 없음**(`supabase db query --linked` SELECT 만). 재현 도구: `scripts/audit/psych-difficulty-audit.ts`(이 문서의 표), `scripts/audit/psych-table-pct-scan.ts`(표 비율 점검).

## 1. 문제: 게시본의 exam_prep 비중이 거의 0
게시 PS1·PS2(둘 다 v2)의 MC 75문항 중 판정기 라벨 `exam_prep` 는 각각 **1문항**(나머지는 basic_learning)이고, 설계 기록의 풀이 단계는 전부 2(검토기 요구 최소)였다. 개념 문항이 단원·Practice 범위를 채우는 구조라서 "개념 한 번 맞추기"가 대부분이었다.

## 2. 측정 방법(두 층)
- **판정기 라벨**: 재고 행의 `difficulty.label`·`reasoning_steps`(Sonnet 판정기, 문항 겉모습 + 아래 구조 사실). 라벨 `exam_prep` = 3단계 이상이고 둘 이상의 개념 또는 자료를 결합(저장소 기준, `lib/ap-generation/stats-difficulty.ts`).
- **모델 없는 대리 지표**: ① 설계 기록 `blueprint.student_thinking` 길이(풀이 단계 수) ② 코드가 선언한 `difficulty_signals`(단계·결합 개념) ③ 표·그래프가 있는 문항 ④ 원형 종류(개념 적용 / 연구 설계 / 통계·자료 해석 / 세트) ⑤ Practice.

## 4. 무엇을 했나
1. **고차 원형 새로 작성**(`scripts/ap-generation/archetypes/psych_p0_hd_a..f.py`, 공통 `psych_hd_common.py`·`psych_hd_signals.py`): 개념 적용 다단계 체인 **41**(예: 시냅스 약물 효과 추론, 병변 패턴에서 구조·기억 체계 추론, 조건화 자극·과정 식별, 강화 유형 + 스케줄 + 소거, 귀인·사회 영향·설득·치료 기전), 연구 설계 평가 **16**(무작위 배정 + 눈가림 + 표집·일반화 + 윤리·재현·메타분석·조작적 정의 타당도 결합), **코드가 값을 계산하는 자료 해석 13**(통제 집단 사전·사후 순 향상, 서로 다른 척도의 z 비교 + 경험칙, 세 집단 인원 → 백분율 → 위약 효과 분리, 상관 행렬 부호·크기, 평균·중앙값·치우침, p 값과 효과 크기와 표본 크기, 신뢰도 대 타당도, 정규분포 인원 수, 지연별 간격, 쌍둥이 일치율, 백분율 포인트 대 상대 변화, 2요인 표). 통계 원형은 정답을 코드가 계산하고 scipy/numpy/statistics 로 두 경로 재계산하며 표에는 정수 인원 수만 싣거나 백분율이 정수 인원과 맞는 값만 쓴다(`pct_rows_ok`).
2. **난이도 신호 선언**(AP Statistics S3 와 같은 방식을 `ap_psychology` 에 켬: `gates.ts` 한 줄 + `difficultyContext` 한 줄): 원형이 단계 목록·결합 개념·자료 수·**오답이 처음 틀어지는 단계**를 코드로 선언하고, 결정적 게이트가 "단계마다 그 단계에서 틀어지는 오답이 있는가"를 검사해(단계 부풀리기 방지) 판정기에 사실로 보여 준다. 판정기가 선언을 반박하면 그대로 basic 이 된다(예: 한 변형에 개념이 하나뿐이면 "선언된 결합 개념이 문항에 없다"며 basic). 효과: 같은 문항·같은 판정기에서 신호 없이 통과 23건 중 exam_prep **3**, 신호를 주면 통과 24건 중 **22**(c3 재실행). 라벨을 올리는 규칙이 아니라 구조 사실을 보여 주는 것이며, 라벨은 여전히 판정기 판단이다.
3. **표 비율 정수 인원 수 수정**(외부 감사 지적): 점검 도구가 게시 후보 8건(세트 2개 `u3_attachment_style` 82%/58%·`u4_bystander_lab` 85%/62%, AAQ `psf_aaq_compliance` 38%)의 표 비율이 정수 인원과 맞지 않음을 찾았다. 원형을 고쳐(80/60%, 80/60/40%, 40%) 세트 2개는 새 배치로 다시 생성·통과, 위반 후보는 `data/ap/stock/psych-table-pct-flags.json` 로 재고에서 뺐다(AAQ 는 재생성하지 않고 다른 AAQ 3종 사용). 새 배정에는 위반 0(테스트 `psych-new-version-plans.test.ts`).
4. **정확 배정 v3**: PS1 exam_prep **51/75**, PS2 **52/75**(기존 1·1), 설계 기록 풀이 단계 3 이상 58·59문항, 가상 칸 0, 독립 검증기 위반 0, 단원 15/15/15/15/15, Practice 45/19/11, 공식 범위 유지. `--min-exam-prep 52` 는 가상 3칸이 필요하고 53 은 불가능(HiGHS infeasible)이라 이번 재고의 상한이다(Practice 1 ≥ 45 때문에 Practice 2+3 ≤ 30).

## 5. 한계(투명 공개)
- exam_prep 은 "구조상 다단계"라는 **내부 라벨**이다. College Board 실측 난이도가 아니며, 선언은 사람이 쓴 구조 사실이고 판정기가 확인한 것이다.
- 새 문항의 정답 보증은 키를 숨긴 독립 풀이(Opus)·5기준 검토(Sonnet)·두 번째 모델 패널(Fable·Sonnet 맹검 풀이, 새 배정 119키 238회 전부 일치·모호 표시 0)이다 — **심리학 교사 검수는 아직 없다**.
- 일부 변형은 개념 하나뿐이라 basic 으로 남았다(25문항 중 배정에는 최소화). 대리 지표 "응용·분석 합계"는 라벨과 별개의 구성 지표다.
- 개념 문항 중 일부 오답은 검토기가 "약한 절대어"라고 지적한 형태가 남아 있다(수정한 것은 다시 생성).
