# 공식 College Board 공개 자료 현황 (2023~2026) — 10과목

조사일 2026-10-08, 출처는 AP Central(공식)만 사용. 서드파티 학습 사이트·계정 사용 없음. **자료 원문은 저장소에 두지 않고 세션 scratchpad에서만 열람**했으며 문항·지문·그림을 복제하지 않는다.

## 1. URL 규칙(전 과목 공통)
- 기출 페이지: `https://apcentral.collegeboard.org/courses/{slug}/exam/past-exam-questions`
- FRQ: `…/media/pdf/ap{YY}-frq-{과목}.pdf`, 채점 가이드: `…/ap{YY}-sg-{과목}.pdf`, 샘플 응답(문항별): `…/ap{YY}-apc-{과목}-q{n}.pdf`, Chief Reader 보고서: `…/ap{YY}-cr-report-{과목}.pdf`, 점수 통계·분포 PDF 별도. Micro·Macro·English는 2023~2025가 **세트 2개씩**(`-set-1/-set-2`), 2026은 1세트.
- CED(문항 샘플 포함): `…/media/pdf/ap-{slug}-course-and-exam-description.pdf`, 정정 사항: `…-clarifications.pdf`.
- 페이지가 밝힌 정책: "최근 3개년 공개"(현재 2023~2026). **2026은 FRQ와 채점 가이드만**(샘플 응답·보고서 없음). 이전 연도 문항·MC 연습은 교사 인증 AP Classroom에만 있음.

## 2. 공개 MC · 모의고사 현황(결론)
- **공개 MC 풀: 현행 CED의 "Sample Exam Questions"가 유일**(과목별 15~24문항, 정답·스킬·LO 표 포함). AP Central의 과거 시험 페이지에는 MC가 **없다**.
- **공개 풀 길이 모의고사(전 문항 PDF)는 없다.** Bluebook의 AP "test preview"는 도구 체험용 짧은 문항 묶음(무점수·무피드백, 다운로드 불가), 풀 연습은 AP Classroom(교사 인증)으로 안내됨.
- AP Classroom Question Bank·AP in Practice 시리즈는 교사 전용/유료로 공개 자료가 아님.
