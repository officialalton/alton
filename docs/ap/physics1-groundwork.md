**렌더링 접근**: Python 원형이 "장면 모델"(JSON: 객체·좌표·힘·라벨)을 만들고, TypeScript 결정적 SVG 생성기(기존 `ap-diagrams.ts` 패턴)가 그린다 — **본문 수치와 그림은 같은 장면 모델에서 파생**해 불일치를 구조적으로 차단. LLM은 그림을 그리지 않는다.

**그림 정확성 비용·위험**: (a) 화살표 각도·상대 길이·라벨 겹침이 틀리면 학생을 오도 — 결정적 검사(화살표 길이 ∝ 힘, 평형 문항이면 벡터 합 0, 라벨 상자 겹침, viewBox 내부) + 렌더 PNG 화면 증거(390×844·1280×800). (b) "그림-본문 불일치" 검사: 장면 모델의 숫자 집합이 지문 숫자와 일치하는지 코드 비교. (c) FBD 정답 문항은 **정답 힘 집합을 코드가 소유**(선택지 FBD는 정답 집합에서 이름 붙은 오개념 변형: "운동 방향 힘 추가", "수직항력 누락", "mg sinθ 별도 힘으로 중복 표기" 등). (d) 그림 필요 비율이 Stats(≈45%)보다 높아 **MC 약 55–60%**로 가정.

재사용 가능 비중: **약 35–40%**(그래프·표·오차 막대·선택지 틀). 신규 필요가 과반 — Stats(재사용 80%)와 크게 다르다.

## 4. 원형(archetype) 설계 계획

프레임워크: `scripts/ap-generation/archetypes/*.py` 함수가 시드 rng에서 값을 뽑아 **sympy 기호 경로 + numpy/수치 독립 경로(ODE 적분·이분법·격자)로 정답을 이중 계산**, `pack(...)`+`Opt(...)`로 정답·이름 붙은 오개념 오답(코드가 계산한 값)·해설을 생성(`calc-core.md` §1). 설계도·결정적 게이트·독립 풀이·5기준 검토·난이도·근접 중복 게이트는 기존과 동일. 수치는 **정수·간단한 소수(g=10 또는 9.8 과목 규칙 하나로 고정)**, 단위·유효숫자 일관, 계산량이 아니라 **표현 전환·개념 선택**이 난이도 원인이 되도록 한다.

위험 L/M/H: L=코드로 정답 확정·해석 문구 적음, M=서술 판정 일부 포함, H=정답이 해석 문장에 의존(반려율 높음). 렌더 열 약어: G=`ap_graph`, T=표, F=FBD, S=장면, B=에너지 막대, V=벡터, M=운동 도해, C=선택지 그림, X=없음.

 - `claim`/`justification`/`design`: `required_elements`(필수 개념 항목: 예 "운동량 보존" 또는 "뉴턴 3법칙", "시스템 외력 0")와 `accepted_phrases`(허용 표현)를 분리 저장 — Stats와 동일 구조.
2. **자기 채점 참고용 모범 답안**: 코드가 모형 사실(factsheet)과 고정 문장 템플릿으로 생성하며 모든 화면에 "**ALTON reference answer for self-review — not official AP scoring**" 표기. 공식 채점 가이드의 문구·허용 목록·Example Response는 복제하지 않고 우리 행 구조로 재작성. AP 1~5 환산·합격 판정 표시 없음(기존 정책 유지).
3. **독립 검증**: 수치·식 행은 sympy와 수치 경로 불일치 시 폐기. 서술 행은 Opus 독립 답안이 `required_elements`를 충족하는지 대조(Stats와 동일 절차). LAB 자료는 코드가 노이즈 시드로 생성하고 기울기 정답을 ± 오차로 계산.

## 7. 위험과 완화

1. **저작권·기출 유사**: 2025–26 개정 과정 FRQ와 CED 샘플 15 MC·4 FRQ가 공개돼 있어 시나리오(도르래·경사·충돌·용수철)가 겹치기 쉽다. 완화: 시나리오·수치·객체 맥락은 우리 도메인 풀로 구성, CED 샘플의 소재(예: 압력센서로 밀도 측정, 원판 굴림 유도)는 **금지 목록**, 기존 `look-alike` 반려 경험(표준 시나리오 반려)에 따라 비표준 맥락. 문구·그림 복제 금지.
2. **물리적 정확성**: 코드로 증명 가능한 것은 이중 경로로 보증. 모형 가정(공기저항·마찰 무시 등)을 문항에 명시(CED 가정 목록 사용). 비물리적 조합(자유낙하 중 정지 마찰 등)은 원형 사전 조건으로 차단. 남는 위험은 개념적 표현 오류 → 해설을 코드가 만들고 Fable 표본 유지.
3. **그림-본문 불일치(가장 큰 위험)**: 장면 모델 단일 원본 + 결정적 일치 검사(W10) + 렌더 PNG 사람 표본(파일럿 전수). 선택지 그림 정답 암시 금지(기존 틀 재사용). 화살표 상대 길이 오류는 코드가 길이를 계산하므로 입력 오류만 남음.
4. **FRQ 비용·채점 신뢰**: 자유서술이 많아 Stats와 비슷하게 FRQ는 보수 단가 가정. 완화: 행 단위 구조화·체크리스트·고정 문장 템플릿, 자기 채점 참고만.
5. **반올림·g 값**: 한 과목 규칙(g 고정)과 선지 간격 ≥ 반올림 오차 10배 게이트.
6. **구조 부족 칸**: U6·U7·세트·FBD 선택지 문항 → 예비 우선 배분. 독립 구조가 부족하면 U6/U7 MC를 공식 하한(5%, 2문항)까지 낮추고 U2·U3로 배분(공식 범위 안).
7. **FRQ 응답 방식**: 종이 시험을 디지털로 옮길 때 그림·그래프 점수 행의 채점 가능성 → §8-B.
8. **중복·고유 재고 부족**: 원형당 고유 8개 가정이 물리 원형은 매개변수 공간이 작아 더 낮을 수 있음(완전 중복 게이트 재측정).
