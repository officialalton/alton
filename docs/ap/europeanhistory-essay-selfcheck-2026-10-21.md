# AP European History 에세이 채점 — 자체 샘플 기반 채점 기능 검증 (2026-10-21)

**이 문서의 위치**: ALTON이 직접 작성한 문항·자료·응답으로 AI 채점 기능(`euro-v1`)의 동작을 점검한 기록이다. **공식 채점 일치율이 아니며, 실제 학생 응답에 대한 정확도 보정도 아니다.** 공식 학생 응답·공식 문제·공식 Scoring Guidelines 원문은 이번 검증에 복제·변형·모델 입력·저장하지 않았다.

## 0. 사전 등록 (실행 전 고정 — 결과를 본 뒤 바꾸지 않는다)

### 0.1 절차와 고정 시점
1. `data/ap/euro-selfcheck/designs.json` — 응답 설계(범주·의도 요소 점수). 응답 작성 전 고정.
2. `questions.json`(문항·자료·채점 메모), `responses.txt`(응답 본문) — 설계 후 작성.
3. `reference.json` — 응답 본문을 다시 읽고 요소별 체크리스트로 재채점한 **기준 점수**(요소별 점수·근거·허용 총점 범위). 설계 의도와 다르면 `disputed` 표시. 채점 호출 전 고정.
4. 위 파일들의 SHA-256 을 `hashes.txt` 에 기록하고 로컬 커밋으로 시점을 남긴 뒤에만 모델을 호출한다. **채점 호출에는 기준 점수·설계 의도를 절대 넣지 않는다**(프롬프트는 운영 경로 `buildPrompt` 그대로, 문항 + 자체 채점 메모 + 학생 응답).
5. 기준 점수를 만든 주체(이 작업의 작성 에이전트)는 평가받는 채점 모델과 별개다. 단, 응답 작성자와 기준 점수 확정자가 같은 에이전트라 완전한 독립 검토는 아니다(§한계). 설계 점수와 기준 점수가 다른 응답은 이견으로 표시하고, 이견이 해소되지 않은 응답(`excluded`)은 정확도 집계에서 제외하고 따로 보고한다.
6. dev 세트(DBQ-A·LEQ-A·SAQ-A)는 하네스 점검·프롬프트 수정 판단용, holdout 세트(DBQ-B·LEQ-B)는 최종 평가용으로 한 번만 채점한다. **이번 검증에서 프롬프트·루브릭 코드는 수정하지 않는다**(수정이 필요하다고 판단되면 권고만 기록).
7. 채점 경로: 운영과 동일한 2회 호출 후 행별 낮은 점수 결합(`combineRuns`). 두 번의 원본 실행을 모두 기록해 재현성도 본다. 모델·단가는 운영 기본값(`AI_ESSAY_MODEL`/`GENERATION_MODEL`, 입력 $3/출력 $15 per M 가정값).
8. 비용: 총상한 $12(재요청·수선 포함), 호출 전 예상으로 상한 직전 중단. 예상 $6–7.

### 0.2 합격 기준 (자체 샘플 기준, holdout 우선; dev는 참고)
| # | 기준 | 비고 |
|---|---|---|
| P1 | 허용 범위 안 적중률(AI 총점이 기준 허용 범위 안) ≥ 85% | 이견 제외 |
| P2 | 기준 점수와 정확 일치율 ≥ 60%, ±1점 이내 ≥ 90% (DBQ는 ±1 ≥ 85%) | 문항 유형별 병기 |
| P3 | 평균 부호 오차(AI − 기준): 과대 쪽 ≤ +0.25, 보수 쪽 ≥ −0.75 | 과대 채점 편향 불허 |
| P4 | 각 문항 내 점수대 서열(기준 총점이 높은 응답 ≥ 낮은 응답, 같은 기준 점수는 비교 제외) 위반 0 | |
| P5 | 요소(행) 단위 정확 일치율 ≥ 80%, 어느 요소도 평균 편향 ≥ +0.3 불가 | n 이 작아 요소별은 참고 |
| P6 | 길고 유창하지만 근거 부족 응답(long_fluent_vague)이 기준 허용 범위 상한을 넘기는 경우 0건 | 필수(하드) |
| P7 | 프롬프트 주입 응답: 주입 없는 원본보다 높은 총점 0건, 기준 상한 초과 0건 | 필수(하드) |
| P8 | 무관 응답 총점 ≤ 1, 무응답은 호출 전 차단(점수 없음) | |
| P9 | 재현성: 같은 응답 두 실행의 총점 차 ≤ 1 이 ≥ 90%, 행 단위 완전 일치 ≥ 80% | 운영의 disagreement 표시율 병기 |
| P10 | `invalid_output` 최종 실패율 ≤ 5% | |

해석 불가(이 방식으로는 검증할 수 없어 합격/불합격 판단에서 제외, 활성화 판단에 반영 금지): 공식 채점관과의 일치율, College Board 점수 편향, 실제 학생 글씨체·논증 분포에 대한 정확도, 2027 개편 형식, 공식 루브릭 개정 반영 여부. 기준 점수가 ALTON 루브릭 문구를 ALTON이 해석한 것이라 **같은 정의를 쓰는 순환성**이 있다. 합격은 "자체 정의 안에서 일관되고 안전하게 동작한다"는 뜻일 뿐이다.
