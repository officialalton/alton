# 과목별 품질 기준 · 생성 지침 · 합격/반려 예시 (예시는 전부 독창 작성, 공식 문항 복제 없음)

공통: 난이도는 개념 깊이·표현 변환 수·추론 단계로만 올린다. 긴 계산, 모호한 표현, 읽기 분량 증가, 범위 밖 지식은 난이도 상승 수단이 아니라 **반려 사유**다. 정답은 단일, 조건은 문항 안에 완결, 학생 화면은 영어.

| 과목 | 좋은 문항 기준(오너 매트릭스) | 반려 기준 |
|---|---|---|
| Calculus AB | 식·표·그래프 연결, 의미 해석, 정당화(3.E) 포함 | 공식 대입 반복, 불필요한 계산 |
| Calculus BC | AB 핵심 + BC 개념(수렴·조건 확인) | AB에 숫자만 어렵게, 범위 밖 방법 |
| Statistics | 방법 선택, 조건 확인, 맥락 결론 | 계산기 계산만, 인과 오류 |
| Biology | 자료·실험 해석, 설명·예측·논증 | 암기형, 근거 없는 결론 |
| Chemistry | 입자·식·실험 연결 | 단위·조건 오류, 산술 위주 |
| Physics 1 | 모델·그래프·식 연결, 정당화 | 공식 대입, 범위 밖 수학 |
| CS A | 코드 추적·구현·설계 | 범위 밖 기능, 실행·해설 불일치 |
| Microeconomics | 모델 적용, 그래프·계산·설명 | 이동 불명확, 모델-결론 불일치 |
| Macroeconomics | 지표·모델·정책 | 시사가 정답 결정, 인과 오류 |
| English Language | 근거 기반 수사·논증·구조·쓰기 | 복수 정답, 근거 없는 해석, 어휘만으로 난이도 |

## Calculus AB
- 지침: 한 문항에 표현 둘 이상(식↔그래프↔표) 연결, 계산은 손으로 가능한 수준, FRQ는 "이유/정당화" 행 포함.
- 합격 예: "The graph of f′ on [0,8] is positive on (0,2), negative on (2,5), positive on (5,8), and f′ is increasing on (3.5,6.5). Which is true about f?" 정답 = x=2 국소 최대, x=5 국소 최소, (3.5,6.5)에서 위로 오목. 오답 = 최대/최소 뒤바꿈(부호 방향 혼동), 같은 구간 아래로 오목(f′ 증가↔f 증가 혼동), x=3.5 국소 최소(f′ 최솟값 오독). 스킬 2.D 주 / 3.D 보조.
- 반려 예: 같은 틀 "∫₀¹(ax²+bx)dx를 계산" 숫자만 바꿔 5문항(공식 대입 반복); "f(x)=(x²+1)⁷e^{3x} sin 2x의 f″(0.37)"(불필요한 계산·시간 낭비).

## Calculus BC
- 합격 예: "Σₙ₌₁^∞ (−1)ⁿ n/(n²+3)은?" 정답 = 조건부 수렴(교대급수 검정: 항 감소 n≥2·극한 0; 절대값 급수는 ~1/n 비교로 발산). 오답 = 절대 수렴(조건 확인 누락), 발산(n항 검정 오용). 3.C 주 / 3.D 보조.
- 반려 예: AB 도함수 문항에서 "f(x)=x^3.7+…, x=1.236에서" 숫자만 지저분; "Raabe 검정을 사용해" 또는 "Laplace 변환" 요구(범위 밖).

## Statistics
- 합격 예: "서로 다른 생산 라인에서 무작위 추출한 배터리 수명 표본 각 40개, 분포는 거의 대칭. 두 브랜드 평균을 비교하는 절차와 점검할 조건은?" 정답 = 두 표본 t 검정/구간, 독립 무작위 표본·표본 크기/정규성 점검·(비복원 추출 시 10% 조건). 오답 = 대응표본 t(독립성 혼동), z 검정(σ 미지), 비율 검정.
- 반려 예: "t = (x̄−μ)/(s/√n)을 계산기로 구하시오"만 묻는 문항; 관찰 연구에서 "그러므로 X가 Y를 일으킨다"를 정답으로 둔 문항; 삭제 주제(기하분포, 카이제곱 적합도) 출제.

## Biology
- 합격 예(자료 세트): 효소 활성 표. 억제제 있을 때 속도가 8 mM에서는 약 40% 낮지만 128 mM에서는 약 6% 낮음. "자료로 가장 잘 지지되는 주장은?" 정답 = 기질이 많아지면 억제가 상당 부분 극복되므로 경쟁적 억제와 일치. 오답 = 효소 영구 변성(고농도에서도 큰 차이가 남아야 함), 억제제가 기질 결합 없이 활성만 절반(비경쟁 억제는 최대 속도 저하), 기질 농도와 무관(자료 반대). 6.B 주 / 4.B·5.A 보조.
- 반려 예: "ATP를 만드는 세포소기관은?"(암기); n=3 자료로 "약이 질병을 치료함이 증명됨"(근거 없는 결론).

## Chemistry
- 합격 예: "0.10 M 약산 HA 용액의 pH가 3.0이다. Ka에 가장 가까운 값은?" 정답 ≈ 1.0×10⁻⁵ ([H⁺]²/(0.10−0.0010)). 오답 = 1.0×10⁻³([H⁺]를 Ka로 혼동), 1.0×10⁻⁶([H⁺]²만 쓰고 분모 누락), 1.0×10⁻⁴(분모에 0.010을 잘못 사용). 입자 그림(대부분 HA) 제공 변형 가능.
- 반려 예: 단위 오류(예: ΔH를 J/mol 값에 kJ/mol로 표기), 조건 누락(온도·압력 없는 기체 법칙), 개념 없이 긴 산술 체인.

## Physics 1
- 합격 예: "속도–시간 그래프가 직선으로 t=0에서 +4 m/s, t=3 s에서 −2 m/s. 옳은 설명은?" 정답 = 가속도 −2 m/s²로 일정, t=2 s에서 순간 정지, 알짜힘은 음의 방향. 오답 = t=2 s에서 가속도 부호 변경, 그 순간 알짜힘 0, 가속도 0. 
- 반려 예: "m=3.47, a=9.13, F=?" 공식 대입; 3차원 벡터 외적·미적분 요구(범위 밖 수학).

## Computer Science A
- 합격 예(코드 추적): `int[] a={3,1,4,1,5}; int count=0; for(int i=1;i<a.length;i++) if(a[i]>a[i-1]) count++;` 실행 뒤 count = 2. 오답 = 3(비교 방향·경계 오류), 4, 0. 실제 Java 실행으로 검증.
- 반려 예: 스트림·람다 사용(범위 밖); 해설의 출력값이 실제 실행 결과와 다름.

## Microeconomics
- 합격 예: "완전경쟁 시장에서 수요가 증가하고 동시에 투입 요소 가격이 하락했다. 균형 가격·수량은?" 정답 = 수량 증가, 가격 변화 불확실. 오답 = 둘 다 증가, 가격만 하락·수량 불변 등. 2.A.
- 반려 예: "취향 변화로 어떤 곡선이 이동하는가"에서 "수요 증가"와 "수요곡선 우측 이동"이 모두 선택지(복수 정답/이동 불명확); "독점기업은 MR=MC에서 P=MC"를 정답으로(모델-결론 불일치).

## Macroeconomics
- 합격 예: "중앙은행이 공개시장에서 국채를 매입했다. 다른 조건이 같을 때 단기 효과는?" 정답 = 통화 공급 증가, 명목금리 하락, 투자·총수요 증가. 오답 = 금리 상승, 총공급곡선 이동만, 통화량 감소. 
- 반려 예: "지난달 금리를 올린 나라는?"(시사); "실업이 줄었으므로 인플레이션이 원인이다"를 정답(인과 오류).

## English Language
- 합격 예(독창 지문 ~120단어): "3문단에서 통계 서술에서 개인 일화로 옮겨 가는 전환이 주로 하는 역할은?" 정답은 지문 근거 문장 인용 가능, 선지 간 의미 중복 없음. 쓰기 세트: 문장 결합·논지 강화 수정.
- 반려 예: 두 선지가 모두 방어 가능(복수 정답); 지문 근거 없는 해석; 단어 "perfunctory"를 알아야만 풀리는 어휘 의존 난이도.
