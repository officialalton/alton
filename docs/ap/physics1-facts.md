## 1. 검증된 사실

| 항목 | 확인 결과 | 출처 |
|---|---|---|
| 시험 총 길이 | **3시간**: MC 42문항 + FRQ 4문항 | CED p.170 |
| MC | **42문항·85분·50%**. 샘플 15문항은 전부 **단일 정답 4지선다(A–D)**, 복수 선택 형식 없음 | CED p.170, p.176–192 샘플 |
| MC 세트 | [AP-exam]: "discrete questions and question sets based on a shared stimulus". 샘플에 **2문항 세트 1개(Q4–5, v–t 그래프)**. **정확한 세트 수·크기는 공식 미공표**(Stats처럼 "3문항 세트 2개"에 해당하는 명시 없음) → UNVERIFIED | [AP-exam], CED p.178(Exam Information) |
| FRQ | **4문항·95분·50%**. 순서·유형 고정: Q1 Mathematical Routines(MR) / Q2 Translation Between Representations(TBR) / Q3 Experimental Design and Analysis(LAB) / Q4 Qualitative/Quantitative Translation(QQT) | CED p.170, p.173–174 |
| **FRQ 배점** | MR **10점**, TBR **12점**, LAB **10점**, QQT **8점** → 합 **40점**(문항별 균등 아님) | CED p.173–174 |
| **FRQ 권장 시간** | MR 20–25분, TBR 25–30분, LAB 25–30분, QQT 15–20분(합 85–105분, 95분 내 배분). Stats와 달리 **공식 명시** | CED p.173–174 |
| FRQ 스킬 | MR: 1.A 1.C 2.A 2.B 3.B 3.C / TBR: 1.A 1.C 2.A 2.D 3.B 3.C / LAB: 1.B 2.B 2.D 3.A / QQT: 2.A 2.D 3.B 3.C | CED p.173–174 |
| FRQ 내용 | MR: 기호 유도+수치 계산+표현(자유물체도 등) 작성, 주장·예측과 정당화. TBR: 시각 표현 작성 → 식 유도 → 그래프 → (두 파트 일치 정당화 / 다른 상황 예측 / 조건 변경 시 표현 변화 예측) 중 하나. LAB: 설계(한 변수 변화·한 특성 측정, 고교 실험실 장비, 불확실성 감소) + 제공 데이터로 선형 그래프 작성·분석(기울기·절편). QQT: 주장·정당화 + 식 유도 + 일치/예측/변경 중 하나(표현 작성은 점수 대상 아님) | CED p.173–174 |
| **"paragraph argument" 유형** | **2027 CED에 별도 유형 없음.** 정당화(justify)는 MR·TBR·QQT 파트 안에서 요구되고 task verb "Justify"로 정의됨. (구 과정의 문단 논증 FRQ와 혼동 금지) | CED p.173–175 |
| 채점 구조(샘플 4문항) | **분석적 채점, 대부분 1점짜리 행**(예: LAB 파트 A=2행·B=2행·C(그래프 선택·점 찍기·추세선 등)…, 합 10). 행은 "…에 대해 1 point" 형식이며 일부 행은 허용 답 목록("Accept ONE of the following")·Scoring Note·Example Response 포함. 표현(자유물체도) 행은 라벨 허용 목록까지 규정 | CED p.196–205 |
| 계산기 | **4칙·공학용·그래핑 계산기 모두 허용, 두 섹션 모두**(파트 분할 없음) | CED p.170 |
| 공식 참조 자료 | 수식·참조 정보는 시험 중 제공(인쇄 + Bluebook). [AP-exam]은 "equation sheet"라 부르지 않고 "reference information"으로 안내. **수식 목록 본문은 이번에 대조하지 않음** → UNVERIFIED(내용), 존재는 확인 | [AP-exam], CED p.176 이하("equation from the reference information") |
| 전달 방식 | **하이브리드**: MC·FRQ 문제는 Bluebook에서 표시, **FRQ 답은 종이 책자에 손으로 작성·회수**. Stats·CS A·Eng Lang(완전 디지털)과 다름 | [AP-exam] |
| 시험일 | 2027-05-05(수) Session 2 | [AP-exam] |
| 단원 MC 가중 | U1 10–15, U2 18–23, U3 18–23, U4 10–15, U5 10–15, U6 5–8, U7 5–8, U8 10–15 (%) | CED p.171 (JSON과 일치) |
| 스킬 MC 가중 | 2.A 15–20, 2.B 20–25, 2.C 10–15, 2.D 10–15, 3.B 20–25, 3.C 5–10 (%). **Practice 1(1.A–1.C)과 3.A는 MC에서 평가하지 않음** | CED p.172 (JSON과 일치) |
| 스킬 FRQ 가중 | 표현 생성(1.x) 20–35, 수학 루틴(2.x) 30–40, 과학적 질문·논증(3.x) 35–45 (%) — Practice 단위 | CED p.172 (JSON과 일치) |
| 모형 가정 | 별도 언급 없으면 관성계, 공기저항·마찰·항력 무시, 줄·용수철·도르래 이상적 — 생성 지침의 기본 가정으로 사용 | CED 부록 p.207 부근(모형·가정 절) |
| 내용 범위 | **8단원**(운동학·힘·일에너지·운동량·토크·회전 에너지·진동·유체). **전기회로·파동·전하·열역학은 2027 CED에 없다**(본문에 "circuit" 0회). 따라서 회로도·파동 그림은 불필요 | CED 전체 검색 |
| 에너지 막대 그래프 | CED가 교수 활동·샘플 TBR(Q2 파트 A)에서 **에너지 막대 차트**를 명시적 표현으로 사용 → 새 표현 필수 | CED p.64 부근(단원 교수 활동)·p.198(Q2 채점) |

## 3. 남은 UNVERIFIED
1. MC 공유 자료 세트의 개수·크기(샘플엔 2문항 세트 1개).
2. 공식 수식·참조 정보 본문(목록 구성, 상수 값 제공 방식). 우리 패널은 자체 문구로 재구성해야 하며 본문 대조가 선행.
3. Bluebook 내 계산기 제공 여부·형태(CED는 4칙/공학용/그래핑 허용만 명시).
4. FRQ 답안을 **앱에서 어떻게 받을지**는 공식 사실이 아니라 제품 결정(실제 시험은 종이 손글씨).
5. 샘플 15 MC의 분포는 시험 분포를 대표하지 않는다고 CED가 명시.
