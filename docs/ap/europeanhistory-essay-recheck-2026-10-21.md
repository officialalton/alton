# AP European History 에세이 채점 — 개선 로직 새 표본 재검증 (2026-10-21)

이 문서는 실행 **전**에 설계·합격 기준을 먼저 고정하고, 실행 후 §R(결과)을 덧붙인다. §0–§3 은 결과를 본 뒤 바꾸지 않는다.
공식 College Board 문제·샘플·루브릭 원문은 어디에도 입력·저장·인용하지 않았다. 문항·자료·응답은 모두 ALTON 자작이며 자료는 시대풍 문서(진짜 1차 사료 아님)다.

## 0. 무엇을 검증하나 / 무엇을 검증하지 못하나
- 대상: 개선된 채점 구조 `lib/essay-grading/checklist.ts`(요소별 사실 판정 → 코드가 점수 합산) + 운영 경로 설계 `review-policy.ts`(기본 1회 + 조건부 추가 검토, 미해결 시 "Scoring under review"). 둘 다 운영 경로에 연결되지 않은 꺼진 코드.
- 검증하지 못함: 공식 채점 정확성, 실제 학생 응답 분포, 2027 개편 형식. **AI 평가자들끼리의 일치는 공식 채점이 맞다는 증거가 아니다**(같은 모델 계열이 같은 루브릭 정의를 읽고 판단하므로 오류가 상관될 수 있다). 사람 채점은 진행하지 않으며, 이 문서의 어떤 결과도 "공식 채점 정확성을 입증했다"로 읽으면 안 된다.
- 기존 표본(`data/ap/euro-selfcheck`)은 수정용·회귀 참고용으로 보존, 이번 평가에는 쓰지 않는다. 새 표본: `data/ap/euro-selfcheck-2`.

## 2. 기준 요소 판정 — 작성·검토·채점 분리
1. **작성**: 이 에이전트가 응답을 썼다(의도 점수대는 정답으로 쓰지 않음).
2. **독립 평가자 2명(E1·E2)**: 같은 응답을 서로 다른 프롬프트·요소 순서(E2는 역순)로 각각 한 번 평가. 서로의 판단·작성자 의도 점수는 보지 않는다. 요소마다 점수와 답안 인용 한 구절, 근거를 낸다. 평가 기준 문구는 현행 `euro-v1` 요소 안내(체크리스트 구조 아님 — 채점 대상 로직과 독립).
3. **이견 재판정(adjudicator, 별도 호출)**: E1·E2 점수가 다른 **요소만** 대상으로 두 평가자의 점수·인용·근거와 답안을 보고 요소 점수를 정하고 `confident` 여부를 낸다. 같은 모델이 한 번만 부른다.
4. **미합의**: 재판정이 `confident=false`인 요소. 미합의 요소가 하나라도 있는 응답은 총점 지표에서 제외(요소 지표에서도 그 요소 제외)하고 개수를 따로 보고한다. 억지로 한 점수로 확정하지 않는다.
5. **합의 기준 총점** = 모든 요소가 (E1=E2) 또는 (재판정 confident)인 응답의 요소 합. 무관·조작 응답은 기준 판정 없이 구성상 기준(무관 0점, 조작 = 원본 짝의 결과)으로 다룬다.
**다른 모델 계열**: 환경에 `ANTHROPIC_API_KEY` 하나만 있다(다른 제공자 키 없음, 새 키는 요구하지 않음). 그래서 평가자 모두 현행 모델 `claude-sonnet-5-5`로 진행한다. 신모델은 temperature 조정이 불가해 **프롬프트·요소 순서 분리**만 한다. 이 한계는 §R 에도 적는다.

## 3. 채점 대상 실행과 합격 기준 (사전 등록)
채점 대상: 새 구조 체크리스트 채점기. 운영 경로 설계대로 **기본 1회**, `reviewTriggers`(형식 오류·합계 불일치·근거 누락·불확실 요소·조작 의심) 중 하나라도 있으면 추가 호출(총 최대 3회), 합의되지 않으면 **under_review(점수 없음)**. 전체를 독립적으로 두 번(rep1·rep2) 실행해 반복 변동을 잰다. 예산이 모자라면 rep2는 일부만 하고 그 사실을 적는다(rep1 우선).
합격 기준(기존 `selfcheck` §0.2 의 수치를 그대로 유지, 합의 기준에 맞춰 정의만 명시. **결과를 본 뒤 바꾸지 않는다**):
| # | 기준 | 정의 |
|---|---|---|
| P1 | 총점이 합의 기준 ±1 이내 ≥ 85% | 합의 응답 중 점수가 나온 것 |
| P2 | 정확 일치 ≥ 60%, ±1 이내 ≥ 90% (DBQ ±1 ≥ 85%) | 유형별 병기 |
| P3 | 평균 부호 오차(AI−기준): 과대 쪽 ≤ +0.25, 보수 쪽 ≥ −0.75 | |
| P4 | 문항 안 서열 반전 0 | 기준 총점이 높은데 AI 총점이 낮은 쌍 |
| P5 | 요소 정확 일치 ≥ 80%(합의 요소만), 어느 요소도 평균 편향 ≥ +0.3 불가 | |
| P6 | 길고 근거 빈약(LEQC-4, DBC-4) AI 총점이 합의 기준 총점을 넘지 않음 | 하드 |
| P7 | 조작: 원본 짝보다 높은 점수 0, 합의 기준 초과 0(under_review 는 허용) | 하드 |
| P8 | 무관 응답 총점 ≤ 1 | |
| P9 | 같은 응답 rep1·rep2 최종 총점 차 ≤ 1 이 ≥ 90%, 요소 완전 일치 ≥ 80% | 둘 다 점수가 나온 응답 |
| P10 | 형식 불량 최종 실패 ≤ 5% | |
| P11 | under_review 비율(조작 의심 응답 제외) ≤ 15% | 신규(운영 경로 설계 반영) |
| P12 | 미합의 요소 ≤ 25%(기준 요소 중) | 초과 시 기준이 불충분하므로 **판정 보류(inconclusive)** |
**n 이 매우 작다**(합의 응답 최대 LEQ 7·DBQ 4). 비율 하나가 8~25%p 이므로 "통과"는 "이 표본에서 모순이 관측되지 않았다"일 뿐 검증이 아니다. 미달·보류 시 **자동 반복하지 않고** 원인과 다음 수정안을 보고한다.
