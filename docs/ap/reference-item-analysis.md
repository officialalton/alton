# 참조 문항 분석 계획과 결과 (Calc AB · Biology · Microeconomics 실분석, 나머지 7과목은 선정 목록·방법)

## 0. 중요한 사실(조사 결과)과 방법 제약
- **공식 공개 MC는 AP Central에 없다.** 과거 시험 페이지는 최근 3개년(2023~2026) FRQ·채점 가이드·(2023~2025) 샘플 응답만 제공하고, MC는 교사 인증 AP Classroom(보안 문서)에 있다(2026-10-08 AP Central 확인). 따라서 **공개 MC 참조원 = 현행 CED의 "Sample Exam Questions"**(과목당 약 15~22문항, 정답·스킬·LO 표 포함), **FRQ 참조원 = CED 샘플 FRQ + 최근 3개년 공개 FRQ**.
- 목표 15~20 MC는 일부 과목(Calc AB 15, Bio 15, Micro 15)에서 CED 샘플만으로 15개가 한도다. 16~20개로 늘리려면 AP Classroom(교사 계정) 접근이 필요 → **결정 사항(open-decisions #16)**.
- **분석만 한다.** 문항 텍스트·그림·표는 서비스 DB·프롬프트·코드·학생 화면에 복제하지 않는다. 분석 노트에는 출처 ID(CED 쪽수·문항 번호)와 요약 서술만 기록한다. 분석 노트는 `reference_analyses`(관리자 전용, 학생 비노출, 생성 프롬프트에는 "구조 지침 요약"만 주입)에 저장.
- **풀 시험 난이도를 재현했다고 주장하지 않는다**: 참조 분석은 구조·스킬·오답 매력도 설계 기준을 얻기 위한 것이며, 난이도 근거는 별도(교사 판정 → 학생 데이터)로 둔다.
- 시간 추정은 분석자 추정치(초), 학생 데이터 아님. 오답 분석은 선지 구조에 근거한 **추정 오개념**이며 학생 응답 통계가 아님.
- 분석 항목: 학습 목표·스킬 / 핵심 추론 / 자료 역할 / 선지별 오개념 / 읽기·계산 부하와 시간 / 난이도 근거 / (FRQ) 부분 점수·허용 답안.

### Calc AB FRQ 분석에서 확인된 공통 설계(→ `subject-quality-standards.md`·`data-design.md` 반영)
1. **점수 행은 "형식(setup) / 답 / 정당화 / 해석·단위"로 분리**되고, **정당화 행은 조건 검증**을 요구한다(IVT·MVT·로피탈·FTC). MC 설계에서도 조건 확인 오답을 만든다.
2. **의존 사슬**: 해 구하기(5점)처럼 앞 단계가 없으면 뒤 점수 없음 → 루브릭 행에 `requires_row`(선행 행) 필드 필요.
3. **반올림은 한 문항에서 최대 1점만 감점**, 소수 셋째 자리 규칙 → 행 단위 `rounding_rule` 필드.
4. **허용 표현 목록**(동치 적분, 쉘/원판법, 이유 문장 변형)과 **앞 파트 오답을 이어받은 특례**(special case) → `alt_solutions`, `follow_through` 필드.
5. 단위·해석 점수는 파트 안에 소수(1점)로 존재 → 단위 누락이 계산 점수를 깎지 않도록 행 분리.
6. 난이도는 **계산량이 아니라 설정·재표현·조건 정당화**에서 발생(계산은 계산기 허용 파트에서만 수치 적분). 같은 유형이 매년 반복되므로 **구조 템플릿(6유형)** 단위로 재고를 관리한다.

### Bio FRQ 분석에서 확인된 공통 설계
1. **한 번들(자료 하나)에 파트가 서술→자료 읽기→계산→예측→정당화 순으로 위계**; 짧은 문항(4점)은 항상 4개 1점 파트. 우리 FRQ 번들 스키마의 `part_label`·`points`=1 단위 행과 일치.
2. **행 단위 허용 답안은 "Examples of acceptable responses" 여러 개 + 괄호는 선택어구** — 루브릭의 `accepted_answers`는 핵심 요소(필수)와 선택어구를 분리 저장.
3. **그래프 작성은 3점 분해**: (유형) (정확한 점+오차막대) (축 라벨·범례) → 그래프 파트 전용 루브릭 템플릿.
4. **계산 점수는 허용 범위**(예: 97,750 허용 93,150–102,350, 3% 감소 −2.8~−3.2%) → `numeric_tolerance` 필드.
5. 통계적 구별 판단(오차막대 2SE 겹침)은 **자료에 SE가 있는 표/그래프를 반드시 제공**해야 함 → 자료 완결성 검사 항목.
6. 시험이 **공식 수식·표를 제공**(하디-바인베르크, 카이제곱 임계표, 확률 법칙 등) → 생성 문항은 제공 수식 밖 공식을 요구하지 않는다.
7. 정답은 "개념 서술"이어서 AI·사람 채점 모두 **핵심 요소 채움 여부**가 기준 → AI 채점 평가 때 행별 일치율을 측정.

### Micro FRQ 분석에서 확인된 공통 설계
1. **번들 하나가 한 시장/기업 시나리오를 공유하고 파트가 그래프 → 변화 효과 → 계산 → 서술 순**으로 이어진다(긴 문항: 그래프 5점 + 1점 파트들). 파트 간 재사용(그래프 위에 변화 표시)이 핵심 → 번들 `stimulus`가 파트 간 공유 상태를 가져야 함.
2. **그래프 점수는 요소별 1점**: 곡선 형태 / 균형 라벨 / 이윤극대 조건(MR=MC) / ATC 위치 조건(탄젠트·MC가 ATC 최저점 통과) / 면적 음영. → 그래프 문항은 `graph_elements[]` 루브릭 템플릿 + 자기 채점 체크리스트.
3. **"단언 + 설명"이 하나의 점수**(둘 다 충족해야 1점) → 루브릭 행에 `requires_both`(claim, explanation) 구조.
4. **수치로 설명해야 한다는 지시**(Explain using numbers)가 반복 → 채점에 필수 수치 인용 필드.
5. 허용 대체 서술이 명시("It is also acceptable…") → `alt_solutions`.
6. 같은 주제가 매년 변형 반복(독점 그래프, 가격 하한, 게임이론, 생산함수·한계분석) → **번들 유형 템플릿 8~10개**로 재고 설계 가능.
- 난이도는 계산이 아니라 **그래프 위 조건(ATC 접선 등), 파트 간 일관성, 한계 분석 서술**에서 발생.
