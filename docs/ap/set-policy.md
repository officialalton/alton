# AP 세트 정책 통합본 (2026-10-09, 오너 결정 반영)

1. **세트 종류와 라벨**: 완성 모의고사("Full Practice Exam")는 해당 연도 공식 구성(섹션·문항 수·시간·배점·단원/스킬 구성·계산기 파트)을 **모두** 만족할 때만 붙인다(`fullPracticeLabelAllowed`). 부분 연습은 "AP Calculus AB — Non-Calculator Practice", "AP Calculus AB — Calculator Practice", "AP Calculus AB — Free-Response Practice"(상수 `partialSetName`). 제목·배지·시작 안내는 같은 의미를 전달하고(`partialBadge`, `partialStartGuidance`) **FRQ 세트도 계산기 사용을 표시**한다(Part A 계산기 허용·Part B 계산기 불가). 공식 구성을 못 채운 세트에 "Full" 을 붙이지 않는다. "과목당 N세트" 공개 표기는 N개가 실제로 검증·완성된 뒤에만.
2. **겹침 정책(하나)**: `OVERLAP_DEFAULT = { full: 0, partialFraction: 0.2 }`. 완성 모의고사 세트 간 동일 문항은 **원칙적으로 없다**(기본 0). 부분 연습 세트는 문항 수의 최대 20% 겹침 허용(`planPartialSet`). **복습·재응시·오답 복습·단원 연습은 재사용 허용**. 조정은 `assemble-ap-set.ts --overlap-max N` 하나. SAT 모의고사의 세트 간 중복 0(확정 정책)은 변경 없음.
3. **첫 노출과 재노출**: 학생의 **첫 응시(first exposure)** 와 재노출(re-exposure)을 구분해 기록한다(분석·약점 판정은 첫 노출 기준). **같은 문항은 고유 재고에 두 번 세지 않는다**(재노출은 재고 수량이 아니라 응시 기록).
4. **문항군 다양성**: 숫자·문구 변형은 한 문항군이다. 세트당 군 집중 상한(MC 군당 2개, FRQ 군당 1개 = 서로 다른 유형)과 서로 다른 문항군 하한을 둔다. FRQ 6개를 소수 원형의 수치 변형으로 채우지 않는다.
5. **재고 목표**: 초기 AB 목표 = MC 100 + FRQ 12 번들(무료 부분 연습 + 풀 세트 1개 칸용), 칸 단위(단원 × 계산기 사용 × 표현 × 스킬 범주 × 문항군 × FRQ 유형, 마이그레이션 404)로 관리하고 **총 auto_passed 와 칸별 부족을 따로 보고**한다. FRQ "6유형"은 내부 구성 기준이며 공식 고정 목록이 아니다. 수업 용도 목표는 실제 수요가 확인될 때까지 두지 않는다. 10과목 × 10세트 최종 목표는 `docs/ap/ten-set-plan.md`(예산 승인 아님).
6. **게시**: 최신 자동 게이트 통과 + 렌더 검증 + 학생 화면 검증 + 생성기 결함 없음이 게시 조건이고 전문가 검수는 게시 후 오류 신고 흐름이다.
