## 표시 요청 3과목 요약(Statistics·Calculus·Physics)
- **Statistics: 가장 큰 변경.** 구 CED 기반 자료(문항·교재·유튜브 해설)와 호환 안 됨. 반드시 신 CED 기준으로 단원·태그 설계. 삭제 주제(기하분포·카이제곱 적합도·기울기 추론 등)는 생성 금지 목록으로 관리.
- **Calculus AB/BC: 내용 불변, 시험 형식만 변경(확정).** AB·BC 모두 42문항·100분(파트 A 29/B 13, 62분/38분).
- **Physics 1: 8단원, 42문항·85분, FRQ 95분.** 유체 단원은 Physics 2에서 이동.

## 라벨 규칙(오너 브리프 §반영)
- 풀 구조(MC+FRQ, 위 문항 수·시간·계산기 파트)를 공식과 동일하게 갖춘 세트만 **"Full Practice Exam"**(풀 모의고사). 시간 규칙은 이 표에서 자동 파생.
- MC만 있는 세트: **"AP Multiple-Choice Practice"**. FRQ만: **"AP Free-Response Practice"**.
- AP 1~5 환산 점수는 표시하지 않는다(검증 계획 승인 전). 결과 화면은 정답률·단원별 약점·FRQ 자기 채점 참고만.
- 학생 화면은 영어(오너 확정). 관리자는 한국어.
