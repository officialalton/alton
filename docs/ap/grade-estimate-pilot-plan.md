# AP 예상 등급 — 파일럿 계획서 (2026-10-21, 제안 단계)

상태: **제안.** 이 문서의 모든 수치(표본·합격 기준·비용 상한)는 실행 전 오너 확인을 받는 제안값이다. 승인 전에는 학생 모집·연락, 유료 AI 호출, 예상 등급 표시를 하지 않는다. 합격 기준은 **실행 전에 고정**하고 결과를 본 뒤 맞추지 않는다(변경하려면 새 파일럿 ID + 오너 승인).
입력: `docs/ap/grade-estimate-audit-2026-10-21.md`(감사표 — 경계점 값은 18과목 모두 없음).

## 1. 대상·단계

| 단계 | 내용 | 비용 | 선행 |
|---|---|---|---|
| 0. 근거 확보(무료) | College Board 공개 자료에서 각 과목의 ① 시험 구조 ② 복합점수→등급 구간 공개 여부 ③ 적용 연도를 1차 문서로 확인하고 §2 재사용 조건 판정표를 채운다. 못 구하면 "외부 추정 없음"으로 기록 | $0 | 없음 |
| 1. AI 채점 정확도(유료·소액) | 공식 공개 채점 샘플(과거 시험 문항별 High/Mid/Low 샘플과 점수)로 FRQ AI 재보정: 유럽사 신규(필수), 영어·문학·미국사·세계사 재확인. 현재 보정은 ALTON 자작 샘플 기반 | ≤ $12 | 오너 승인 |
| 2. 그림자 계산(무료) | 4개 우선 과목의 풀 구성 응시에서 합산 점수·예상 범위를 **숨긴 채** 스냅샷으로만 저장(`ap_attempt_score_snapshots`, `display_state='hidden'`). 이미 켜진 FRQ AI 채점 비용 외 추가 없음 | $0 추가 | 구현 계획 M1~M2 |
| 3. 실제 성적 대조(학생 참여) | 아래 §3. 모집·연락은 이 계획 승인 후 | ≤ $48 + 인건비(§6) | 오너 승인 |
| 4. 판정 | §5 기준 평가 → 과목별 표시 여부 보고 → 오너 승인 시 활성화 | $0 | 3단계 |

**대상 과목**: English Language, English Literature, U.S. History, World History: Modern(우선 4과목, 감사 §4). European History 는 1단계 통과 후 합류. 나머지 13과목은 FRQ 점수 수단이 생길 때까지 제외(결과 분석만).
**대상 세트**: 각 과목의 공개 풀 세트(2개씩) 전부. 세트가 2개뿐이므로 "세트 일반화" 결론은 내리지 않는다 — 세트별 결과를 따로 보고하고, 새 세트가 추가되면 §7 동등성 점검을 거친다.

## 2. 환산 근거 재사용 조건 (0단계 판정표 양식)

비교 자료를 환산 근거로 쓰려면 아래 4개가 모두 "예"여야 한다. 하나라도 "아니오/미확인"이면 값 성격은 "외부 추정"(표시 불가, 참고용)이다.

1. 같은 시험 구조(문항 수·배점·섹션 비중·채점 기준)인가 — 2027 구조 변경 과목(§감사 5)은 이전 연도 자료가 "아니오".
2. 공개 출처·연도·문서를 특정할 수 있는가.
3. 우리 문항의 난도·단원·스킬 분포가 그 자료의 시험과 비교 가능하다는 증거가 있는가(문항 응답 자료 또는 전문가 판정). 자체 생성 문항이므로 기본은 "아니오"이고 파일럿(3단계)이 이 증거 역할을 한다.
4. 공식 등급 분포(몇 %가 몇 점)만으로 경계를 역산한 값이 아닌가 — 역산값은 근거로 인정하지 않는다.

파일럿의 환산 방식: 학생의 실제 AP 등급을 정답으로 삼아, 우리 합산 점수(0~100)와의 관계에서 등급 경계를 **경험적으로** 추정(순서형 모델 또는 경계 탐색)한다. 따라서 값 성격은 "내부 임시(파일럿 검증 전)" → 검증 통과 시 "내부 검증됨"이며, 공식값이라 부르지 않는다.

## 3. 학생 구성·표본·응시 조건 (3단계)

- **표본**: 과목당 **40명**(최초 응시·사전 노출 없음 기준), 4과목 160명. 재응시 보조 표본 과목당 10명. 최소 승인 표본 = 과목당 40명(미달이면 판정 보류, 표시 불가). 표본 40의 의미: 정확 일치율 ±15%p, 1등급 이내 일치율 90% 관찰 시 하한 약 77%(Wilson 95%) — 이보다 작은 표본은 §5 기준을 검증할 수 없다.
- **모집 대상**: 2027년 5월 해당 과목 실제 AP 응시 예정 학생(자발 참여, 보호자 동의 포함). 한국·미국 거주 구성 비율과 학년을 기록한다. **모집·연락은 이 계획 승인 후**이며 지금은 하지 않는다. 사례비 여부·금액은 오너 결정(§8).
- **비교 기준(정답)**: 실제 AP 성적(2027년 5월 시험, 성적 공개 7월경) 자발 제출 + 확인 방법(스크린샷·성적표) 기록. 5월 이전 보조 기준으로 College Board 공개 시험의 공식 환산이 확인되는 경우에만(0단계) 보조 대조 사용 — 확인 전에는 가정하지 않는다.
- **응시 조건**: 한 번에 시간 제한을 지킨 풀 구성 모의고사 완료(서버 기준 시간, 부분 세트 제외), 시험일 8주 이내, 실제 시험과의 시점 차이 기록, 공부량·수업 병행 여부 설문(선택).
- **구분 라벨**(스냅샷 컬럼): 최초 응시 / 재응시(회차), 사전 노출(해당 문항을 수업·과제·이전 모의고사에서 본 적 있음 — 기존 최초 노출/재노출 구분 사용), 테스트 계정 제외(`students.is_test_account`), 내부·교사 계정 제외. 주 분석은 **최초 응시 + 사전 노출 없음**만. 재응시·노출 표본은 별도 보고하고 주 지표에 섞지 않는다.

## 4. 지표 (과목별, 세트별 병기)

1. 정확 등급 일치율.
2. 1등급 이내 일치율(+ Wilson 95% 구간).
3. 평균 오차(예상 − 실제, 등급 단위)와 평균 절대 오차.
4. 과대평가율(예상 > 실제)·과소평가율, 2등급 이상 과대 건수.
5. 경계 부근 오차: 합산 점수가 추정 경계에서 ±3점 이내인 응시의 불일치율(보고용, 합격 기준 아님).
6. **FRQ 채점 오차**: 교사(또는 2차 채점자)가 같은 에세이 최소 40건/과목을 독립 채점 → AI 대 사람 차이(문항 점수, 총점), ±1 이내 비율, 평균 부호 편향.
7. **환산 오차**: 사람 채점 FRQ로 만든 합산 점수 → 예상 등급 vs 실제 등급. 지표 6·7을 분리해 AI 오차가 최종 등급을 얼마나 바꿨는지(AI 합산 vs 사람 합산에서 등급이 다른 응시 비율)를 따로 보고한다.
8. 예상 범위 폭과 실제 등급 포함률(범위가 2등급 초과면 표시 불가).

## 5. 합격 기준 (제안 — 실행 전 고정)

과목별로 판정한다(과목 간 합산 금지). 모두 **주 분석 집단(최초·노출 없음) n ≥ 40**에서:

| # | 기준 | 임계 |
|---|---|---|
| 1 | 1등급 이내 일치율 | 관찰 ≥ 90% **그리고** Wilson 95% 하한 ≥ 75% |
| 2 | 정확 일치율 | ≥ 45% |
| 3 | 평균 부호 오차 | −0.3 ~ +0.3 등급 |
| 4 | 과대평가 | 1등급 이상 과대 ≤ 20%, 2등급 이상 과대 0건 |
| 5 | FRQ AI 대 사람 | 에세이 총점 ±1 이내 ≥ 90%, 평균 절대 오차 ≤ 0.5, 프롬프트 주입 시험에서 점수 상승 없음 |
| 6 | AI 오차의 등급 영향 | AI 합산과 사람 합산의 등급이 다른 응시 ≤ 15% |
| 7 | 범위 | 데이터에서 도출한 범위(경험적 포함률 ≥ 80%)의 폭이 2등급 이하인 응시 ≥ 85% |

미달 항목이 있으면 그 과목은 등급 숨김 유지 + 원인 보고. 일부 통과로 "조금 낮춰서" 통과시키지 않는다. 1단계(AI 재보정) 통과 기준: 공식 샘플 대비 항목별 정확 일치 ≥ 80%, 총점 ±1 이내 ≥ 90%, 서열(High>Mid>Low) 역전 0건, 주입 시험 무상승.

## 6. 비용·실행 상한 (제안)

실측 단가(`docs/ap/essay-ai-calibration.md`): 에세이 1건 ≈ $0.05(영어, 2회 채점 합), 미국사 SAQ 1문항 ≈ $0.048. 응시 1건당 AI 채점: 영어·문학 3에세이 ≈ $0.16, 역사 5건(SAQ 3 + DBQ + LEQ) ≈ $0.25~0.40(DBQ·LEQ 단가는 상향 여유 포함).

| 항목 | 산식 | 상한 |
|---|---|---|
| 1단계 공식 샘플 재보정 | 유럽사 ~30 + 4과목 재확인 ~60 샘플 × 2회 | $12 |
| 3단계 학생 응시 AI 채점 | 160(최초) + 40(재응시) = 200건 × 평균 $0.24 | $48 |
| 여유 | 재시도·실패·상향 | $15 |
| **합계 상한** | | **$75** (90% = $67.5에서 중단·보고) |

- 생성 예산($50 상한·$45 중단선)과 **별도 장부**로 관리하고 단계별 상한·최소 범위를 먼저 제출한 뒤 실행한다(증액은 단계별 승인 없는 실행 권한이 아님).
- 인건비(교사 2차 채점 약 400에세이, 사례비)는 위 상한에 포함하지 않았다 — 단가 오너 결정(§8).
- 일일·응시당 AI 상한은 기존 플래그·상한 설정을 그대로 사용(`AI_ESSAY_*`). 기본 꺼짐 유지, 활성화는 단계 승인 시에만.

## 7. 소량 표본 결과의 일반화 금지

- 파일럿 결과는 **해당 과목·해당 세트·해당 학생 집단·해당 시험 연도**에만 유효하다. 다른 과목, 새 세트, 다른 학생층(예: 상위권만 모집된 경우), 다른 해에 그대로 적용하지 않는다.
- n < 40 또는 한쪽 등급(예: 4~5점)에 쏠린 표본은 판정하지 않는다(분포 보고만). 모집 편향(자발 참여자는 성취가 높을 수 있음)을 보고서에 명시한다.
- 새 세트가 공개되면 기존 세트와의 동등성(단원·스킬 분포, 문항 난도 지표, 평균 합산 점수 차이)을 점검하고, 동등성이 확인되기 전에는 그 세트에서 예상 등급을 숨긴다.
- 18샘플·30샘플 규모의 현재 FRQ AI 보정 결과도 같은 이유로 "참고 추정치" 근거일 뿐 등급 정확성 근거가 아니다.

## 8. 오너 결정 필요

1. 파일럿 비용 상한 $75(단계별 $12/$48/$15)와 별도 장부 승인.
2. 합격 기준 §5 승인(또는 수정 — 실행 전에만).
3. 사례비 지급 여부·금액, 교사 2차 채점 시간당 단가.
4. 학생 모집 시작 시점(계획 승인 후) 및 대상(무료 회원 포함 여부, 한국·미국 비율 목표).
5. 실제 AP 성적 자발 제출의 동의 문구·보관 기간(`docs/POLICY-DECISIONS.md` 보관기간 정책과 정합 — 신규 동의 추가 금지 원칙과 충돌 여부 확인: 별도 체크박스를 늘리지 않고 계정 설정의 자발 입력으로 둘지).
