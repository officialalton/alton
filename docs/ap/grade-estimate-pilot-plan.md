# AP 예상 등급 — 파일럿 계획서 v2 (2026-10-21, 제안 단계, 오너 확정 전)

상태: **제안.** 예산($65 제안, 이전 $75 철회)과 합격 기준은 **아직 확정되지 않았다**. 확정 전에는 유료 호출, 학생 모집·연락, 예상 등급 표시, DB 쓰기를 하지 않는다. 합격 기준은 실행 전에 고정하고 결과를 본 뒤 맞추지 않는다(변경 = 새 파일럿 ID + 오너 승인).
입력: `grade-estimate-audit-2026-10-21.md`(전 과목 경계점 값 없음), `frq-scoring-roadmap.md`(FRQ 채점 없는 과목).
European History 는 이미 전달된 자체 샘플 검증 지시를 다른 에이전트가 진행 중이므로 이 계획의 예산·단계에서 **제외**한다(중복 없음).

## 0. 두 단계 구조

| | A단계: 지금 가능한 채점·합산 검증 | B단계: 예상 등급 타당성 |
|---|---|---|
| 질문 | FRQ AI 점수와 가중 합산이 **우리가 정한 기준 점수**와 얼마나 맞는가 | 합산 점수로 낸 예상 등급이 실제 AP 등급과 맞는가 |
| 기준 | ALTON 자체 샘플의 확정 점수·근거 | 학생의 실제 AP 등급(장기 추적) |
| 시기 | 지금 | 2027년 5월 시험 → 7월경 성적 공개 이후 |
| 사용자 영향 | 없음(내부 검증) | 등급은 숨김 유지; 원점수·가중 합산·피드백은 계속 제공 |
| 결과 | 채점·합산 기능 검증(등급 정확성 아님) | 과목별 등급 표시 여부 판단 자료 |

A단계 통과는 "채점기와 합산 계산이 자체 기준대로 동작한다"만 뜻한다. 등급이 정확하다는 근거가 아니다(공식 섹션 비중 적용과 예상 등급 정확성은 별개로 관리).

## 1. A단계 (지금 가능)

1. **현재 "보정 완료" 표기 정리**: 영어·문학·미국사·세계사의 기존 보정은 **자체 샘플 기능 검증**이다(실제 학생 답안 정확도 검증이 아님). 모든 문서·보고에서 이렇게 표기한다.
2. **자체 샘플 기준 점수·근거 확정**: ALTON 작성 샘플 답안 각각에 기준 점수와 요소별 근거를 사람 검토로 먼저 확정하고 잠근다(채점기 출력을 정답으로 쓰지 않는다).
3. **개발용/최종 평가용 분리**: 샘플을 개발 세트(프롬프트·루브릭 문구 조정에 사용 가능)와 최종 평가 세트(조정에 사용 금지, 버전당 1회 측정)로 나눈다. 현재 샘플은 조정과 측정에 함께 쓰였으므로 최종 평가 세트는 **새로 작성**해야 한다(과목당 최소 12샘플, 점수대별).
4. **합산 검증**: 결정적 단위 테스트(이미 추가: `result-score.test.ts`)에 더해, 완성 응시 시나리오(만점·0점·경계·미채점 혼합)를 사람이 계산한 합산과 대조.
5. 범위: 영어·문학·미국사·세계사. 유럽사는 별도 진행분을 따른다.
6. A단계 보고에 포함: 요소별 정확 일치, 문항 유형별 절대오차(§4), 서열 역전·주입 시험 결과, 실패율.

## 2. B단계 (예상 등급 타당성)

### 2-1. 경계점을 어떻게 만들 것인가 (먼저 제시)
경계점 = "가중 합산 점수(0~100) → 1~5등급" 임계값. 공식 등급 분포만으로 역산하지 않는다. 후보 방법:

1. **경험적 설정(주)**: 파일럿 학생의 합산 점수와 실제 AP 등급(정답)으로 순서형 모델(ordered logit) 또는 경계 탐색(합산 점수 구간별 최빈 등급)을 적합해 경계를 추정한다. 값 성격 = "내부 임시" → 평가 통과 후 "내부 검증됨".
2. **전문가 설정(보조)**: 공개 채점 정보를 쓸 수 있는 경우(재사용 조건 4개 충족: 같은 구조·공개 출처와 연도·난도 비교 증거·역산 아님)에만 교사 패널의 경계 판단을 시작점으로 사용. 현재 충족 과목 없음 — 0단계에서 확인.
3. **금지**: 다른 시험의 환산표를 그대로 적용하고 "검증됨"이라 부르는 것, 분포 역산.

### 2-2. 데이터 분리
- **경계 설정용 자료**와 **평가용 자료**를 학생 단위로 분리한다: 무작위 층화(합산 점수대·학년)로 학생의 50%는 경계 설정, 50%는 평가. 표본이 부족하면 학생 단위 교차검증(재응시 포함 같은 학생은 항상 같은 폴드).
- 경계 설정에 쓰지 않은 **별도 자료**(다른 학생 집단 또는 다음 시험 연도 코호트)로 최종 평가를 한다. 평가 자료가 없으면 활성화하지 않는다.
- **재응시는 독립 표본이 아니다**: 같은 학생의 여러 응시는 학생 1명으로 센다(주 분석은 최초 응시 1건). 신뢰구간은 학생 단위 군집 부트스트랩.

### 2-3. 장기 추적
실제 AP 성적은 한 번에 끝나는 조사가 아니라 장기 추적이다. 학생이 자발 제출하면 아래를 함께 연결한다: 모의 응시일, 본시험 연도, 그 사이의 추가 학습 기록(수업·과제·연습 기록은 복사하지 않고 날짜 범위로 조회). 그동안 원점수·가중 합산·피드백 제공은 계속한다. 제출 방식은 §5.

## 3. 표본과 데이터 조건

- **40명은 모집 목표일 뿐**이다. 도달만으로 등급을 활성화하지 않는다. 활성화 전 확인: ① 합산 점수대별 표본(하위·중위·상위 3구간 각 최소 8명) ② 실제 등급이 한쪽(예: 4~5)에 쏠리지 않음(각 등급 최소 3명 또는 분포 보고 후 오너 판단) ③ 독립 평가 자료 확보.
- 구분 라벨(스냅샷 컬럼): 최초/재응시, 사전 노출 문항 여부, 테스트 계정·내부 계정 제외. 주 분석 = 최초 응시 + 사전 노출 없음, 학생당 1건.
- 모집·연락은 계획 확정 후이며 지금은 하지 않는다. 사례비는 오너 결정.

## 4. 지표 (모든 지표에 분모 명시)

| 지표 | 분모 | 구간 계산 |
|---|---|---|
| 정확 등급 일치율 | 평가 집단의 학생 수(최초 응시) | Wilson 95% |
| 1등급 이내 일치율 | 같음 | Wilson 95% |
| **부호 있는 편향**(예상 − 실제, 등급 단위) | 같음 | 학생 단위 부트스트랩 95% |
| **평균 절대오차** | 같음 | 학생 단위 부트스트랩 95% |
| 과대평가율 / 과소평가율(1등급 이상, 2등급 이상 각각) | 같음 | Wilson; 0건이어도 상한 보고(3/n 근사) |
| 경계 부근 오차(경계 ±3점 이내 응시의 불일치율) | 해당 응시 수 | 보고용 |
| FRQ 채점 오차 | 문항 유형별 에세이/문항 수 | 아래 |
| 환산 오차 | 사람 채점 합산으로 예상한 등급 vs 실제 | 학생 단위 |
| AI 오차의 등급 영향 | AI 합산과 사람 합산의 등급이 다른 응시 / 이중 채점된 응시 | Wilson |

보고 원칙: 등급 일치율·과대·과소평가를 **항상 함께** 보고하고 평균 오차는 편향과 절대오차로 분리한다. **2등급 이상 과대평가가 표본에서 0건이어도 "실제 위험 0"이라 쓰지 않는다**(n=40에서 0건이면 95% 상한 약 7.5%).
**FRQ 채점 기준은 문항 만점이 달라 ±1점의 의미가 다르다**(SAQ 3점·LEQ 6점·DBQ 7점·에세이 6점 등): 문항 유형별로 (a) 정확 일치율 (b) 절대오차(점수와 만점 대비 %) (c) 채점 요소별 오류율(어느 요소에서 틀리는가)을 함께 본다. 일률 ±1 기준은 쓰지 않는다.

## 5. 합격 기준 (제안, 미확정 — 실행 전에 오너 확정 후 고정)

아래는 **제안 틀**이다. 임계값은 오너가 확정하기 전까지 가안이며, 확정 전에 어떤 데이터도 이 기준에 맞춰 조정하지 않는다.

| # | 항목 | 가안 |
|---|---|---|
| 1 | 1등급 이내 일치율 | 관찰 ≥ 90% 그리고 Wilson 하한 ≥ 75% |
| 2 | 정확 일치율 | ≥ 45% (하한 보고) |
| 3 | 부호 있는 편향 | −0.3 ~ +0.3 등급, 신뢰구간 포함 보고 |
| 4 | 평균 절대오차 | 별도 임계(오너 확정) |
| 5 | 과대평가 | 1등급 이상 ≤ 20%; 2등급 이상은 임계 + 상한 보고 |
| 6 | FRQ | 문항 유형별 정확 일치·절대오차 임계(유형별로 오너 확정), 요소별 오류율 보고, 주입 시험 무상승 |
| 7 | AI 오차의 등급 영향 | ≤ 15% (가안) |
| 8 | 범위 폭 | **일률 지정하지 않는다.** 검증 결과(경험적 포함률과 폭의 관계)를 본 뒤 오너가 한도를 정한다. 포함률 목표(예: 80%)만 사전 고정 |

미달 시 그 과목은 등급 숨김 유지. 과목 간 합산 금지. 소량 표본 결과의 일반화 금지: 결과는 해당 과목·세트·학생 집단·시험 연도에만 유효하고, 새 세트는 동등성 점검 전까지 숨김.

## 6. 예산안 (제안, 미확정)

이전 "$75"는 철회한다(공식 샘플 재보정 $12 항목은 유럽사 별도 진행분과 겹쳐 삭제). 아래는 4과목(영어·문학·미국사·세계사) 기준이며 **유럽사는 포함하지 않는다**.

| 항목 | 산식 | 상한 |
|---|---|---|
| A단계 새 최종 평가 세트 측정 | 4과목 × 12샘플 × 2회 + 개발 세트 재측정 약 30% | $8 |
| B단계 학생 응시 AI 채점 | 아래 가정 | $48 |
| 여유(재시도·단가 상향) | | $9 |
| **합계(제안)** | 90% = $58.5 에서 중단·보고 | **$65** |

B단계 가정: 고유 학생 160명(과목당 40) + 재응시 보조 40건 = **응시 200건**(재응시는 같은 학생, 독립 표본 아님). 과목군별 채점 호출: 영어·문학 응시 100건 × 3개 서술형 × 2회 = 600호출, 역사 2과목 응시 100건 × 5건(SAQ 3 + DBQ + LEQ) × 2회 = 1,000호출, 재시도 여유 15% → 약 1,840호출. 호출당 단가는 실측 약 $0.0265(영어 에세이 $0.053/2회)를 적용해 ≈ $48.8, 역사 DBQ·LEQ 단가는 여유분에 포함.
**예산에 포함되지 않는 것**: 사례비(인센티브), 사람 표본 채점 비용(교사 2차 채점 약 160 에세이 × 약 12분 ≈ 32시간, 이중 채점이면 약 64시간), 개발 인력. 오너가 단가를 정한 뒤 별도 항목으로 확정한다.
생성 예산($50 상한·$45 중단선)과 별도 장부. 단계별 상한·최소 범위를 먼저 제출하고 승인 후 실행한다(증액은 단계별 승인을 대체하지 않는다).

## 7. 환산표 활성화와 변경 이력

- 환산표(경계점)의 활성화는 **오너 승인**이 필요하다(승인자·시각 기록, 영향 보고 선제출). 모든 버전과 변경 이력을 남긴다(`ap_grade_scales` 버전, 불변 스냅샷 — 구현 계획 참고). 승인 없이 활성 상태로 전환하는 경로는 만들지 않는다.

## 8. 실제 AP 성적 제출 (설계)

- 위치: 학생이 **결과 화면·응시 기록에서 접근 가능한 선택 입력**(해당 응시 상세에서 "Add your real AP score"). 필수 아님.
- 기록: 과목, 시험 연도, 성적(1~5), 제출일, 자기보고 여부(`self_reported`), 연결된 모의 응시 id(선택).
- 성적표 이미지 제출은 **기본 필수 아님**(선택 첨부는 별도 결정 전까지 만들지 않는다).
- 동의 체크박스는 늘리지 않는다(정책 대장의 동의 4개 원칙).

## 9. 오너 결정 필요

1. 예산 $65(제안) 확정 또는 수정, 그리고 인센티브·사람 표본 채점 단가.
2. 합격 기준 §5 임계값(특히 평균 절대오차, 문항 유형별 FRQ 임계, 2등급 이상 과대평가 상한) 확정.
3. A단계 최종 평가 세트를 누가 작성·확정하는가(교사 패널 또는 오너).
4. 평가용 독립 자료의 출처(분할 vs 다음 해 코호트).
5. 모집 시작 시점과 대상.
