# AP 예상 등급 — 파일럿 계획서 v3 (2026-10-21, 제안 단계)

상태: **제안.** 예산과 합격 기준은 확정되지 않았다. 확정 전에는 신규 유료 호출, 예상 등급 표시, DB 쓰기를 하지 않는다. 합격 기준은 실행 전에 고정하고 결과를 본 뒤 맞추지 않는다(변경 = 새 파일럿 ID + 오너 승인).
**범위 제외(오너 확정)**: 교사·사람의 2차 채점, 유료 인센티브 모집. 이 계획은 사람 채점·섭외·사례비를 어떤 단계의 필수 조건으로도 두지 않는다. 유럽사의 추가 자체 샘플 검증은 별도 에이전트가 진행하며 이 계획의 예산·단계에 포함하지 않는다.
입력: `grade-estimate-audit-2026-10-21.md`(전 과목 경계점 값 없음), `frq-scoring-roadmap.md`.

## 0. 두 단계 구조

| | A단계: 지금 가능한 채점·합산 검증 | B단계: 예상 등급 타당성 |
|---|---|---|
| 질문 | FRQ AI 점수와 가중 합산이 **우리가 정한 기준 점수(자체 샘플)** 대로 동작하는가 | 합산 점수로 낸 예상 등급이 실제 AP 등급과 맞는가 |
| 기준 | ALTON 자체 샘플의 확정 점수·근거 | 이용자가 자발적으로 공유한 실제 AP 등급 |
| 시기 | 지금 | 실제 이용·성적 공유가 쌓이는 만큼(2027년 7월 성적 공개 이후 본격) |
| 사용자 영향 | 없음 | 등급은 숨김 유지; 원점수·가중 합산·피드백은 계속 제공 |

**주장 범위의 한계**: 사람 채점과의 비교는 하지 않으므로 이 계획은 "AI 채점이 공식 채점과 같다"를 입증하지 않는다. A단계는 자체 샘플 기능 검증이고, B단계는 최종 합산 점수와 실제 AP 등급의 **결과 수준 일치**만 본다. 채점기 오차는 B단계에서 별도로 측정하지 않고 민감도 분석(아래 §4)으로 등급에 미치는 영향 범위만 추정한다.

## 1. A단계

1. 영어·문학·미국사·세계사의 기존 "보정"은 **자체 샘플 기능 검증**이다(실제 학생 답안 정확도 검증 아님). 모든 문서·보고에 이렇게 표기한다.
2. 자체 샘플 기준 점수·요소별 근거를 **먼저 확정하고 잠근다**(채점기 출력을 정답으로 쓰지 않는다). 확정은 사람의 2차 채점이 아니라 샘플 작성 시 설계한 기준 점수와 ALTON 내부 검토로 한다.
3. 개발용/최종 평가용 분리: 개발 세트(프롬프트·루브릭 조정에 사용 가능)와 최종 평가 세트(조정 금지, 버전당 1회 측정). 현재 샘플은 조정과 측정에 함께 쓰였으므로 최종 평가 세트는 새로 작성(과목당 12샘플, 점수대별).
4. 합산 검증: 결정적 단위 테스트(`result-score.test.ts`) + 완성 응시 시나리오(만점·0점·경계·미채점·빈 답안·건너뜀 혼합)를 손계산과 대조.
5. 보고: 요소별 정확 일치, 문항 유형별 절대오차, 서열 역전·주입 시험, 실패율.

## 2. B단계 — 경계점 만들기와 데이터 분리

1. **경험적 설정(주)**: 자발 공유된 실제 AP 등급과 합산 점수(0~100)로 순서형 모델 또는 구간별 최빈 등급 탐색을 적합. 값 성격 "내부 임시" → 평가 통과 후 "내부 검증됨".
2. **외부 근거(보조)**: 재사용 조건 4개(같은 구조 · 출처와 연도 특정 · 난도 비교 증거 · 분포 역산 아님)를 모두 충족하는 공개 자료가 확인될 때만 시작점으로 사용. 현재 충족 과목 없음.
3. 금지: 다른 시험 환산표의 그대로 적용, 공식 등급 분포만으로 경계 역산.
4. **데이터 분리**: 학생 단위로 경계 설정용과 평가용을 나눈다(층화 무작위 또는 학생 단위 교차검증). 경계 설정에 쓰지 않은 별도 자료(다른 학생 집단 또는 다음 시험 연도 코호트)로 평가. 평가용 자료가 없으면 활성화하지 않는다.
5. **재응시는 독립 표본이 아니다**: 같은 학생의 응시는 학생 1명으로 센다(주 분석은 최초 응시 1건). 신뢰구간은 학생 단위 군집 부트스트랩.
6. **장기 추적**: 학생이 입력한 실제 성적에 모의 응시일·본시험 연도·그 사이 학습 기록(날짜 범위로 조회, 복사 없음)을 연결. 그동안 원점수·가중 합산·피드백은 계속 제공.

## 3. 자발적 참여 설계 (확정 모집 인원 없음)

- **160명은 확정 인원이 아니다.** 모집·섭외·사례비 없이, 이미 모의고사를 응시하는 실제 이용자가 결과·응시 기록의 선택 입력으로 **자발적으로** 본시험 성적을 공유하면 쌓이는 만큼 사용한다.
- 입력 항목: 과목, 시험 연도, 성적(1~5), 제출일, 자기보고 여부, 연결 응시 id(선택). 성적표 이미지는 요구하지 않는다. 새 동의 체크박스 없음.
- **참여 편향·누락 기록 항목**(분기별 보고 필수; 데이터 집계만, 개인 식별 없음):
  1. 적격 응시 수(풀 구성·채점 완료·실사용) 대 성적 제출 수 = 제출률(과목별).
  2. 제출자 대 비제출자의 모의 합산 점수 분포·학년·거주(한국/미국) 비교 — 제출은 성취가 높은 쪽으로 쏠릴 수 있으므로 비제출자의 실제 등급은 알 수 없다는 점을 보고에 명시.
  3. 모의 응시 후 본시험을 치르지 않았거나 과목을 바꾼 경우, 제출 시점 지연(성적 공개 후 N일), 중복·정정 제출.
  4. 최초 응시 / 재응시 / 사전 노출 문항 비율.
  5. 누락 민감도: 비제출자의 등급이 최악·최선인 경우를 가정한 지표 범위(경계 분석)를 함께 보고 — 제출자만의 일치율을 전체 이용자 정확도로 일반화하지 않는다.
- 활성화 판단의 최소 조건(예산 도달 여부와 무관): 합산 점수대별(하·중·상) 표본, 실제 등급의 편중 없음 또는 분포 보고 후 오너 판단, 독립 평가 자료. 표본 수만으로 활성화하지 않는다.

## 4. 지표 (모든 지표에 분모 명시)

| 지표 | 분모 | 구간 |
|---|---|---|
| 정확 등급 일치율 | 평가 집단의 학생 수(최초 응시) | Wilson 95% |
| 1등급 이내 일치율 | 같음 | Wilson 95% |
| 부호 있는 편향(예상 − 실제, 등급 단위) | 같음 | 학생 단위 부트스트랩 95% |
| 평균 절대오차 | 같음 | 학생 단위 부트스트랩 95% |
| 과대·과소평가율(1등급 이상, 2등급 이상 각각) | 같음 | Wilson; 0건이어도 상한 보고(3/n 근사) |
| 경계 부근 오차(경계 ±3점 이내 응시의 불일치율) | 해당 응시 수 | 보고용 |
| 채점 일관성(두 번 채점의 불일치율, 문항 유형별) | 이중 채점된 서술형 수 | Wilson |
| AI 오차 민감도: 합산 점수에 문항 유형별 관측 오차(A단계 자체 샘플 기준)를 가감했을 때 등급이 바뀌는 응시 비율 | 평가 집단 | 범위 |

보고 원칙: 일치율·과대·과소평가를 함께, 평균 오차는 편향과 절대오차로 분리. 2등급 이상 과대평가가 0건이어도 "실제 위험 0"이라 쓰지 않는다(n=40에서 0건이면 95% 상한 약 7.5%). FRQ는 문항 유형별(만점이 달라 ±1점의 의미가 다름)로 정확 일치·절대오차·채점 요소별 오류율을 함께 본다.

## 5. 합격 기준 (제안 틀, 미확정)

| # | 항목 | 가안 |
|---|---|---|
| 1 | 1등급 이내 일치율 | 관찰 ≥ 90% 그리고 Wilson 하한 ≥ 75% |
| 2 | 정확 일치율 | ≥ 45% (하한 보고) |
| 3 | 부호 있는 편향 | −0.3 ~ +0.3 등급, 신뢰구간 포함 |
| 4 | 평균 절대오차 | 오너 확정 |
| 5 | 과대평가 | 1등급 이상 ≤ 20%; 2등급 이상은 임계 + 상한 보고 |
| 6 | 채점 일관성·요소별 오류 | 문항 유형별 임계(오너 확정), 주입 시험 무상승 |
| 7 | 민감도 | AI 오차 가감 시 등급 변경 ≤ 15% (가안) |
| 8 | 범위 폭 | 일률 지정하지 않음 — 검증 결과를 본 뒤 오너가 한도 설정(포함률 목표만 사전 고정) |

미달 시 그 과목은 등급 숨김 유지. 과목 간 합산 금지. 소량 표본 결과의 일반화 금지. 새 세트는 동등성 점검 전까지 숨김.

## 6. 예산안 (제안 — 미승인): 이용량 구간별 AI 호출 예산표

이전 $65·$75안과 160명 확정 모집 가정은 폐기한다. 학생 응시 자체의 AI 채점 비용은 정상 서비스 운영 비용이며 이 파일럿 예산이 아니다. 파일럿 예산은 **파일럿 목적의 추가 AI 호출**만 센다: ① A단계 최종 평가 세트 측정 ② 실제 성적을 공유한 응시의 **재채점 일관성 점검**(고정 구성으로 다시 채점해 두 번 채점 불일치·민감도 측정). 호출 단가는 실측 약 $0.0265(영어 에세이 $0.053/2회). 상한 = 호출 수 × 단가 × 1.15(재시도 여유).

| 단계 | 도달 조건(실제 이용량) | 목적 | 산출물 | 추가 AI 호출(상한) | 상한 금액 |
|---|---|---|---|---|---|
| T0 | 즉시(A단계) — 최종 평가 세트 작성 완료 | 자체 샘플 기준의 채점 기능 검증 | 요소별 정확 일치·유형별 절대오차·서열 역전·주입 시험 | 약 125 | $4 |
| T1 | 자발 제출 성적 ≥ 20건(전 과목) 이고 풀 구성 채점 완료 응시 ≥ 20 | 제출 응시의 재채점 일관성 첫 측정 | 두 번 채점 불일치율, 초기 민감도 | 200 | $6 |
| T2 | 제출 성적 ≥ 60건 이고 한 과목 ≥ 15건 | 과목별 일관성·민감도 | 과목별 일관성 표, 경계 부근 민감도 | 600 | $18 |
| T3 | 제출 성적 ≥ 150건 이고 한 과목 ≥ 40건 | 경계점 평가용 민감도 전수 | 평가용 자료에 대한 등급 변경 비율 범위 | 1,500 | $46 |
| 합계(모든 단계 도달 시 최대) | | | | 약 2,425 | **약 $74 (미승인)** |

호출 비용 = 호출 수 × 약 $0.0265 × 1.15. **European History 예산과의 중복: 없음**(유럽사의 추가 자체 샘플 검증은 별도 에이전트·별도 승인분이며 이 표에 포함하지 않는다).

- 각 단계는 도달 조건 확인 → 단계별 상한·최소 범위 제출 → 오너 승인 후에만 집행한다(승인 전 실행 없음). 단계 도달이 등급 활성화를 뜻하지 않는다(§3 최소 조건 별도).
- 이 표에 **포함하지 않는 것**: 학생 응시 정상 채점 비용, 개발 인력, 유럽사 별도 검증(다른 에이전트 진행분 — 중복 없음). 사람 채점·사례비는 계획에 없다.
- 과목 수 4(영어·문학·미국사·세계사). 유럽사는 검증 통과 후 같은 방식으로 합류.

## 7. 환산표 활성화와 변경 이력

환산표(경계점) 활성화는 오너 승인이 필요하며 승인자·시각·버전과 변경 이력을 남긴다. 승인 없는 활성화 경로는 만들지 않는다(`ap_grade_scales`, 불변 스냅샷 — 구현 계획).

## 8. 실제 AP 성적 제출 (설계)

결과 화면·응시 기록에서 접근하는 **선택 입력**. 필드: 과목, 시험 연도, 성적(1~5), 제출일, 자기보고 여부, 연결 응시 id. 성적표 이미지 필수 아님. 새 동의 체크박스 없음(동의 4개 원칙).

## 9. 오너 결정 필요

1. 합격 기준 §5 임계값(평균 절대오차, 문항 유형별 임계, 2등급 이상 과대평가 상한).
2. §6 단계별 도달 조건과 상한 승인(단계마다 집행 전 승인).
3. A단계 최종 평가 세트 기준 점수 확정 방식(내부 검토자 지정).
4. 평가용 독립 자료의 출처(분할 vs 다음 해 코호트).
