**풀 세트는 개수만으로 완성으로 판정하지 않는다.** 공식 구성(MC 42 = Part A 29 계산기 불가 + Part B 13 그래핑 계산기 필수, FRQ 6 = Part A 2 계산기 + Part B 4 계산기 불가, 단원별 MC 비중, 계산기 파트)과 문항군 다양성 하한(MC 군당 2개 이하·서로 다른 문항군 ≥ 절반, **FRQ 는 문항군당 1개 = 6개 모두 다른 유형**)을 모두 만족해야 한다(`lib/ap-exam/assemble.ts` 옵션 `unitBounds`, `maxPerFamily`, `minDistinctFamilies`). 재현: `npx tsx scripts/ap-generation/ab-feasibility.ts`(결과 `data/ap/stock/ap_calculus_ab-set-feasibility.json`). 한계: 조립은 탐욕적(부족 단원 우선)이라 "불가"는 "이 알고리즘으로 불가"이며 정확한 최적화(ILP)는 아니다.
