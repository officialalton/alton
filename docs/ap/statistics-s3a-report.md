오너 지시(standing "기다리지 말고 진행", AP 예산 총 상한 $50·중단선 $45): 새 다단계 MC 원형 10개 x 시드 2 = 20 후보 유료 런. 이번 런 하드 한도 $0.88, 자동 수선 반복 없음, 첫 통과 50% 미만 시 중단. 서비스 키·원격/비프로덕션 DB·push·프로덕션·공유 ALTON 스택은 쓰지 않았다(Anthropic 호출은 저장소 복사본 `.env.local` 의 키만, 유료 호출 직후 `.env.local` 을 격리 스택 값으로 덮어써 키 제거).

## 2. 일치율에 대한 정직한 주의
일치율 100% 는 판정기가 구조 신호(단계 수·결합 수)를 **사실로 받고** 판정한 결과이므로 독립 검증이 아니다(`statistics-difficulty.md` §4: 유도 효과 가능). 따라서 exam_prep 100% 는 "판정기가 신호를 따랐다"는 뜻이지, 실제 학생 난이도가 높다는 증거가 아니다. 교차 확인은 풀이자(Opus) 정답률과 검토 5기준 통과로만 가능하며 학생 데이터 전에는 미검증이다. 일치율 60% 미만 조건은 해당 없음(S3-b 보류 사유 없음).

- 화면 증거(격리 스택 `ALTON_apstats4`, 하드닝 가드 통과): 통과 17개 전부(그림·표 의존 잔차·트리·블록·표 포함) 390x844·1280x800 = **34항목**, 점검 238건 중 pass 188 · 해당 없음 50 · **fail 0**, 스크린샷 `docs/ap/screen-evidence/stats-s3a/`.
