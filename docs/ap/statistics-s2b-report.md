## 2. Phase 1 — 무료 엔지니어링 (커밋 `6dee19c1`)
**반려 6건 수정**(S2-a 보고 §3)
1. `st_method_choice_means`: 오답마다 구별 근거(쌍 구조·표본 수·변수 유형)를 표(`MEAN_WHY`)로 고정, 키를 쌍/한 표본으로 한정(쌍 시나리오의 "한 표본 t" 선택지는 모호해서 제외), 쌍 시나리오 3가지(전후·양손·쌍둥이).
2. `st_method_choice_cat`: 3.14 전용(카이제곱 독립성 시나리오, 범주 3개 이상 변수) — 장식 오답 대신 이분 비율 검정·단일 비율·평균 검정을 각각 구별 근거와 함께.
3. `st_conditions_prop`: 다단계로 재설계 — 표본 비율이 아니라 귀무값 $p_0$ 로 큰 수 조건을 확인(표본 성공 수로 확인하면 판정이 뒤집히게 값 설계), 10% 조건은 $N$ 의 10% 를 직접 계산(경계 근처 값). 선택지 4개는 서로 다른 판정(모두 충족/10%/큰 수/임의성)이고 코드가 세 조건을 따로 평가해 정답 하나만 일치.
4. `st_boxplot_compare`: 비교하는 5개 통계량(중앙값·IQR·범위·Q3·최댓값)의 두 집단 차이가 모두 ≥6, 눈금(격자) 표시 문구, 오답 근거에 실제 값 표기. (수정·무료 테스트만 — 이번 칸 채우기에는 필요 없어 유료 생성은 하지 않음)
5. `st_set_binomial`: 문항 앞 "Questions refer to the following information." 제거(소개 문구는 공유 자료 설명 문장), 표를 읽는 확률 합산 문항은 토픽 2.8, 오답 근거의 "non-defective" 를 맥락별 문구로, 모드 오답을 n/2 로 교체. 회귀 세트의 같은 문구도 제거.
6. FRQ Q1: 검토기 `SUBJECT_NOTES` 에 **Statistics 10점·행 10개·복합 초점** 기준 추가(칼큘러스 9점 기준과 충돌 시 통계 기준 우선), 자료 표를 파트 A 연구 맥락으로 연결, "chose to not" → "do not ...".
**파이프라인 상수**: `pipeline2.ts` 내보내기 `shared_set` → `shared_stimulus_set`(DB 제약값). 확정 스크립트 `stats-s2a-finalize.ts` 에 `--batch` 인자(출력 파일 접두)와 S2-a 재고 비교 추가.
**신규 원형 9개**(단독 MC): 스킬 1 — `st_question_type`(질문이 묻는 변수 구조), `st_question_revision`(초안 결함 진단 후 수정), `st_question_scope`(표본이 답할 수 있는 모집단); 스킬 2 — `st_sampling_bias`(1.12), `st_blocking_design`(1.13), `st_simulation_design`(2.3, 숫자 배정·시행 길이·사건 규칙 삼중 비교), `st_hypotheses_means`(4.4, 빼는 순서로 방향 결정), `st_ci_width_effect`(4.2, 표본 크기·신뢰수준 동시 변화의 순효과, t* 이중 계산), `st_power_effect`(3.8). 전부 코드가 정답을 계산하고 고정 문장 선택지. 가이드 JSON 50항목.
