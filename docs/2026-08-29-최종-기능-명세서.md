# Alton Education — 최종 기능 명세서 (2026-08-29)

이 문서는 최종적으로 완성된 제품에 들어가야 하는 모든 기능을 포털별로 정리한 것이다. 이미 만들어진 기능과 앞으로 만들 기능을 구분하지 않고 "완성됐을 때 이 서비스가 무엇을 할 수 있어야 하는가"를 기준으로 전부 나열했다 — 기획 검토·수정용 문서다.

배경(사업 개요, 4개 포털과 수업 세션뷰의 관계, 저작권 정책 등)은 `docs/spec/functional-spec.md`에 이미 정리되어 있으므로 이 문서는 반복하지 않고, **거기서 이번에 바뀐 부분만** 아래 0번 항목에 정리했다. 그 뒤로는 포털별 전체 기능 목록이다.

---

## 0. 기존 사업 개요 대비 변경된 부분

- **화상 수업**: 줌 → **구글 미트**로 변경.
- **예약**: 캘린들리 → **구글 캘린더 기반 자체 예약 화면**으로 변경(포털 안에 자체 UI로 구현, 외부 서비스 임베드 아님).
- **계정 체계**: 관리자·선생님은 **회사 도메인(alton.education) 구글 계정**을 발급받아 사용. 학생·학부모는 **본인 구글 계정 보유가 서비스 이용 조건**.
- **계약서 서명**: DocuSign 유지(변경 없음).
- **연습장 Docs 서브탭**: 외부 링크 목록이 아니라 **구글 문서(Google Docs) 임베드**.
- 그 외 사업 개요·법인 구조·고객 분류 체계·저작권 정책은 기존 문서 그대로 유효.

## 1. 학생 포털

- **홈**: 이번 달 캘린더(날짜 클릭 시 그 날 수업 목록), 다가오는 수업 요약, 수업권 잔여 장수, 참여율 등 통계 요약.
- **레슨**
  - 예정된 수업 목록 / 지난 수업 목록
  - **예약**(구글 캘린더 기반): 담당 선생님의 예약 가능 시간을 캘린더 형태로 보고 직접 슬롯을 선택해 예약. 예약 시 이름/이메일을 매번 새로 입력하지 않고 로그인 정보로 자동 채움.
  - **취소/재예약**: 정해진 기한 전까지 학생이 직접 취소·재예약 가능. 기한 이후 취소는 지각/노쇼 처리 정책과 연동.
  - 수업 회차별 커리큘럼(단원 진도) 열람
  - 지난 수업에 대한 선생님 리뷰 확인, 학생 본인의 피드백(별점+코멘트) 작성
- **선생님**: 담당 선생님 목록 → 프로필(학교/전공/약력) → 그 선생님과의 수업 이력 → 1:1 실시간 메시지
- **과제**: 할일/완료 서브탭, 문항별 인라인 답안 작성(자동저장)
- **문제 기록**: 그동안 풀었던 모든 문제 이력, 과목/단원/정답여부/포맷별 필터링
- **단어장**: 세션 중 클릭으로 추가한 단어 + AI 뜻풀이, 직접 추가/삭제
- **교재**: 수강 중인 과목의 교재를 세션과 무관하게 미리 훑어보는 라이브러리(단원 목차 → 교재 → 문제 풀이까지 가능하되, 정답/해설은 실제로 풀어야 노출)
- **수업권**: 보유 크레딧 장수/유효기간, 부족 시 "부모님께 결제 요청" 보내기
- **통계**: 출석률, 지각률, 만족도, 과목별 참여 현황 그래프
- **계정메뉴**: 공지사항, 회원정보 변경(시간대 설정 포함), 관리자 문의, FAQ, 학원 정책 안내, 로그아웃
- **알림**: 우측 상단 알림벨(예약 확정, 새 과제, 정산 관련 등 역할별 알림)

## 2. 학부모 포털

- **홈**: 자녀 전환(자녀가 여럿이면 상단에서 전환), 캘린더, 수업권 잔여, 참여 통계 요약
- **레슨**: 예정된 수업 / 지난 수업 / **선생님**(자녀 담당 선생님 프로필 + 이력 + 메시지) — 3개 서브탭. **예약·취소·재예약 기능은 없음**(학부모는 조회 전용, 예약은 학생 계정에서만 가능 — 정책적으로 의도된 제약).
- **수업권**: 크레딧 구매(패키지 선택 → 결제), 자녀별 사용 현황, 추천인 코드
- **통계**: 자녀별 출석률/지각률/만족도/과목별 참여 그래프
- **계정메뉴**: 공지사항, 문서 관리(계약서 등 다운로드), 회원정보 변경, 관리자 문의, FAQ, 학원 정책 안내, 로그아웃
- **알림**: 알림벨

## 3. 선생님 포털

- **홈**: 캘린더+오늘/이번주 수업 요약, 대기 중인 예약 신청, 담당 학생 요약, 정산 요약(다음 정산 예정 금액), 알림벨
- **일정**: "예약 관리"(들어온 예약 신청 수락/거절, 처리 내역) / "일정 오픈"(구글 캘린더 연동 기반으로 예약 가능 시간대 설정) 2개 서브탭
- **수업**: 예정된 수업 / 지난 수업, 세션뷰 진입("수업 준비"/"수업 진행"/"수업 기록"), 지난 수업에 대한 리뷰 작성(AI 초안 지원)
- **학생**: 담당 학생 목록(과목별), 학생별 메시지/문제기록/단어장 바로가기, 학부모 요청사항 아카이브
- **커리큘럼**: 내가 등록한 과목(과목 템플릿 기반), 학생별 커리큘럼(진도 순서 편집)
- **교재**: 담당 과목의 교재 라이브러리 열람(자신이 만든 교재 포함)
- **정산**: 정산 예정 금액, 정산 히스토리, 정산 계좌 등록/변경, 정산 관련 문의
- **계정메뉴**: 회원정보 변경, 관리자 문의, 로그아웃

## 4. 관리자 포털

- **홈**: 상담 대기/확정, 학생 매칭 대기, 선생님 승인 대기, QC 경고 현황 요약 카드
- **사용자**: 학부모/학생/선생님 목록·상세, 상태 변경, 초대, 학생 크레딧 수동 조정, 선생님 승인, **선생님 담당 과목 배정**, 정산용 시급 등록, 구글 계정 발급 상태 표시
- **매칭**: 매칭 대기 학생을 과목별로 선생님과 연결, 총 회차 수 입력, 매칭 취소
- **상담**: 상담 신청 현황(랜딩 페이지 접수분), 상담 슬롯 오픈(구글 캘린더 기반), 상담 아카이브(과거 상담 기록), 상담 회신 자료/템플릿 관리
- **커리큘럼**: 과목 템플릿(과목/단원 관리, 다른 모든 화면의 단일 진실 소스), 교재 문서 편집(WYSIWYG, AI 문제 생성 연동), 교재 라이브러리, **선생님 작성 교재 승인 대기 큐**
- **수업권**: 학생별 크레딧 발급/조정 이력
- **계약**: 학부모·학생 계약(DocuSign), **선생님 계약(신규)** — 서명 상태 총괄
- **QC**: QC 경고 이력(지각/노쇼 등), 보충수업 현황, 학부모 요청 아카이브, 선생님-학생 메시지 조회(품질 관리 목적)
- **정산**: 선생님별 인건비 계산(시급×완료 수업시간), 지급 처리/완료취소, 기간별 조회
- **문서**: 회사 공식 문서 보관함(법인설립·세무·계약 템플릿 등, 업로드/다운로드)
- **슈퍼바이저**: 중간관리자 역할 신설 — 초대, 접근 가능한 관리 기능 범위 설정
- **개발 로그**: 개발 진행 이력 열람(내부용)

## 5. 수업 세션뷰 (4개 포털 공통 진입 화면)

- **상단바**: 세션 제목(과목/학생/회차), 상태(준비중/진행중/완료됨)에 따라 다른 컨트롤(예정 일시 / 구글 미트 연결+노쇼 알림+수업 종료 / 완료 배지)
- **교재 탭**: 목차+본문, 스크롤스파이, 필기 캔버스(펜/지우개), 선생님 전용 티칭팁
- **과제 탭**: 세션 진입 시 기본 탭. 학생 답안 작성(자동저장), 선생님 과제 추가/확인
- **문제 생성 탭**(선생님 전용, 학생·학부모에겐 완전히 숨김): 포맷/난이도/유형/개수 선택 → AI 생성 → 편집 가능한 초안 → 재생성 → "과제로 확정"
- **문제 기록 탭**: 이력 필터링, 선생님의 "선생님 픽" 태그
- **단어장 탭**: 클릭 추가 + AI 뜻풀이, 학생 포털과 데이터 공유
- **연습장 탭**: **Docs 서브탭(구글 문서 임베드)** + 화이트보드 서브탭(실시간 공동 필기, 무한 스크롤)
- **보충 자료 탭**: 선생님 업로드/학생 업로드 서브탭, 각자 자신이 올린 파일만 삭제(확인 다이얼로그 필수)

## 6. 인증/랜딩 (포털 공통)

- 랜딩 페이지 → 인테이크 폼 → 상담 예약(구글 캘린더 기반)
- 로그인/역할 기반 라우팅(학생/학부모/선생님/관리자)
- 최초 로그인 시 비밀번호 설정 플로우(초대 이메일 링크, 이메일 스캐너에 의한 토큰 소진 방지 처리 포함)
- 비밀번호 재설정
