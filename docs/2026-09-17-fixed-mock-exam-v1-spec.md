# 고정형 SAT 모의고사 V1 — 확정 사양

> 작성일: 2026-09-17  
> 상태: 제품 정책 확정, 구현은 문제 생성 품질 작업 완료 뒤 별도 마일스톤으로 착수

## 1. 목표와 범위

학생이 일반 과제와 분리된 시험 환경에서 SAT Reading & Writing 및 Math 세트를 응시하고, 교사는 수업 중 같은 시험을 배정·확인하며, 결과를 다음 수업과 과제에 활용한다.

V1은 **고정형 모의고사**다. 시험 시작 뒤 문항 난이도가 바뀌는 적응형 모듈은 구현하지 않는다. 관리자는 기본·표준·상위 난이도의 완성된 시험 세트를 여러 개 운영한다.

이번 범위에 포함하지 않는 항목:

- 적응형 모듈과 그에 따른 점수 산정
- AP 시험과 구형 SAT Essay
- College Board 공식 점수와 동등하다고 주장하는 점수 환산
- 시험 중 학생의 계산기 입력·탭 이동 기록을 이용한 감독 기능

## 2. 제품 원칙

- 모의고사는 과제가 아니다. 과제 배치와 별도 원본·상태·결과를 가진다.
- 수업 안에서는 단어장·과제처럼 **모의고사 탭**으로 열리며, 수업 밖에서는 학생 포털의 독립 **모의고사** 탭에서 같은 응시 기록을 연다.
- 배정은 수업 안에서도 할 수 있지만, 응시 기록과 결과는 학생당 시험당 하나다.
- 학생이 시험을 완료하면 결과는 교사 수업 화면, 학생 모의고사 탭, 학부모 읽기 전용 화면에 같은 원본에서 표시된다.
- 문제·과제·모의고사의 풀이 결과는 같은 세부기술 성취 기록에 반영하되, 학습 맥락과 평가
  성격은 분리해 표시한다.
- V1의 결과는 정답률·영역·세부기술·난이도·소요 시간 기반 학습 진단이다. 실제 SAT 점수나 College Board 점수와 동등하다고 표시하지 않는다.

## 3. 역할별 흐름

### 관리자

1. 문제은행의 공개 문항만 사용해 고정형 시험 세트를 만든다.
2. 세트에 R&W와 Math 구성, 난이도 등급, 문항 순서, 시간 제한, 공개 상태를 정한다.
3. 세트를 공개하면 교사 배정 후보와 학생 모의고사 목록에 노출할 수 있다.
4. 세트 수정은 새 버전으로 만든다. 이미 시작한 응시는 시작 시점의 문제·정답·시간 규칙을 고정한다.

### 교사

1. 수업 화면의 새 `모의고사` 탭에서 담당 학생에게 공개된 시험 세트를 배정한다.
2. 시작 가능 시점, 마감일, 응시 가능 횟수를 정한다.
3. 학생의 미시작·진행 중·제출·채점 완료 상태와 요약 결과를 본다.
4. 완료 결과에서 약한 세부기술을 확인하고, 다음 회차의 문제 구성 또는 별도 과제 발급에 활용한다.

### 학생

1. 수업 안의 `모의고사` 탭 또는 학생 포털의 `모의고사` 탭에서 배정된 시험을 연다.
2. 시험 시작 전 안내, 시간, 문항 수, 계산기·참조표 제공 여부를 확인한다.
3. 시작하면 전용 시험 인터페이스에서 문항 이동, 표시, 답안 저장, 중단 후 재개, 제출을 한다.
4. 완료 뒤 결과·세부기술별 진단·오답 복습 진입점을 본다.

### 학부모

- 학생과 같은 모의고사 목록, 응시 상태, 완료일, 요약 결과와 학습 진단을 읽기 전용으로 본다.
- 답안 입력, 시험 시작·제출, 배정 변경, 정답·해설 조기 열람은 할 수 없다.

## 4. 수업 탭과 독립 진입의 연결

수업 화면 탭은 다음처럼 확장한다.

`교재 · 문제 · 단어장 · 과제 · 모의고사 · 수업 준비(교사)`

- `모의고사` 탭은 수업에 종속된 사본을 만들지 않고, 학생에게 배정된 독립 시험 기록을 불러온다.
- 학생은 수업 도중 교사가 배정한 시험을 같은 탭에서 바로 시작할 수 있다.
- 같은 시험은 학생 포털의 독립 `모의고사` 탭에서도 재개할 수 있다.
- 시험을 시작한 뒤에는 시험 화면 안에서 문항 이동·답안 저장·제출을 처리한다. 수업의 다른 탭으로 돌아가려면 시험을 나가고, 진행 상태와 남은 시간은 유지된다.
- 실전형 응시에서는 정답·해설을 시험 완료와 채점 확정 전까지 숨긴다.

## 5. 시험 구성과 상태

V1 시험 세트는 다음을 가진다.

- 이름, 설명, 난이도 등급(기본·표준·상위), 공개 상태
- R&W 섹션과 Math 섹션의 문항 목록과 순서
- 섹션별 시간 제한과 계산기·참조표 허용 여부
- 시험 버전

학생 응시 기록은 다음 상태를 가진다.

`배정됨 → 진행 중 → 제출됨 → 채점 완료`

마감 또는 응시 횟수 제한에 걸린 경우도 기록한다. 시작된 응시에는 세트의 문제 버전, 답안 규칙, 시간 규칙을 고정한다. 새 공개 문제나 이후 시험 세트 수정은 기존 응시에 영향을 주지 않는다.

## 6. 공통 Math 도구

계산기와 참조표는 모의고사 전용이 아니다. Math 문항을 푸는 모든 학생 화면에서 같은 공통 도구를 제공한다.

- 수업 중 `문제` 탭
- 수업 중 `과제` 탭
- 학생 포털 과제 화면
- 수업 안 및 독립 모의고사의 Math 섹션
- 교사의 학생 화면 미리보기

R&W, 단어장, 교재에는 표시하지 않는다.

문제·과제·모의고사는 같은 Math 도구 모음과 렌더러를 사용한다. 화면마다 계산기나 참조표의
서로 다른 사본을 만들지 않는다.

### 계산기

- Math 화면 오른쪽의 고정 패널로 제공하고, 좁은 화면에서는 플로팅 버튼으로 연다.
- 그래프 계산을 지원하는 Desmos 스타일 도구를 목표로 한다.
- 같은 응시 세션에서 문항을 옮겨도 계산기 입력 상태는 유지한다.

### 참조표

- College Board Math reference sheet의 필요한 공식 범위를 기준으로, ALTON 화면용으로 재구성한 참조표를 사용한다.
- 원·부피·직각삼각형·특수각·도/라디안 등 필요한 공식을 포함한다.
- 외부 PDF를 화면에 그대로 삽입하지 않는다. 실제 문구·도표의 재사용 범위는 구현 전에 사용 조건을 확인한다.

## 7. 답안·채점·결과

- 객관식과 SPR는 기존 문제 답안 모델을 재사용한다.
- 시험 제출 뒤 자동 채점 가능한 문항은 서버가 계산하고, 교사가 확정하는 기존 정책을 따른다.
- 정답과 해설은 학생에게 채점 확정 뒤에만 열린다.
- V1 결과 화면에는 전체 정답률, 섹션별 결과, 세부기술·난이도별 결과, 소요 시간, 오답 복습 및 보충 과제 추천을 표시한다.
- 점수 추정은 실제 학생 응답과 시험 세트의 보정 데이터가 쌓이기 전에는 구현하지 않는다. 향후 추가하더라도 “예상 범위·학습 진단”으로만 표시한다.

### 문제·과제·모의고사 결과의 공동 활용

- 문제 풀이, 과제, 모의고사의 정답·오답·부분 답안·소요 시간은 공통 세부기술 성취 기록에
  반영한다.
- 성취 화면은 전체 추세를 보여 주되, 결과의 출처를 `수업 문제`·`과제`·`모의고사`로
  구분해 표시한다. 짧은 과제의 정답률이 제한 시간 모의고사 결과를 덮어쓰지 않게 한다.
- 교사는 수업 준비에서 약한 세부기술과 근거가 된 최근 문제를 확인하고, 그 결과를 이용해
  기존 과제를 발급하거나 다음 회차 문제를 구성한다.
- 모의고사 결과에서는 시험 전체·섹션별 결과를 우선으로 보이고, 약점 세부기술을 다음
  수업 문제와 과제의 추천 후보로 보낸다. 자동 발급하지는 않는다.
- 학생과 학부모는 자신의 누적 성취와 출처별 결과를 읽기 전용으로 보고, 교사만 그 결과를
  이용해 과제 발급과 회차 구성을 조정할 수 있다.

## 8. V1 완료 기준

1. 관리자가 고정형 시험 세트를 버전으로 만들고 공개할 수 있다.
2. 교사가 수업의 `모의고사` 탭에서 세트를 학생에게 배정할 수 있다.
3. 학생이 수업 안과 독립 모의고사 탭에서 같은 응시를 시작·중단·재개·제출할 수 있다.
4. Math 시험·문제·과제에서 계산기와 참조표가 일관되게 보인다.
5. R&W에는 계산기·참조표가 보이지 않는다.
6. 시험 시작 뒤 문제·정답·시간 규칙이 고정된다.
7. 학생·교사·학부모가 권한에 맞는 동일 결과를 보고, 학부모는 읽기 전용이다.
8. 모의고사 결과를 근거로 교사가 기존 과제 발급과 회차 문제 구성을 할 수 있다.
9. 문제·과제·모의고사의 세부기술 성취는 함께 집계되고, 각 결과의 출처와 평가 성격은
   분리되어 표시된다.
10. 역할별 Preview UAT와 모바일 좁은 화면 UAT를 통과한다.

## 9. 후속 V2

문제은행 난이도와 실제 학생 응답 데이터가 충분히 쌓인 뒤에만 아래를 검토한다.

- 모듈 1 결과에 따른 모듈 2 난이도 조정
- 적응형 경로별 시험 조립
- 점수 추정 범위와 보정 방식
- Bluebook에 가까운 실전 모드 세부 경험
